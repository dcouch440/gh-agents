## Project Requirements Document

The concept of the database schema is to do the following.
Create reusable agents belonging to the user that come with a system prompt.
Create clusters which is a collection of agents executing in a chain.
Create pipelines thats a mix of clusters and agents.
The goal of the pipeline stage is to complete all the clusters and tasks to progress to the next stage.

Example ->
- Stage one needs some input data, this could be a file + a prompt, or just a prompt (The goal of the pipeline).
- From an initial prompt we want to have a few options:
  - Assign 1 agent to the input and have 5 agents work on each completed task.
  - Assign 5 agents to work on the input that all do different jobs resulting in a different result.
  - This would result in the next stage taking 5 inputs (or you can think of it like 5 new stages for stage 2).
  - We would handle this by asking the LLM (The 1 agent solution) to return a "for each" style solution (decompose the features this requires and assort it in an array).
    Then because the agents response is an array it would show a "for each" symbol on the screen and we would be assigning a single agent to each iteration (or multiple!).
  - In the case of 5 agents assigned (via user programming and selection), tier 2 would have a variable selection of a task to "inherit" as context from the previous stage.


## Phase 1 (Backend)
1. Agents belong to a the user that created them.
2. Agents have system prompt only, they will be prompted with instructions from the task.
3. From the task we can find what the system prompt, prompt, message history (including tools and solution) was at the time of execution.
4. Clusters have a complete execution system to create an agent flow of actions.
5. Pipelines have the capability of adding multiple clusters + agents to complete the goal.
6. We can toggle on and off "review" for any section.
   For example, if we had a pipeline stage where an agents goal was to create a milestone with 6 tickets and multiple slices.
   We would have a review for it, where you would connect with an agent and refine their milestone with the requirements I ask.
