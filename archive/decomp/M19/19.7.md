# Ticket 19.7: CLI Tool Execution Display

> Terminal-native rendering of agent tool calls in the Ink CLI — structured, colored, collapsible, and real-time.

## Goal

The CLI shows agent tool execution inline as agents work. Each tool call renders as a compact, colored block using Ink's Box/Text primitives. Running calls show a spinner, completed calls collapse to a one-line summary. Users can expand calls with keyboard navigation.

**Checkpoint**: User sends a task via CLI. As the explorer agent works, tool calls appear: `◆ Read src/main.rs (42ms)`, `◆ Grep "AuthService" (128ms, 3 matches)`. Running calls show `● Bash cargo test...` with a spinner. Errors show in red.

---

## Context

The CLI currently only handles authentication. This ticket adds real-time agent activity rendering using the same WebSocket events as the web UI.

### Slice 19.7.2: ToolCall Component (Ink)

**Do this**:
- Create `ToolCall` Ink component: `({ toolCall: ToolCall })`
- Render using Ink Box/Text:
  - Running: `● {ToolName} {argument}...` with `ink-spinner`
    - Spinner in accent color, tool name bold, argument dim
  - Completed: `◆ {ToolName} {argument} ({duration})`
    - `◆` in tool-type color, tool name bold white, argument dim, duration dim
  - Failed: `✗ {ToolName} {argument} — {error}`
    - `✗` in red, error message in red
- Tool-type colors (map to ANSI):
  - Read/Write: blue
  - Edit: yellow
  - Glob/Grep: cyan
  - Bash: white
  - Git: green
- Expanded mode (toggle with arrow keys):
  - Show output preview (first 10 lines of text, or file count, or match count)
  - Bordered Box with output content

**Verify**:
- [ ] Running call shows spinner
- [ ] Completed call shows duration
- [ ] Failed call shows error in red
- [ ] Colors match tool type
- [ ] Expanded mode shows output preview
