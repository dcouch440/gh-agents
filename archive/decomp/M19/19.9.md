# Ticket 19.9: Tasks Page with Delegation View

> Replace the TasksPage stub with a real implementation showing task status, progress, and subagent delegation trees.

## Goal

The TasksPage shows all tasks with status, progress bars, and delegation details. Clicking a task opens a detail view showing the full delegation tree — which agents worked on it, what tools they called, and the final result. This is the "project manager" view complementing the chat's inline tool display.

**Checkpoint**: TasksPage shows 5 tasks in a list. One is in-progress with a progress bar. Clicking it shows a delegation tree: orchestrator → explorer (completed, 8 tool calls) + coder (active, tool calls streaming) + tester (pending).
