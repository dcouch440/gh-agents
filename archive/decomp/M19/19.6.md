# Ticket 19.6: Agent Activity Views

> Full-page and panel views that compose ToolCallBlocks into agent activity timelines — the AgentsPage, task detail delegation view, and a floating activity panel.

## Goal

Three views that show agent tool execution at different scopes: (1) the AgentsPage shows all active agents with their live tool call streams, (2) a task detail view shows the delegation tree with each subagent's activity, (3) a floating panel can be pinned while on the chat page to watch agent progress.

**Checkpoint**: AgentsPage shows 3 active agents in cards, each with a live-updating stream of ToolCallBlocks. Clicking an agent expands to full-screen detail. A floating panel on the chat page shows the currently active agent's tool calls.
