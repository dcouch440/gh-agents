# Ticket 13.4: Agent Grid Layout

> Grid of agent stations organized by tier with section headers and pool statistics.

## Goal

An `AgentGrid` component that arranges all agent stations into a structured grid with tier sections and a summary bar.

**Checkpoint**: `<AgentGrid />` renders sections for orchestrators, workers, and utilities, each with a header and station boxes in responsive rows.

---

## Context

Agents are grouped by tier. Each tier section has a header line, then stations arranged in rows (fitting as many as terminal width allows). A summary bar at the top shows pool counts and connection status.

**Layout**:
```

─── ORCHESTRATORS ──────────────────────────────────────────
┌─ orchestrator-01 ───── ●┐
│ task: Plan milestone 5   │

│                          │

─── WORKERS ────────────────────────────────────────────────
┌─ worker-01 ───── ●┐  ┌─ worker-02 ───── ●┐  ┌─ worker-03 ── ○┐
│ task: Impl auth   │  │ task: Fix tests   │  │                 │

```
