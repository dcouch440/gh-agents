# Ticket 18.3: Spawn Request Protocol

> Extend command/response protocol for subagent spawning.

## Goal

The agent communication protocol supports spawn requests and subagent lifecycle events. An orchestrator agent can send `SpawnSubagent` commands and receive `SubagentSpawned`/`SubagentResult` responses.

**Checkpoint**: `AgentCommand::SpawnSubagent(SpawnRequest)` can be sent through dispatcher. `AgentResponse::SubagentSpawned` and `SubagentResult` serialize and pattern-match correctly.

---

## Context

The existing `AgentCommand`/`AgentResponse` enums in `channels.rs` need new variants for subagent lifecycle events. The `SpawnRequest` struct is defined in `agent_type.rs` (18.1).

**Key files**:
- `src/agents/channels.rs` — New command/response variants
- `src/agents/agent_type.rs` — `SpawnRequest`, `SpawnRecommendation` (from 18.1)

**Dependencies**: 18.1
