# Ticket 18.5: Parallel Subagent Coordination

> Fan-out/fan-in: spawn N subagents, collect results, synthesize.

## Goal

`SubagentCoordinator` spawns multiple subagents concurrently, waits for all results (with timeout), handles partial failures, and synthesizes a final output from all subagent results.

**Checkpoint**: 3 spawn requests → 3 concurrent agents run → all results collected → synthesized output. If one fails, partial results still returned.

---

## Context

This is the core coordination logic. The orchestrator delegates to the coordinator for complex multi-subagent tasks.

**Key files**:
- New `src/agents/coordinator.rs` — `SubagentCoordinator`, `CoordinationResult`
- `src/agents/spawner.rs` — Used by coordinator
- `src/agents/mod.rs` — Add module declaration

**Dependencies**: 18.4

  - Log and skip individual spawn failures (don't fail the whole fan-out)

### Slice 18.5.2: fan_in()

**Do this**:
- Implement `fan_in(agent_ids: Vec<AgentId>, timeout: Duration) -> CoordinationResult`:
  - Listen on the dispatcher response channel for `EphemeralComplete` events matching the agent IDs
  - Collect results as they arrive
  - If timeout expires before all agents complete, mark remaining as timed out
  - Return `CoordinationResult` with collected results and failures

**Verify**:
- [ ] All 3 agents succeed → 3 results in `CoordinationResult`, no failures
- [ ] 1 agent fails → 2 successes + 1 failure in result
- [ ] Timeout expires with 1 agent still running → 2 results + 1 timeout failure
- [ ] All agents timeout → 0 results + N timeout failures

### Slice 18.5.4: Result Synthesis

**Do this**:
- Add `synthesize(result: &CoordinationResult, original_task: &str, llm: &dyn LLMProvider) -> Result<String>`:
  - Build a synthesis prompt with the original task and all subagent outputs
  - Ask the LLM to produce a unified response
  - Include failure information if any subagents failed
  - Return the synthesized output
- The orchestrator calls this after `fan_in` completes

**Verify**:
- [ ] All subagents succeed → synthesis prompt includes all outputs
- [ ] Partial failure → synthesis prompt notes which subtasks failed
- [ ] Synthesized output is returned as the orchestrator's task result
