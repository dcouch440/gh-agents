# Ticket 18.2: Ephemeral Agent Lifecycle

> Agents that auto-remove after task completion.

## Goal

Ephemeral agents bypass tier limits, use their own `max_ephemeral` limit, and are automatically cleaned up from the pool and dispatcher after task completion or failure.

**Checkpoint**: `spawn_ephemeral()` creates an agent that completes its task and is removed from pool + dispatcher. Timeout enforcement force-cleans stuck ephemerals.

---

## Context

Normal agents persist across tasks. Ephemeral agents are fire-and-forget: spawn, run one task, clean up. They need separate limits so they don't block persistent agent slots.

**Key files**:
- `src/agents/agent.rs` — Add `ephemeral: bool` field
- `src/types/config.rs` — Add `max_ephemeral: u8` to `AgentPoolConfig`
- `src/agents/pool.rs` — Add `spawn_ephemeral()`, `spawn_ephemeral_with_dispatcher()`, cleanup methods
- `src/agents/channels.rs` — Add `EphemeralComplete` response variant
- `src/agents/executor.rs` — Ephemeral exit behavior after task completion
- `src/agents/dispatcher.rs` — Cleanup on `EphemeralComplete`

**Dependencies**: 18.1

- The orchestrator/response handler should call `pool.cleanup_ephemeral()` when it sees `EphemeralComplete`

**Verify**:
- [ ] `cleanup_ephemeral` removes agent from pool
- [ ] `ephemeral_count` decrements
- [ ] Dispatcher unregisters the agent
- [ ] Agent is gone from pool after cleanup

### Slice 18.2.6: Timeout Enforcement

**Do this**:
- Add `spawn_time: Instant` field to ephemeral agent tracking (add `ephemeral_agents: HashMap<AgentId, Instant>` to `AgentPool`)
- Add `cleanup_timed_out_ephemerals(dispatcher) -> Vec<AgentId>` to `AgentPool`:
  - Check each ephemeral agent's elapsed time against the agent type's `default_timeout`
  - For timed-out agents: fail their task, send `EphemeralComplete`, cleanup
- This method should be called periodically by the orchestrator (or via a tokio interval)

**Verify**:
- [ ] Timed-out ephemeral agents are force-cleaned
- [ ] Non-timed-out agents are left alone
- [ ] Cleanup sends `TaskFailed` before removing
