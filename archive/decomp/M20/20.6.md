# Ticket 20.6: MainView + App Wiring

> Wire all components into the MainView screen and update App.tsx to route to it after authentication.

## Goal

After login, the CLI shows a live feed with status bar, scrollable feed area, and input bar. WebSocket connects and feed updates appear in real-time.

**Checkpoint**: Authenticated user sees live feed, can send chat messages, can run `/help` and `/clear`.

### Slice 20.6.2: WebSocket Integration

**Do this**:
- Create `NexorWsClient` instance in `useEffect` (or `useRef`)
- Wire `'message'` events to feed store mutations:
  - `feed` → `pushFeedItem(data, currentBranch)`
  - `task_update` → `updateTask(data)`
  - `agent_update` → `updateAgent(data)`
- Wire `'status'` events to `wsStatus` state
- Connect on mount, disconnect on unmount
- Push system message on connect: `Connected to server`
- Push system message on disconnect: `Disconnected from server`

**Verify**:
- [ ] Test: MainView renders with mocked WS client

---

### Slice 20.6.3: Command Wiring

**Do this**:
- Call `registerAllCommands` with deps:
  - `onBranch` → if args, call `handleBranchSwitch(args)`; else set `showBranchSelector(true)`
  - `onClear` → call `clearFeed()`
- In `handleInput`:
  - Parse input with `parseInput`
  - If command: dispatch via `getCommand` + execute, or push unknown command error
  - If not command: call `api.chat.send(text)` and push user message to feed

**Verify**:
- [ ] Test: /help pushes command list to feed
- [ ] Test: /clear empties feed
- [ ] Test: regular text calls api.chat.send
