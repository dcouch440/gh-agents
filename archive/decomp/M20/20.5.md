## Slices

### Slice 20.5.1: StatusBar

**Do this**:
- Create `cli/src/components/StatusBar.tsx`
- Props: `{ branch: string, wsStatus: 'connecting' | 'connected' | 'disconnected' }`
- Renders a single row with border-bottom:
  - Left: `nexor` in bold cyan
  - Right: `branch: <name>` in magenta, then connection dot (green=connected, yellow=connecting, red=disconnected)
- Use Ink `<Box justifyContent="space-between">`

**Verify**:
- [ ] Test: renders branch name
- [ ] Test: renders correct status color

### Slice 20.5.2: FeedItemRow

**Do this**:
- Create `cli/src/components/FeedItemRow.tsx`
- Props: `{ item: FeedItem }`
- Render based on `item.type`:
  - `branch_switch` → yellow bold divider: `━━━ Connected to branch: <name> ━━━`
  - `system` → dim text
  - `feed` → `<time> <icon> <agentId> <content>` with activity icon based on `itemType`
  - `task` / `agent` → similar with appropriate formatting
- Activity icons: `▶` for agent_report, `•` for action, `│` for log, `·` default
- Time format: `HH:MM:SS`

**Verify**:
- [ ] Test: branch_switch renders divider
- [ ] Test: system renders dim
- [ ] Test: feed renders with icon + agent + content

### Slice 20.5.3: FeedArea

**Do this**:

- Renders vertical list of `<FeedItemRow>` items
- Show last N items that fit terminal (use `useStdout()` for height)
- Auto-scroll: always show newest items
- `flexGrow={1}` to fill available space

**Verify**:
- [ ] Test: renders multiple feed items

### Slice 20.5.4: InputBar

**Do this**:
- Create `cli/src/components/InputBar.tsx`
- Props: `{ onSubmit: (text: string) => void, disabled?: boolean }`
- Renders bordered box at bottom with `❯` prompt and `ink-text-input`
- On submit: call `onSubmit` with trimmed text, clear input
- Skip empty/whitespace-only input
- `placeholder="Type a message or /command..."`

**Verify**:
- [ ] Test: onSubmit called with text on enter
- [ ] Test: input cleared after submit
