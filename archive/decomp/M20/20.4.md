# Ticket 20.4: Slash Command System

> Create a registry-based slash command parser and dispatcher with /help, /branch, and /clear commands.

## Goal

Input starting with `/` is parsed and dispatched to registered command handlers. `/help` lists all commands. `/clear` clears the feed. `/branch` delegates to branch switching (M21).

**Checkpoint**: `/help` prints command list to feed, `/clear` clears feed, unknown commands show error.

---

## Context

Commands follow the pattern: `/name [args]`. The registry is a simple `Map<string, SlashCommand>`. Commands receive a dependency object for accessing feed store and UI state.

**Key files**:
- `cli/src/commands/registry.ts` — New file
- `cli/src/commands/index.ts` — New file (registers all commands)
- `cli/src/commands/registry.test.ts` — New file

**Dependencies**: 20.3

---

## Slices

### Slice 20.4.1: Command Registry & Parser

**Do this**:
- Create `cli/src/commands/registry.ts`
- `SlashCommand` interface: `{ name: string, description: string, execute(args: string): void | Promise<void> }`
- `registerCommand(cmd)` — adds to map
- `getCommand(name)` — lookup
- `getAllCommands()` — returns all registered commands
- `parseInput(input: string)` — returns `{ isCommand: boolean, name?: string, args?: string }`
  - Input starting with `/` is a command
  - Split on first space: name is before space, args is after

**Verify**:
- [ ] Unit test: parseInput handles `/help`, `/branch main`, `/unknown`, `hello` (not a command)
- [ ] Unit test: register + get + getAll

### Slice 20.4.2: Built-in Commands
