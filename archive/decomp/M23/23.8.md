# Ticket 23.8: CLI Tree Overlay

> Full-screen colored tree view showing the project hierarchy with gate statuses.

## Goal

A full-screen overlay in the Ink CLI that shows the entire project hierarchy (PRD → milestones → slices → tasks) as a tree with box-drawing characters and color-coded gate statuses. The user navigates with arrow keys, expands/collapses nodes, and enters gates.

**Checkpoint**: Press `t` → tree overlay covers the screen → navigate with arrows → see colored gate statuses → press Enter on a gated item to open it → Esc to close.

---

## Context

The overlay renders on top of the main chat view. It fetches the tree from `GET /tree` and renders it with Ink `<Box>` and `<Text>` components. Similar to a file explorer in a terminal.

**Key files**:
- `cli/src/components/TreeOverlay.tsx` — New component
- `cli/src/hooks/useTree.ts` — New hook
- `cli/src/api/client.ts` — `getProjectTree()` (from 23.7)

**Dependencies**:
- 23.7 (CLI API client)

**Create `cli/src/components/TreeOverlay.tsx`**:

import React, { useState } from 'react';
import { Box, Text, useInput } from 'ink';
import { useTree } from '../hooks/useTree.js';

// Tree line characters
const BRANCH = '├─ ';
const LAST_BRANCH = '└─ ';
const VERTICAL = '│  ';
const SPACE = '   ';

interface TreeOverlayProps {
  onSelectGate: (gateId: string) => void;
  onClose: () => void;
}

export function TreeOverlay({ onSelectGate, onClose }: TreeOverlayProps) {
  const { flatItems, loading, toggleExpand, refresh } = useTree();
  const [selectedIndex, setSelectedIndex] = useState(0);

  useInput((input, key) => {
    if (key.escape) onClose();
    if (key.upArrow) setSelectedIndex(Math.max(0, selectedIndex - 1));
    if (key.downArrow) setSelectedIndex(Math.min(flatItems.length - 1, selectedIndex + 1));
    if (key.return) {
      const item = flatItems[selectedIndex];
      if (item?.gate && item.gate.status === 'pending') {
        onSelectGate(item.gate.id);
      } else if (item?.hasChildren) {
        toggleExpand(item.id);
      }
    }
    if (input === 's') {
      const item = flatItems[selectedIndex];
      if (item?.gate && item.gate.status === 'pending') {
        // Skip gate via API
      }
    }
  });

  // ... render bordered box with items
}

### Slice 23.8.3: Color-Coded Gate Statuses

**Do this**:
- Apply colors to gate status indicators on each tree row
- Green: resolved / completed
- Cyan: active (currently in conversation)
- Yellow: pending (waiting for user)
- Dim/gray: skipped
- White/no indicator: no gate for this item
- Status icons: ✓ resolved, ● active, ⏸ pending, ⊘ skipped

**Add gate status rendering**:
```tsx
function GateIndicator({ gate }: { gate?: Gate }) {
  if (!gate) return null;

  const config: Record<string, { icon: string; color: string }> = {
    resolved: { icon: '✓', color: 'green' },
    active:   { icon: '●', color: 'cyan' },
    pending:  { icon: '⏸', color: 'yellow' },
    skipped:  { icon: '⊘', color: 'gray' },
  };

  const { icon, color } = config[gate.status] ?? { icon: '?', color: 'white' };

  return (
    <Text color={color}> {icon} {gate.status}</Text>
  );
}
```

### Slice 23.8.4: Status Bar

**Do this**:
- Add a status bar at the bottom of the overlay showing gate counts and keyboard hints
- Format: `Pending: N │ Resolved: N │ Skipped: N`
- Below that: `↑/↓: Navigate │ Enter: Open/Expand │ s: Skip │ Esc: Close`

**Add to `TreeOverlay`**:
```tsx
function StatusBar({ items }: { items: FlatTreeItem[] }) {
  const gates = items.filter(i => i.gate).map(i => i.gate!);
  const pending = gates.filter(g => g.status === 'pending').length;
  const resolved = gates.filter(g => g.status === 'resolved').length;
  const skipped = gates.filter(g => g.status === 'skipped').length;

  return (
    <Box flexDirection="column" marginTop={1}>
      <Text>
        <Text color="yellow">Pending: {pending}</Text>
        <Text dimColor> │ </Text>
        <Text color="green">Resolved: {resolved}</Text>
        <Text dimColor> │ </Text>
        <Text dimColor>Skipped: {skipped}</Text>
      </Text>
      <Text dimColor>
        ↑/↓: Navigate │ Enter: Open/Expand │ s: Skip │ Esc: Close
      </Text>
    </Box>
  );
}
```
