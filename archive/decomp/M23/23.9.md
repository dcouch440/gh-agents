# Ticket 23.9: CLI Gate Conversation View

> Chat interface for syncing with an agent at a gate.

## Goal

When the user opens a gate from the tree, they see the agent's understanding and can have a back-and-forth conversation. They can resolve or skip the gate when done.

**Checkpoint**: Open a gate → see agent intro → send a message → get response → press `r` to resolve → return to tree.

---

## Context

The gate view is similar to the existing `ChatView` but scoped to a single gate's conversation. It reuses existing `MessageList`, `Message`, and `Input` components where possible.

**Key files**:
- `cli/src/components/GateView.tsx` — New component

- `cli/src/components/MessageList.tsx` — Existing (reuse)
- `cli/src/components/Input.tsx` — Existing (reuse)

## Slices

### Slice 23.9.1: useGate Hook

**Do this**:
- Create a hook that manages gate conversation state
- On mount: fetch gate detail and messages
- If gate is Pending (no messages yet), send an initial empty message to trigger activation + intro
- Provides: gate detail, messages, sendMessage, resolve, skip, loading states

**Create `cli/src/hooks/useGate.ts`**:
```typescript
import { useState, useEffect, useCallback } from 'react';
import { getGate, getGateMessages, sendGateMessage, updateGateStatus } from '../api/client.js';
import type { GateDetail, GateMessage } from '../api/types.js';

export function useGate(gateId: string) {
  const [gate, setGate] = useState<GateDetail | null>(null);
  const [messages, setMessages] = useState<GateMessage[]>([]);
  const [loading, setLoading] = useState(true);
  const [sending, setSending] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    loadGate();
  }, [gateId]);

  const loadGate = async () => {
    try {
      setLoading(true);
      const [detail, msgs] = await Promise.all([
        getGate(gateId),
        getGateMessages(gateId),
      ]);
      setGate(detail);
      setMessages(msgs);

      // If no messages yet, trigger activation
      if (msgs.length === 0) {
        const introResponse = await sendGateMessage(gateId, '');
        // The API activates the gate and returns the intro
        setMessages([introResponse]);
      }
    } catch (err) {
      setError(String(err));
    } finally {
      setLoading(false);
    }
  };

  const send = useCallback(async (content: string) => {
    setSending(true);
    try {
      // Optimistically add user message
      const userMsg: GateMessage = {
        id: crypto.randomUUID(),
        gate_id: gateId,
        role: 'user',
        content,
        created_at: new Date().toISOString(),
      };
      setMessages(prev => [...prev, userMsg]);

      const response = await sendGateMessage(gateId, content);
      setMessages(prev => [...prev, response]);
    } catch (err) {
      setError(String(err));
    } finally {
      setSending(false);
    }
  }, [gateId]);

  const resolve = useCallback(async () => {
    await updateGateStatus(gateId, 'resolved');
  }, [gateId]);

  const skip = useCallback(async () => {
    await updateGateStatus(gateId, 'skipped');
  }, [gateId]);

  return { gate, messages, loading, sending, error, send, resolve, skip };
}
```

**Verify**:
- [ ] Hook fetches gate + messages on mount
- [ ] Pending gate triggers activation
- [ ] Send adds user message optimistically
- [ ] Resolve/skip call API

### Slice 23.9.2: GateView Component

**Do this**:
- Create the gate conversation view component
- Show header with gate level, target title, and status
- Render messages using existing `MessageList` or similar layout
- Show input at bottom (reuse `Input` component)
- Keyboard shortcuts: `r` to resolve, `s` to skip, `Esc` to go back

**Create `cli/src/components/GateView.tsx`**:
```tsx
import React from 'react';
import { Box, Text, useInput } from 'ink';
import Spinner from 'ink-spinner';
import { useGate } from '../hooks/useGate.js';
import { Input } from './Input.js';

interface GateViewProps {
  gateId: string;
  onClose: () => void;
}

export function GateView({ gateId, onClose }: GateViewProps) {
  const { gate, messages, loading, sending, error, send, resolve, skip } = useGate(gateId);

  useInput((input, key) => {
    if (key.escape) onClose();
    // Only handle r/s when not focused on input
    // Implementation detail: may need a "command mode" flag
  });

  if (loading) {
    return <Box padding={1}><Text><Spinner type="dots" /> Loading gate...</Text></Box>;
  }

  if (!gate) {
    return <Text color="red">Gate not found</Text>;
  }

  return (
    <Box flexDirection="column" padding={1}>
      {/* Header */}
      <Box borderStyle="single" paddingX={1}>
        <Text bold color="cyan">
          Gate: {gate.target_title}
        </Text>
        <Text dimColor> ({gate.gate.level})</Text>
      </Box>

      {/* Messages */}
      <Box flexDirection="column" marginTop={1}>
        {messages.map(msg => (
          <Box key={msg.id} marginBottom={1} flexDirection="column">
            <Text bold color={msg.role === 'assistant' ? 'cyan' : undefined}>
              {msg.role === 'assistant' ? 'nexor' : 'you'}
            </Text>
            <Text>{msg.content}</Text>
          </Box>
        ))}
      </Box>

      {/* Error */}
      {error && <Text color="red">Error: {error}</Text>}

      {/* Input */}
      <Box marginTop={1}>
        <Input onSubmit={send} disabled={sending} />
      </Box>

      {/* Controls */}
      <Box marginTop={1}>
        <Text dimColor>
          r: Resolve │ s: Skip │ Esc: Back to tree
        </Text>
      </Box>
    </Box>
  );
}
```

### Slice 23.9.3: Resolve/Skip Actions

**Do this**:
- Wire up the `r` and `s` keyboard shortcuts to resolve/skip
- After resolving/skipping, call `onClose()` to return to the tree
- Handle the edge case where shortcuts should not fire while user is typing in the input
- Consider a "command mode" approach: shortcuts only work when input is empty, or use a modifier key

**Implementation approach**:
```tsx
// Option: Use Ctrl+R and Ctrl+S to avoid conflict with typing
useInput((input, key) => {
  if (key.escape) {
    onClose();
  }
  if (key.ctrl && input === 'r') {
    resolve().then(onClose);
  }
  if (key.ctrl && input === 's') {
    skip().then(onClose);
  }
});
```

Alternatively, detect when input is focused vs not. Choose whichever pattern the existing CLI uses.

**Verify**:

- [ ] Skip shortcut works and closes view
