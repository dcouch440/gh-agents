# Ticket 23.3: Gate Service

> Business logic layer for gate lifecycle management and LLM-powered conversations.

## Goal

Create a `GateService` that manages gate creation, activation, conversation (via LLM), and resolution. This is the core orchestration layer between the database, LLM provider, and API.

**Checkpoint**: Gate service can create a gate, generate an intro message from the LLM, handle a multi-turn conversation, and resolve/skip the gate.

---

## Context

The gate service sits between the API layer and the repository. It coordinates:
- Gate lifecycle (create → activate → resolve/skip)
- LLM calls for agent conversation (using the assigned agent tier's model)
- Context assembly (PRD summary + target description + parent context)

### Slice 23.3.2: Gate Activation & Intro Message

**Do this**:
- Add `activate_gate()` method that sets status to `Active` and generates an intro message via LLM
- Build the system prompt from `GateContext` — the agent should present its understanding and ask clarifying questions
- Save the assistant intro message to `gate_messages`

**Add to `src/orchestration/gates.rs`**:
```rust
impl<P: LLMProvider, R: GateRepo> GateService<P, R> {
    pub async fn activate_gate(
        &self,
        gate_id: &GateId,
        context: GateContext,
    ) -> Result<GateMessage> {
        // 1. Update gate status to Active
        self.repo.update_gate_status(gate_id, GateStatus::Active, None).await?;

        // 2. Build system prompt
        let system_prompt = self.build_gate_system_prompt(&context);

        // 3. Call LLM for intro message
        let response = self.provider.send_message(/* system_prompt, no user messages yet */).await?;

        // 4. Save assistant message
        let msg = GateMessage {
            id: Uuid::new_v4(),
            gate_id: gate_id.clone(),
            role: "assistant".to_string(),
            content: response,
            created_at: Utc::now(),
        };
        self.repo.add_gate_message(&msg).await?;

        Ok(msg)
    }

    fn build_gate_system_prompt(&self, context: &GateContext) -> String {
        let mut prompt = String::new();
        prompt.push_str("You are an agent about to begin work. ");
        prompt.push_str("Present your understanding of the task and ask any clarifying questions.\n\n");

        if let Some(ref prd) = context.prd_summary {
            prompt.push_str(&format!("## Project Context\n{}\n\n", prd));
        }
        if let Some(ref parent) = context.parent_context {
            prompt.push_str(&format!("## Parent Scope\n{}\n\n", parent));
        }
        prompt.push_str(&format!("## Your Assignment\n**{}**\n{}\n", context.target_title, context.target_description));

        prompt
    }
}
```

```rust
impl<P: LLMProvider, R: GateRepo> GateService<P, R> {
    pub async fn resolve_gate(&self, gate_id: &GateId) -> Result<()> {
        self.repo.update_gate_status(gate_id, GateStatus::Resolved, Some(Utc::now())).await
    }

    pub async fn skip_gate(&self, gate_id: &GateId) -> Result<()> {
        self.repo.update_gate_status(gate_id, GateStatus::Skipped, Some(Utc::now())).await
    }

    pub async fn is_gate_clear(&self, level: GateLevel, target_id: Uuid) -> Result<bool> {
        match self.repo.get_gate_by_target(level, target_id).await? {
            Some(gate) => Ok(gate.status.is_clear()),
            None => Ok(true), // No gate means no blocking
        }
    }
}
```
