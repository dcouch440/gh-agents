# Ticket 23.1: Database Schema & Core Types

> Migration for gates tables and Rust type definitions for the gate domain model.

## Goal

Define the database schema for gates and gate messages, and create the core Rust types that the rest of the system will use.

**Checkpoint**: Migration runs successfully against Postgres, `cargo check` passes with new gate types.

---

## Context

Gates are the foundation of the human-in-the-loop system. Each gate references a target at a specific decomposition level (milestone, slice, or task) via a polymorphic `(level, target_id)` pair. Gate messages store the conversation between the user and the agent.

**Key files**:
- `migrations/` — New migration file
- `src/types/` — New gate types module
- `src/types/config.rs` — Add gate toggle fields

**Dependencies**: None

**Do this**:
- Create migration `015_create_gates.sql`
- Define `gates` table with polymorphic target reference
- Define `gate_messages` table with FK to gates
- Add appropriate indexes

**Create `migrations/015_create_gates.sql`**:
```sql
-- Gates: sync points between decomposition and execution
CREATE TABLE IF NOT EXISTS gates (
    id UUID PRIMARY KEY,
    level TEXT NOT NULL CHECK (level IN ('milestone', 'slice', 'task')),
    target_id UUID NOT NULL,
    status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'active', 'resolved', 'skipped')),
    agent_tier TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    resolved_at TIMESTAMPTZ
);

-- Gate conversation messages
CREATE TABLE IF NOT EXISTS gate_messages (
    id UUID PRIMARY KEY,
    gate_id UUID NOT NULL REFERENCES gates(id) ON DELETE CASCADE,
    role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
    content TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_gates_level_target ON gates(level, target_id);
CREATE INDEX idx_gates_status ON gates(status);
CREATE INDEX idx_gate_messages_gate_id ON gate_messages(gate_id);
CREATE INDEX idx_gate_messages_created ON gate_messages(gate_id, created_at);
```

### Slice 23.1.2: Core Gate Types

- Add `Display` impl for `GateLevel` and `GateStatus` (for DB serialization)

**Create `src/types/gate.rs`**:
```rust
use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use uuid::Uuid;

use super::AgentTier;

#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct GateId(pub Uuid);

impl GateId {
    pub fn new() -> Self {
        Self(Uuid::new_v4())
    }
}

impl std::fmt::Display for GateId {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "{}", self.0)
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum GateLevel {
    Milestone,
    Slice,
    Task,
}

impl std::fmt::Display for GateLevel {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            GateLevel::Milestone => write!(f, "milestone"),
            GateLevel::Slice => write!(f, "slice"),
            GateLevel::Task => write!(f, "task"),
        }
    }
}

impl std::str::FromStr for GateLevel {
    type Err = anyhow::Error;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s {
            "milestone" => Ok(GateLevel::Milestone),
            "slice" => Ok(GateLevel::Slice),
            "task" => Ok(GateLevel::Task),
            _ => Err(anyhow::anyhow!("invalid gate level: {}", s)),
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum GateStatus {
    Pending,
    Active,
    Resolved,
    Skipped,
}

impl std::fmt::Display for GateStatus {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            GateStatus::Pending => write!(f, "pending"),
            GateStatus::Active => write!(f, "active"),
            GateStatus::Resolved => write!(f, "resolved"),
            GateStatus::Skipped => write!(f, "skipped"),
        }
    }
}

impl std::str::FromStr for GateStatus {
    type Err = anyhow::Error;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s {
            "pending" => Ok(GateStatus::Pending),
            "active" => Ok(GateStatus::Active),
            "resolved" => Ok(GateStatus::Resolved),
            "skipped" => Ok(GateStatus::Skipped),
            _ => Err(anyhow::anyhow!("invalid gate status: {}", s)),
        }
    }
}

impl GateStatus {
    /// Whether this gate is no longer blocking work
    pub fn is_clear(&self) -> bool {
        matches!(self, GateStatus::Resolved | GateStatus::Skipped)
    }
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Gate {
    pub id: GateId,
    pub level: GateLevel,
    pub target_id: Uuid,
    pub status: GateStatus,
    pub agent_tier: AgentTier,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    pub resolved_at: Option<DateTime<Utc>>,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct GateMessage {
    pub id: Uuid,
    pub gate_id: GateId,
    pub role: String,
    pub content: String,
    pub created_at: DateTime<Utc>,
}

/// Context bundle passed to the LLM when generating gate conversation
#[derive(Debug, Clone)]
pub struct GateContext {
    pub prd_summary: Option<String>,
    pub target_title: String,
    pub target_description: String,
    pub parent_context: Option<String>,
}
```
