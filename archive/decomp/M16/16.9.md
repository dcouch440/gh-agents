# Ticket 16.9: Onboarding Wizard

> Sign up → connect GitHub → import repos → invite team → start working. Under 2 minutes.

## Goal

A new user goes from landing on nexor.io to working on their first project in under 2 minutes. The wizard guides them through every step with the ability to skip and complete later.

**Checkpoint**: New user clicks "Sign in with GitHub" → auto-creates account → sees repos → imports one → invites a teammate → lands in the workspace with the repo loaded.

---

## Context

Combines auth (16.2/16.3), repo import (16.4), and invitations (16.2) into a single streamlined flow.

**Key files**:
- `ui/src/pages/` — Onboarding wizard pages
- `ui/src/components/` — Wizard components

**Dependencies**:
- Requires 16.2 (Users/Orgs), 16.3 (GitHub OAuth), 16.4 (Cloud repos)
