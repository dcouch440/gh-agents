# Ticket 12.3: Auth Flow

> Login prompt and token persistence for the terminal CLI.

## Goal

User can authenticate with the backend on first run. Token is saved to disk and reused on subsequent runs. Expired tokens trigger re-login.

**Checkpoint**: Run CLI → prompted for password → token saved → next run skips login.

---

## Context

The backend uses JWT authentication. The React UI stores tokens in localStorage. The CLI needs to persist tokens to the filesystem instead.

**Key files**:
- `cli/src/api/client.ts` - API client (from 12.2)
- `src/server/auth.rs` - Backend auth logic

**Dependencies**:
- 12.2 (API client)

---

## Slices

### Slice 12.3.1: Token Storage

**Do this**:
- Use the `conf` package to persist the JWT token and server URL to disk
- Store in the OS-standard config directory (`~/.config/nexor-cli/` on Linux/macOS)

**Create `cli/src/store/auth.ts`**:
```typescript
import Conf from 'conf';

interface AuthConfig {
  token: string | null;
  tokenExpiry: number | null;
  serverUrl: string;
}

// Methods:
// getToken() → string | null
// setToken(token: string, expiresIn: number) → void
// clearToken() → void
// isTokenExpired() → boolean
// getServerUrl() → string
// setServerUrl(url: string) → void
```

Default server URL: `http://localhost:3000`

**Verify**:
- [ ] `npx tsc --noEmit` passes
