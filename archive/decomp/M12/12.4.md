# Ticket 12.4: Chat UI Components

> Core chat interface components rendered in the terminal with Ink.

## Goal

A Claude Code-style chat interface: conversation history scrolling above, input at the bottom, flat turn-based message layout.

**Checkpoint**: Can see message history and type new messages in a terminal UI that looks like Claude Code.

---

## Context

This is the main UI. It should feel like Claude Code — not a chatbot. Flat layout, role labels, monospace output, no bubbles or avatars.

**Key files**:
- `cli/src/App.tsx` - Root component (from 12.3)
- `cli/src/api/client.ts` - API client (from 12.2)

**Dependencies**:
- 12.3 (auth flow, so we're authenticated)

---
