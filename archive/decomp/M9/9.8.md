# Ticket 9.8: Refactor Agent

> Agent implementation for handling refactor conversations and changes.

## Overview

Create the refactor agent that:
- Converses with users to understand desired changes
- Detects intent from user messages
- Proposes changes to planning files
- Applies approved changes to the filesystem

## Slices

### Slice 9.8.1: Refactor Persona Prompt

**Goal**: Create specialized prompts for the refactor agent

**Files**:
- `src/prompts/templates/refactor.rs` - New file
- `src/prompts/templates/mod.rs` - Export refactor module

**Prompts**:
- `conversation()` - Main conversation prompt with intent detection
- `propose_changes()` - Generate change proposals
- `analyze_impact()` - Analyze impact on in-progress work

**Constants**:
- `REFACTOR_ROLE` - Agent persona description
- `INTENT_DETECTION` - Guidelines for detecting user intent
- `HALT_GUIDELINES` - When to halt production
- `CHANGE_GUIDELINES` - How to propose changes
- Output schemas for all prompts

**Verify**: Unit tests pass

### Slice 9.8.2: Agent with Intent Detection

**Goal**: Implement the refactor agent with intent analysis

**Files**:
- `src/refactor/mod.rs` - New module
- `src/refactor/agent.rs` - Agent implementation
- `src/lib.rs` - Export refactor module

**Types**:
- `IntentAnalysis` - Result of intent detection
- `Confidence` - Low, Medium, High
- `ProposedChange`, `ChangeProposal` - Change proposal structures
- `ImpactAnalysis`, `ImpactSeverity`, `ImpactRecommendation`

**Methods**:
- `new()`, `start_session()` - Agent creation
- `analyze_intent_simple()` - Rule-based intent detection
- `build_intent_prompt()` - Build LLM prompt

**Verify**: Unit tests pass

### Slice 9.8.3: Change Proposal Generation

**Goal**: Add ability to propose changes

**Files**:
- `src/refactor/agent.rs` - Extend agent

**Methods**:
- `halt_production()` - Pause the scheduler
- `add_proposed_change()` - Add change to session
- `approve_change()` - Mark change as approved
- `get_context()` - Get current refactor context

**Verify**: Unit tests pass

### Slice 9.8.4: Change Application Logic

**Goal**: Apply approved changes to filesystem

**Files**:
- `src/refactor/agent.rs` - Extend agent

**Methods**:
- `apply_changes()` - Write approved changes to files
- `end_session()` - End session and resume production

**Handles**:
- Create new files
- Modify existing files
- Delete files
- Rename/move files

**Verify**: Integration test - create, apply, verify file changes
