# Ticket 9.2: Headless Mode

> Non-interactive operation for CI/CD and automation.

## Goal

Add headless mode that allows nexor to run without TUI:
- Accept tasks from command line or file
- Output progress to stdout or file
- Exit when work complete
- Enable CI/CD integration and scripting

**Checkpoint**: Can run `nexor --headless --task "implement feature X"` and see output in terminal.

---

## Context

Headless mode is essential for automation. CI/CD pipelines, cron jobs, and scripts need to invoke nexor without interactive terminal access.

**Key files**:
- `src/cli.rs` - CLI argument parsing (create)
- `src/headless.rs` - Headless mode runner (create)
- `src/main.rs` - Route to headless vs TUI mode (modify)

**Dependencies**:
- Requires M5 (Orchestration Core) for task processing
- Uses clap for CLI argument parsing

**References**:
- See `ROADMAP.md` Ticket 9.2 for spec

```rust
// src/cli.rs
use clap::Parser;
use std::path::PathBuf;

#[derive(Parser, Debug)]
#[command(name = "nexor")]
#[command(author, version, about = "AI Agent Orchestration TUI")]
pub struct Args {
    /// Run in headless mode (no TUI)
    #[arg(short = 'H', long)]
    pub headless: bool,

    /// Task description to process (headless mode)
    #[arg(short, long)]
    pub task: Option<String>,

    /// Read task(s) from file (headless mode)
    #[arg(short, long)]
    pub input: Option<PathBuf>,

    /// Write output to file instead of stdout (headless mode)
    #[arg(short, long)]
    pub output: Option<PathBuf>,

    /// Override config file location
    #[arg(short, long)]
    pub config: Option<PathBuf>,

    /// Increase log verbosity (-v, -vv, -vvv)
    #[arg(short, long, action = clap::ArgAction::Count)]
    pub verbose: u8,

    /// GitHub issue URL to sync and work on
    #[arg(long)]
    pub sync: Option<String>,
}

impl Args {
    pub fn parse_args() -> Self {
        Self::parse()
    }

    pub fn validate(&self) -> Result<(), String> {
        if self.headless {
            // In headless mode, need either --task, --input, or --sync
            if self.task.is_none() && self.input.is_none() && self.sync.is_none() {
                return Err(
                    "headless mode requires --task, --input, or --sync".to_string()
                );
            }
        }

        if self.input.is_some() && !self.headless {
            return Err("--input requires --headless mode".to_string());
        }

        Ok(())
    }

    pub fn log_level(&self) -> tracing::Level {
        match self.verbose {
            0 => tracing::Level::INFO,
            1 => tracing::Level::DEBUG,
            _ => tracing::Level::TRACE,
        }
    }
}

#[cfg(test)]
mod tests {

        let args = Args {
            headless: true,
            task: None,

    #[test]

            headless: true,

            input: None,
            output: None,
            config: None,
            verbose: 0,
            sync: None,
        };
        assert!(args.validate().is_ok());
    }
}
```

**Do this**:
- Update `src/main.rs` to check `args.headless`
- If headless, skip terminal initialization
- If not headless, proceed with normal TUI startup
- Initialize only required components for headless (no ratatui)

**Create/modify**:
- `src/main.rs`

**Code example**:
```rust
// src/main.rs
use nexor::cli::Args;
use nexor::headless::HeadlessRunner;
use nexor::tui::{app::{App, init_terminal, restore_terminal, install_panic_hook}};
use anyhow::Result;

#[tokio::main]
async fn main() -> Result<()> {
    let args = Args::parse_args();

    if let Err(e) = args.validate() {
        eprintln!("Error: {}", e);
        std::process::exit(1);
    }

    // Set up logging based on verbosity
    let log_level = args.log_level();
    // ... tracing setup with log_level ...

    if args.headless {
        // Headless mode - no TUI
        let runner = HeadlessRunner::new(args)?;
        runner.run().await?;
    } else {
        // Interactive TUI mode
        install_panic_hook();
        let mut terminal = init_terminal()?;
        let mut app = App::new();

        let result = app.run(&mut terminal);

        restore_terminal(&mut terminal)?;
        result?;
    }

    Ok(())
}
```

```rust
// src/headless.rs
use crate::cli::Args;
use anyhow::{Context, Result};
use std::fs::File;
use std::io::{self, Write, BufWriter};
use std::path::PathBuf;
use tokio::sync::mpsc;

pub struct HeadlessRunner {
    args: Args,
    output: Box<dyn Write + Send>,
}

impl HeadlessRunner {
    pub fn new(args: Args) -> Result<Self> {
        let output: Box<dyn Write + Send> = match &args.output {
            Some(path) => {
                let file = File::create(path)
                    .context(format!("failed to create output file: {:?}", path))?;
                Box::new(BufWriter::new(file))
            }
            None => Box::new(io::stdout()),
        };

        Ok(Self { args, output })
    }

    fn write_line(&mut self, line: &str) -> Result<()> {
        writeln!(self.output, "{}", line)?;
        self.output.flush()?;
        Ok(())
    }

    fn write_progress(&mut self, message: &str) -> Result<()> {
        self.write_line(&format!("[PROGRESS] {}", message))
    }

    fn write_error(&mut self, message: &str) -> Result<()> {
        self.write_line(&format!("[ERROR] {}", message))
    }

    fn write_result(&mut self, status: &str, details: &str) -> Result<()> {
        self.write_line(&format!("[RESULT] {} - {}", status, details))
    }

    pub async fn run(mut self) -> Result<()> {
        self.write_line("nexor headless mode starting...")?;

        // Determine task source
        let task_description = if let Some(ref task) = self.args.task {
            task.clone()

            std::fs::read_to_string(input_path)
                .context("failed to read input file")?

            // Sync from GitHub and use issue as task
            self.write_progress(&format!("Syncing issue: {}", url))?;
            // ... sync logic ...
            format!("Work on synced issue: {}", url)
        } else {
            anyhow::bail!("no task specified");
        };

        self.write_progress(&format!("Task: {}", task_description))?;

        // Initialize orchestration (without TUI)
        // ... setup orchestrator, agent pool, etc ...

        // Process task

        // ... orchestration logic ...

        // For now, placeholder

        self.write_result("SUCCESS", "Task completed")?;

        Ok(())
    }
}
```

### Slice 9.2.4: Task Input from File

**Do this**:
- Support reading task from `--input` file
- Support multiple tasks in file (one per line or YAML/JSON format)
- Process tasks sequentially
- Report per-task results
- Exit with non-zero status if any task fails

**Create/modify**:
- `src/headless.rs` - add file input parsing

**Code example**:
```rust
// src/headless.rs - add input file handling
use serde::Deserialize;

#[derive(Debug, Deserialize)]
pub struct TaskInput {
    pub description: String,
    pub priority: Option<String>,
    pub github_issue: Option<String>,
}

impl HeadlessRunner {
    fn parse_input_file(path: &PathBuf) -> Result<Vec<TaskInput>> {
        let content = std::fs::read_to_string(path)
            .context("failed to read input file")?;

        // Try JSON array first
        if let Ok(tasks) = serde_json::from_str::<Vec<TaskInput>>(&content) {
            return Ok(tasks);
        }

        // Try YAML
        if let Ok(tasks) = serde_yaml::from_str::<Vec<TaskInput>>(&content) {
            return Ok(tasks);
        }

        // Fall back to line-by-line plain text
        let tasks = content
            .lines()
            .filter(|line| !line.trim().is_empty())
            .filter(|line| !line.starts_with('#'))  // Skip comments
            .map(|line| TaskInput {
                description: line.trim().to_string(),
                priority: None,
                github_issue: None,
            })
            .collect();

        Ok(tasks)
    }

    pub async fn run(mut self) -> Result<()> {
        self.write_line("nexor headless mode starting...")?;

        let tasks: Vec<TaskInput> = if let Some(ref input_path) = self.args.input {
            Self::parse_input_file(input_path)?
        } else if let Some(ref task) = self.args.task {
            vec![TaskInput {
                description: task.clone(),
                priority: None,
                github_issue: None,
            }]
        } else if let Some(ref url) = self.args.sync {
            vec![TaskInput {
                description: format!("Work on: {}", url),
                priority: None,
                github_issue: Some(url.clone()),
            }]
        } else {
            anyhow::bail!("no task specified");
        };

        self.write_line(&format!("Processing {} task(s)...", tasks.len()))?;

        let mut failed = 0;
        for (i, task) in tasks.iter().enumerate() {
            self.write_line(&format!("\n--- Task {}/{} ---", i + 1, tasks.len()))?;
            self.write_progress(&format!("Task: {}", task.description))?;

            match self.process_task(task).await {
                Ok(_) => {
                    self.write_result("SUCCESS", &task.description)?;
                }
                Err(e) => {
                    self.write_error(&format!("{}", e))?;
                    self.write_result("FAILED", &task.description)?;
                    failed += 1;
                }
            }
        }

        self.write_line(&format!(
            "\n=== Summary: {}/{} tasks completed successfully ===",
            tasks.len() - failed,
            tasks.len()
        ))?;

        if failed > 0 {
            std::process::exit(1);
        }

        Ok(())
    }

    async fn process_task(&mut self, task: &TaskInput) -> Result<()> {
        // ... actual task processing ...

        self.write_progress("Assigning to agents...")?;
        self.write_progress("Executing...")?;
        // Placeholder for now
        Ok(())
    }
}
```

## Notes

- **Exit codes**: 0 = all tasks succeeded, 1 = one or more failed
- **Verbosity**: `-v` adds debug logs, `-vv` adds trace logs
- **Compatibility**: Headless mode should work in CI environments (no TTY)

- **JSON output**: Could add `--json` flag for machine-readable output
- **Progress format**: Prefix format allows easy parsing/grep
