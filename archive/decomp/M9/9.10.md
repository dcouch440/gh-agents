### Slice 9.10.1: Menu Types

**Do this**:
- Create `src/tui/menu/mod.rs` with module exports
- Create `src/tui/menu/types.rs` with all menu types

**Types to define**:
```rust
/// A menu item that can be selected
pub struct MenuItem {
    pub id: String,
    pub label: String,
    pub shortcut: Option<char>,
    pub item_type: MenuItemType,
    pub enabled: bool,
}

pub enum MenuItemType {
    Action(MenuAction),
    Submenu(String),  // Opens menu by id
    Separator,
    Back,
}

pub enum MenuAction {
    // Production
    StartProduction,
    PauseProduction,
    SetMilestoneLimit(u8),  // M1-M9
    ClearMilestoneLimit,

    // Refactor
    ExitRefactorMode,
    CancelRefactor,
    ApplyChanges,
    DiscardChanges,
    ReviewChanges,

    // Navigation
    GoToView(View),

    // App
    OpenSettings,
    Quit,
}

/// Menu definition
pub struct Menu {
    pub id: String,
    pub title: String,
    pub items: Vec<MenuItem>,
}

/// Menu state during interaction
pub struct MenuState {
    pub stack: Vec<String>,  // Menu id stack for back navigation
    pub selected_index: usize,
    pub is_open: bool,
}

/// Status info for menu header display
pub struct MenuStatus {
    pub production_state: String,
    pub current_milestone: String,
    pub pending_changes: usize,
}
```
