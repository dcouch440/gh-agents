# Ticket 9.6: Observability & Replay

> Debug why agents made specific decisions.

## Goal

Add observability features that allow:
- Viewing full prompt/response for any LLM call
- Replaying agent decision sequences
- Tracing why orchestrator chose specific decompositions
- Exporting sessions for analysis
- Understanding cost per decision

**Checkpoint**: Can run `/replay <task_id>` and see exactly what the agent was thinking.

---

## Context

When agents make unexpected decisions, we need to understand why. This requires logging all LLM interactions and providing tools to review them.

**Key files**:
- `src/observability/mod.rs` - Module root (create)
- `src/observability/logging.rs` - LLM call logging (create)
- `src/observability/replay.rs` - Decision replay (create)
- `src/observability/export.rs` - Session export (create)

**Dependencies**:
- Requires M2 (LLM Layer) for LLM call interception
- Requires M5 (Orchestration Core) for task tracking

**References**:
- See `ROADMAP.md` Ticket 9.6 for spec

// src/observability/mod.rs
pub mod logging;
pub mod replay;
pub mod export;

pub use logging::LlmCallLogger;
pub use replay::DecisionReplay;

// src/observability/logging.rs
use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use sqlx::SqlitePool;
use uuid::Uuid;
use anyhow::Result;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LlmCall {
    pub id: Uuid,
    pub task_id: Option<Uuid>,
    pub agent_id: Option<String>,
    pub model: String,
    pub prompt: LlmPrompt,
    pub response: String,
    pub input_tokens: u32,
    pub output_tokens: u32,
    pub latency_ms: u64,
    pub timestamp: DateTime<Utc>,
    pub cost_usd: f64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LlmPrompt {
    pub system: String,
    pub messages: Vec<PromptMessage>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PromptMessage {
    pub role: String,  // "user" or "assistant"
    pub content: String,
}

pub struct LlmCallLogger {
    pool: SqlitePool,
}

impl LlmCallLogger {
    pub fn new(pool: SqlitePool) -> Self {
        Self { pool }
    }

    pub async fn log_call(&self, call: &LlmCall) -> Result<()> {
        let prompt_json = serde_json::to_string(&call.prompt)?;

        sqlx::query!(
            r#"
            INSERT INTO llm_calls (
                id, task_id, agent_id, model, prompt, response,
                input_tokens, output_tokens, latency_ms, timestamp, cost_usd
            )
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            "#,
            call.id.to_string(),
            call.task_id.map(|u| u.to_string()),
            call.agent_id,
            call.model,
            prompt_json,
            call.response,
            call.input_tokens,
            call.output_tokens,
            call.latency_ms,
            call.timestamp.to_rfc3339(),
            call.cost_usd,
        )
        .execute(&self.pool)
        .await?;

        Ok(())
    }

    pub async fn get_calls_for_task(&self, task_id: Uuid) -> Result<Vec<LlmCall>> {
        let rows = sqlx::query!(
            r#"
            SELECT * FROM llm_calls
            WHERE task_id = ?
            ORDER BY timestamp ASC
            "#,
            task_id.to_string()
        )
        .fetch_all(&self.pool)
        .await?;

        rows.into_iter().map(|row| {
            Ok(LlmCall {
                id: Uuid::parse_str(&row.id)?,
                task_id: row.task_id.map(|s| Uuid::parse_str(&s)).transpose()?,
                agent_id: row.agent_id,
                model: row.model,
                prompt: serde_json::from_str(&row.prompt)?,
                response: row.response,
                input_tokens: row.input_tokens as u32,
                output_tokens: row.output_tokens as u32,
                latency_ms: row.latency_ms as u64,
                timestamp: DateTime::parse_from_rfc3339(&row.timestamp)?.with_timezone(&Utc),
                cost_usd: row.cost_usd,
            })
        }).collect()
    }
}
```

// src/observability/replay.rs
use crate::observability::logging::{LlmCall, LlmCallLogger};
use uuid::Uuid;
use anyhow::Result;

pub struct DecisionReplay {
    logger: LlmCallLogger,
}

impl DecisionReplay {
    pub fn new(logger: LlmCallLogger) -> Self {
        Self { logger }
    }

    pub async fn get_task_timeline(&self, task_id: Uuid) -> Result<TaskTimeline> {
        let calls = self.logger.get_calls_for_task(task_id).await?;

        let total_cost: f64 = calls.iter().map(|c| c.cost_usd).sum();
        let total_tokens: u32 = calls.iter().map(|c| c.input_tokens + c.output_tokens).sum();

        Ok(TaskTimeline {
            task_id,
            calls,
            total_cost,
            total_tokens,
        })
    }
}

pub struct TaskTimeline {

// src/tui/views/replay.rs
use ratatui::{
    buffer::Buffer,
    layout::{Constraint, Direction, Layout, Rect},
    style::{Color, Modifier, Style},
    text::{Line, Span},
    widgets::{Block, Borders, Paragraph, Widget, Wrap},
};
use crate::observability::logging::LlmCall;

pub struct ReplayView {
    pub calls: Vec<LlmCall>,
    pub selected_index: usize,
    pub scroll_offset: usize,
    pub show_full_prompt: bool,
}

impl Default for ReplayView {
    fn default() -> Self {
        Self {
            calls: Vec::new(),
            selected_index: 0,
            scroll_offset: 0,
            show_full_prompt: false,
        }
    }
}

impl ReplayView {
    pub fn select_next(&mut self) {
        if self.selected_index < self.calls.len().saturating_sub(1) {
            self.selected_index += 1;
        }
    }

    pub fn select_prev(&mut self) {
        self.selected_index = self.selected_index.saturating_sub(1);
    }

    pub fn toggle_full_prompt(&mut self) {
        self.show_full_prompt = !self.show_full_prompt;
    }
}

impl Widget for ReplayView {
    fn render(self, area: Rect, buf: &mut Buffer) {
        if self.calls.is_empty() {
            buf.set_string(
                area.x + 2,
                area.y + 2,
                "No LLM calls found for this task.",
                Style::default().fg(Color::DarkGray),
            );
            return;
        }

        // Split into timeline (left) and detail (right)
        let chunks = Layout::default()
            .direction(Direction::Horizontal)
            .constraints([
                Constraint::Percentage(30),
                Constraint::Percentage(70),
            ])
            .split(area);

        // Timeline (left panel)
        let mut y = chunks[0].y;
        buf.set_string(
            chunks[0].x,
            y,
            "Timeline (↑↓ navigate, Enter expand)",
            Style::default().add_modifier(Modifier::BOLD),
        );
        y += 2;

        for (i, call) in self.calls.iter().enumerate() {
            if y >= chunks[0].bottom() {
                break;
            }

            let style = if i == self.selected_index {
                Style::default().bg(Color::DarkGray)
            } else {
                Style::default()
            };

            let time = call.timestamp.format("%H:%M:%S").to_string();
            let line = format!(
                "{} {} ${:.4}",
                time,
                call.model.split('/').last().unwrap_or(&call.model),
                call.cost_usd
            );
            buf.set_string(chunks[0].x, y, &line, style);
            y += 1;
        }

        // Detail (right panel)
        if let Some(call) = self.calls.get(self.selected_index) {
            let mut detail_y = chunks[1].y;

            // Header
            let header = format!(
                "Call {} | {} | {} in / {} out tokens | ${:.4}",
                self.selected_index + 1,
                call.model,
                call.input_tokens,
                call.output_tokens,
                call.cost_usd
            );
            buf.set_string(
                chunks[1].x,
                detail_y,
                &header,
                Style::default().add_modifier(Modifier::BOLD),
            );
            detail_y += 2;

            // Prompt summary or full
            buf.set_string(
                chunks[1].x,
                detail_y,
                "PROMPT:",
                Style::default().fg(Color::Cyan),
            );
            detail_y += 1;

            let prompt_preview = if self.show_full_prompt {
                call.prompt.system.clone()
            } else {
                let preview = &call.prompt.system[..call.prompt.system.len().min(200)];
                format!("{}...", preview)
            };

            for line in prompt_preview.lines().take(10) {
                if detail_y >= chunks[1].bottom() - 5 {
                    break;
                }
                buf.set_string(chunks[1].x + 2, detail_y, line, Style::default());
                detail_y += 1;
            }

            detail_y += 1;

            // Response
            buf.set_string(
                chunks[1].x,
                detail_y,
                "RESPONSE:",
                Style::default().fg(Color::Green),
            );
            detail_y += 1;

            let response_preview = &call.response[..call.response.len().min(500)];
            for line in response_preview.lines().take(15) {
                if detail_y >= chunks[1].bottom() {
                    break;
                }
                buf.set_string(chunks[1].x + 2, detail_y, line, Style::default());
                detail_y += 1;
            }
        }
    }
}
```

// src/observability/export.rs
use crate::observability::logging::{LlmCall, Decision};
use crate::types::{Task, Ticket};
use chrono::{DateTime, Utc};
use serde::Serialize;
use std::path::PathBuf;
use anyhow::Result;

#[derive(Debug, Serialize)]
pub struct SessionExport {
    pub version: String,
    pub exported_at: DateTime<Utc>,
    pub time_range: TimeRange,
    pub summary: ExportSummary,
    pub tickets: Vec<Ticket>,
    pub tasks: Vec<Task>,
    pub llm_calls: Vec<LlmCall>,
    pub decisions: Vec<Decision>,
}

#[derive(Debug, Serialize)]
pub struct TimeRange {
    pub start: DateTime<Utc>,
    pub end: DateTime<Utc>,
}

#[derive(Debug, Serialize)]
pub struct ExportSummary {
    pub total_tickets: usize,
    pub total_tasks: usize,
    pub total_llm_calls: usize,
    pub total_tokens: u32,
    pub total_cost_usd: f64,
}

pub struct SessionExporter {
    pool: SqlitePool,
}

impl SessionExporter {
    pub fn new(pool: SqlitePool) -> Self {
        Self { pool }
    }

    pub async fn export(
        &self,
        start: Option<DateTime<Utc>>,
        end: Option<DateTime<Utc>>,
        task_id: Option<Uuid>,
    ) -> Result<SessionExport> {
        let start = start.unwrap_or_else(|| Utc::now() - chrono::Duration::hours(24));
        let end = end.unwrap_or_else(Utc::now);

        // Fetch all relevant data
        let llm_calls = self.fetch_llm_calls(start, end, task_id).await?;
        let decisions = self.fetch_decisions(start, end, task_id).await?;
        let tasks = self.fetch_tasks(start, end, task_id).await?;
        let tickets = self.fetch_tickets(&tasks).await?;

        let total_tokens: u32 = llm_calls.iter()
            .map(|c| c.input_tokens + c.output_tokens)
            .sum();
        let total_cost: f64 = llm_calls.iter().map(|c| c.cost_usd).sum();

        Ok(SessionExport {
            version: env!("CARGO_PKG_VERSION").to_string(),
            exported_at: Utc::now(),
            time_range: TimeRange { start, end },
            summary: ExportSummary {
                total_tickets: tickets.len(),
                total_tasks: tasks.len(),
                total_llm_calls: llm_calls.len(),
                total_tokens,
                total_cost_usd: total_cost,
            },
            tickets,
            tasks,
            llm_calls,
            decisions,
        })
    }

    pub async fn export_to_file(&self, path: &PathBuf, ...) -> Result<()> {
        let export = self.export(...).await?;
        let json = serde_json::to_string_pretty(&export)?;
        std::fs::write(path, json)?;
        Ok(())
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Decision {
    // ... existing fields ...
    pub cost_usd: f64,  // Total cost of LLM calls for this decision
}

impl LlmCallLogger {
    pub async fn calculate_decision_cost(&self, decision_id: Uuid) -> Result<f64> {
        // Sum costs of all LLM calls associated with this decision
        let result = sqlx::query!(
            r#"
            SELECT COALESCE(SUM(cost_usd), 0.0) as total
            FROM llm_calls
            WHERE id IN (
                SELECT llm_call_id FROM decisions WHERE id = ?
            )
            "#,
            decision_id.to_string()
        )
        .fetch_one(&self.pool)
        .await?;

        Ok(result.total)
    }
}

## Notes

- **Storage growth**: LLM calls can be large. Consider retention policy (e.g., 7 days)

- **Decision extraction**: May need to parse structured output to find "thinking" section
