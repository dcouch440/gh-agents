### Slice 1.1.1: Create Cargo.toml with Dependencies

**Do this**:
- Create `Cargo.toml` in project root
- Add workspace configuration
- Add all core dependencies with versions:
  - `tokio` (full features, async runtime)
  - `ratatui` (TUI framework)
  - `crossterm` (terminal backend)
  - `sqlx` (SQLite, runtime-tokio, macros)
  - `serde` (derive feature)
  - `serde_json`
  - `toml` (config parsing)
  - `uuid` (v4, serde features)
  - `chrono` (serde feature)
  - `tracing` (logging)
  - `tracing-subscriber` (env-filter feature)
  - `tracing-appender` (file logging)
  - `thiserror` (error types)
  - `anyhow` (error handling)
  - `reqwest` (rustls-tls, json features)

**Create/modify**:
- `Cargo.toml`

**Verify**:
- [ ] File exists at project root
- [ ] `cargo check` passes (will warn about missing src/main.rs, that's ok)

**Code**:
```toml
[package]
name = "nexor"
version = "0.1.0"
edition = "2021"
authors = ["Your Name"]
description = "AI Agent Orchestration TUI for GitHub Workflows"

[dependencies]
# Async runtime
tokio = { version = "1", features = ["full"] }

# TUI
ratatui = "0.28"
crossterm = "0.28"

# Database
sqlx = { version = "0.8", features = ["runtime-tokio", "sqlite", "macros"] }

# Serialization
serde = { version = "1", features = ["derive"] }
serde_json = "1"
toml = "0.8"

# Utilities
uuid = { version = "1", features = ["v4", "serde"] }
chrono = { version = "0.4", features = ["serde"] }

# Logging
tracing = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter"] }
tracing-appender = "0.2"

# Error handling
thiserror = "1"
anyhow = "1"

# HTTP client (for LLM APIs)
reqwest = { version = "0.12", features = ["rustls-tls", "json", "stream"] }
```
