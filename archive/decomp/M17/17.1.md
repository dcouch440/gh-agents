# Ticket 17.1: Infrastructure & Dependencies

> Set up Docker Compose Postgres service, update Cargo.toml sqlx features, and add config support for DATABASE_URL.

## Goal

Postgres runs locally via Docker Compose, sqlx is configured for Postgres in Cargo.toml, and the config system reads `DATABASE_URL`.

**Checkpoint**: `docker compose up -d postgres` starts a healthy Postgres instance, `cargo check` passes with new sqlx features.

---

## Context

This is the foundation ticket. Everything else depends on Postgres being available and sqlx being configured for the Postgres driver.

**Key files**:
- `docker-compose.yml` — Add Postgres service
- `Cargo.toml` — Change sqlx features from sqlite to postgres
- `src/config/mod.rs` — Add `database_url` config field
- `.env.example` — Add DATABASE_URL template

**Dependencies**: None

---

## Slices

### Slice 17.1.1: Docker Compose Postgres Service

**Do this**:
- Add a `postgres` service to `docker-compose.yml`
- Use `postgres:16-alpine` image
- Set `POSTGRES_USER=nexor`, `POSTGRES_PASSWORD=nexor`, `POSTGRES_DB=nexor`
- Add health check: `pg_isready -U nexor`
- Expose port 5432
- Add a named volume for data persistence

**Add to `docker-compose.yml`**:
```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: nexor
      POSTGRES_PASSWORD: nexor
      POSTGRES_DB: nexor
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U nexor"]
      interval: 5s
      timeout: 5s
      retries: 5

volumes:
  pgdata:
```

**Verify**:
- [ ] `docker compose up -d postgres` starts successfully
- [ ] `docker compose exec postgres psql -U nexor -c 'SELECT 1'` returns 1
