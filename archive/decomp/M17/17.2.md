# Ticket 17.2: Migration Files Rewrite

> Rewrite all 14 SQLite migration files as PostgreSQL DDL for use with `sqlx::migrate!`.

## Goal

All migration files use Postgres-native types and syntax. The `sqlx::migrate!` macro can apply them to a fresh Postgres database.

**Checkpoint**: `sqlx migrate run` applies all migrations to a clean Postgres database without errors.

---

## Context

The existing migrations use SQLite syntax: `TEXT` for UUIDs/timestamps/JSON, `INTEGER` for booleans, `datetime('now')` for defaults, and `?` for parameters. All must be converted to Postgres equivalents.

**Key files**:
- `migrations/*.sql` — All 14 migration files

**Dependencies**: 17.1 (Postgres must be running)

**Type mapping**:
| SQLite | Postgres |
|--------|----------|
| `TEXT` (UUID) | `UUID` |
| `TEXT` (timestamp) | `TIMESTAMPTZ` |
| `INTEGER` (boolean) | `BOOLEAN` |
| `TEXT` (JSON) | `JSONB` |
| `datetime('now')` | `NOW()` |
| `AUTOINCREMENT` | `GENERATED ALWAYS AS IDENTITY` or `SERIAL` |
