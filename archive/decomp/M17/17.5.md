# Ticket 17.5: Query Rewrites — Refactor & PRD

> Rewrite SQL queries in `db/refactor.rs` and `db/prd.rs` for Postgres syntax and native types.

## Goal

All queries in the refactor and PRD database modules use Postgres syntax with native types.

**Checkpoint**: `cargo check` passes for `db/refactor.rs` and `db/prd.rs`.

---

## Context

These modules were added in M9 (refactor mode) and contain their own query functions separate from the main `queries.rs`. Same conversion rules apply.

**Key files**:
- `src/db/refactor.rs` — Refactor mode queries
- `src/db/prd.rs` — PRD-related queries

**Dependencies**: 17.3 (PgPool must be available)

**Note**: This ticket can run in parallel with 17.4.

---

## Slices

### Slice 17.5.1: Refactor Queries — CRUD

**Do this**:
- Rewrite refactor session/proposal/change CRUD queries
- Convert `?` to `$1, $2, ...`
- Update row structs to native types (UUID, TIMESTAMPTZ, BOOLEAN, JSONB)
- Remove string parsing helpers

**Verify**:
- [ ] All refactor CRUD queries compile
- [ ] Row structs use native types

---

### Slice 17.5.2: Refactor Queries — Status & History

**Do this**:
- Rewrite status tracking, history, and listing queries
- Convert any `datetime('now')` to `NOW()`
- Update ordering/filtering queries

**Verify**:
- [ ] Status and history queries compile
- [ ] Ordering by timestamp works with TIMESTAMPTZ

---

### Slice 17.5.3: PRD Queries

**Do this**:
- Rewrite all PRD-related queries
- Same conversion: parameters, types, functions
- Update PRD row structs to native types

**Verify**:
- [ ] All PRD queries compile
- [ ] `cargo check` passes for `db/prd.rs`

---

### Slice 17.5.4: Cross-Module Type Consistency

**Do this**:
- Ensure row struct types in refactor/PRD match the types used in `queries.rs`
- Verify shared types (e.g., `TaskId`, `AgentId`) work consistently across all query modules
- Remove any remaining SQLite-specific code patterns

**Verify**:
- [ ] `cargo check` passes for entire `src/db/` module
- [ ] No SQLite references remain in db module
