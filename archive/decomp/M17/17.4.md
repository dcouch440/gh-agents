# Ticket 17.4: Query Rewrites — Tasks, Chat, Auth

> Rewrite all SQL queries in the main query files for Postgres syntax and native types.

## Goal

All queries in `db/queries.rs` (tasks, chat, auth sections) use Postgres `$1, $2` parameter markers, return native types (`Uuid`, `DateTime<Utc>`, `bool`, `serde_json::Value`), and compile against `PgPool`.

**Checkpoint**: `cargo check` passes for all task, chat, and auth query functions.

---

## Context

This is the largest query file. Every `?` becomes `$1`, every `TEXT` UUID becomes a native `Uuid` parameter, every `INTEGER` boolean becomes a native `bool`, and row structs use native types instead of string parsing.

**Key files**:
- `src/db/queries.rs` — Main query file

**Dependencies**: 17.3 (PgPool must be available)

---

## Slices

### Slice 17.4.1: Task CRUD Queries

**Do this**:
- Rewrite all task-related queries (create, read, update, delete, list)
- Change `?` to `$1, $2, ...` positional parameters
- Change `sqlx::query_as!(... SqliteRow)` to use Postgres-compatible row types
- Update row structs: `id: Uuid`, `created_at: DateTime<Utc>`, `completed: bool`, `metadata: serde_json::Value`
- Remove any string-to-UUID or string-to-bool parsing in application code

**Verify**:
- [ ] All task queries compile
- [ ] Insert and select roundtrip with correct types

### Slice 17.4.2: Chat History Queries

**Do this**:

- [ ] Auth queries compile
