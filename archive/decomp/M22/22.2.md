# Ticket 22.2: Agent Worker Dockerfile

> Container image with nexor binary + language runtimes for agent workers.

## Goal

A Dockerfile that builds a container image agents can run inside. Includes git, Node.js, Python, and common build tools. The nexor binary is copied in and configured to run in worker mode.

## File Changes

| File | Change |
|------|--------|
| `docker/agent-worker.Dockerfile` | **New** — Multi-stage build for worker image |
| `docker/docker-compose.yml` | Add `nexor-worker` service template |
| `docker/.dockerignore` | Ensure build context is clean |

## Slices

### 22.2.1: agent-worker.Dockerfile

Multi-stage build:

**Stage 1 (builder)**: Reuse existing Rust build pattern from `docker/Dockerfile`.

**Stage 2 (runtime)**:
- Base: `debian:bookworm-slim`
- Install: `git`, `ca-certificates`, `libssl3`, `curl`, `build-essential`
- Install: Node.js 20 LTS (via nodesource)
- Install: Python 3 + pip
- Copy nexor binary from builder
- Non-root user `nexor` (uid 1000)
- Entrypoint: `nexor --worker`
- Expose port 3001 (worker health check)

**Test**: `docker build -f docker/agent-worker.Dockerfile -t nexor-worker:test .` succeeds.

### 22.2.2: docker-compose.yml worker service

Add a `nexor-worker` service definition as a template (not started by default):

```yaml
nexor-worker:
  build:
    context: ..
    dockerfile: docker/agent-worker.Dockerfile
  image: nexor-worker:latest
  profiles:
    - worker
  environment:
    - NEXOR_ORCHESTRATOR_URL=ws://host.docker.internal:3000/ws/worker
    - RUST_LOG=${RUST_LOG:-info}
  volumes:
    - type: bind
      source: ${WORKTREE_PATH}
      target: /workspace
  working_dir: /workspace
  deploy:
    resources:
      limits:
        memory: 2g
        cpus: "2.0"
```

**Test**: `docker compose config` validates without errors.

### 22.2.3: Build script and .dockerignore

Add a `scripts/build-worker-image.sh` convenience script:

```bash
#!/bin/bash
docker build -f docker/agent-worker.Dockerfile -t nexor-worker:latest .
```

Update `.dockerignore` to exclude `target/`, `.nexor/`, `node_modules/`.

**Test**: Script runs and produces tagged image.
