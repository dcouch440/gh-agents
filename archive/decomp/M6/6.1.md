# Ticket 6.1: Terminal Setup

> Initialize ratatui and crossterm for TUI rendering with proper cleanup.

## Goal

Set up the terminal infrastructure so the application can:
- Enter raw mode and alternate screen for TUI
- Restore terminal state on normal exit
- Restore terminal state on panic (no corrupted terminal)
- Run a basic event loop that responds to input

**Checkpoint**: `cargo run` enters TUI mode, responds to keypresses, and exits cleanly with Ctrl+C.

---

## Slices

### Slice 6.1.1: Terminal Initialization

**Do this**:
- Create `src/tui/mod.rs` with module declarations
- Create `src/tui/app.rs` with terminal setup functions
- Implement `init_terminal()` that:
  - Enables raw mode via `crossterm::terminal::enable_raw_mode()`
  - Enters alternate screen via `crossterm::execute!(stdout, EnterAlternateScreen)`
  - Creates and returns a `ratatui::Terminal<CrosstermBackend<Stdout>>`
- Implement `restore_terminal()` that:
  - Disables raw mode
  - Leaves alternate screen
  - Shows cursor

**Create/modify**:
- `src/tui/mod.rs`
- `src/tui/app.rs`

**Code example**:
```rust
// src/tui/app.rs
use std::io::{self, Stdout};
use crossterm::{
    execute,
    terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen},
};
use ratatui::{backend::CrosstermBackend, Terminal};

pub type Tui = Terminal<CrosstermBackend<Stdout>>;

pub fn init_terminal() -> io::Result<Tui> {
    enable_raw_mode()?;
    let mut stdout = io::stdout();
    execute!(stdout, EnterAlternateScreen)?;
    let backend = CrosstermBackend::new(stdout);
    Terminal::new(backend)
}

pub fn restore_terminal(terminal: &mut Tui) -> io::Result<()> {
    disable_raw_mode()?;
    execute!(terminal.backend_mut(), LeaveAlternateScreen)?;
    terminal.show_cursor()?;
    Ok(())
}
```

- [ ] Can call `init_terminal()` and get a Terminal instance
- [ ] Can call `restore_terminal()` without errors

### Slice 6.1.2: Panic Handler for Clean Shutdown

**Do this**:
- Install a panic hook that restores terminal state before printing panic info
- Use `std::panic::set_hook()` to wrap the default handler
- Ensure panic messages are visible (not lost in alternate screen)

**Create/modify**:
- `src/tui/app.rs` - add `install_panic_hook()` function

**Code example**:
```rust
// src/tui/app.rs
use std::panic;

pub fn install_panic_hook() {
    let original_hook = panic::take_hook();
    panic::set_hook(Box::new(move |panic_info| {
        // Best effort to restore terminal
        let _ = disable_raw_mode();
        let _ = execute!(io::stdout(), LeaveAlternateScreen);
        original_hook(panic_info);
    }));
}
```

### Slice 6.1.3: Main Event Loop

**Do this**:
- Create `App` struct to hold application state
- Implement basic event loop that:
  - Polls for crossterm events with timeout
  - Handles `KeyCode::Char('c')` with Ctrl modifier to exit
  - Renders a simple "Press Ctrl+C to exit" message
- Update `src/main.rs` to initialize TUI and run the loop
- Ensure clean shutdown on both normal exit and Ctrl+C

**Create/modify**:
- `src/tui/app.rs` - add `App` struct and `run()` method
- `src/main.rs` - start TUI

**Code example**:
```rust
// src/tui/app.rs
use crossterm::event::{self, Event, KeyCode, KeyModifiers};
use ratatui::widgets::Paragraph;
use std::time::Duration;

pub struct App {
    should_quit: bool,
}

impl App {
    pub fn new() -> Self {
        Self { should_quit: false }
    }

    pub fn run(&mut self, terminal: &mut Tui) -> io::Result<()> {
        while !self.should_quit {
            terminal.draw(|frame| {
                let message = Paragraph::new("nexor TUI - Press Ctrl+C to exit");
                frame.render_widget(message, frame.area());
            })?;

            if event::poll(Duration::from_millis(100))? {
                if let Event::Key(key) = event::read()? {
                    if key.code == KeyCode::Char('c')
                        && key.modifiers.contains(KeyModifiers::CONTROL)
                    {
                        self.should_quit = true;
                    }
                }
            }
        }
        Ok(())
    }
}
```

```rust
// src/main.rs (simplified)
use nexor::tui::{app::{App, init_terminal, restore_terminal, install_panic_hook}};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    install_panic_hook();

    let mut terminal = init_terminal()?;
    let mut app = App::new();

    let result = app.run(&mut terminal);

    restore_terminal(&mut terminal)?;
    result?;

    Ok(())
}
```

- [ ] `cargo check` passes

- [ ] Ctrl+C exits cleanly, terminal is restored
- [ ] Terminal shows normal prompt after exit (not corrupted)

## Notes

- **Event polling timeout**: 100ms is a good balance between responsiveness and CPU usage
- **Alternate screen**: This prevents TUI from overwriting terminal history
- **Raw mode**: Required for reading individual keypresses without Enter
- **The panic hook is critical**: Without it, a panic leaves the terminal in unusable state
- Future slices will expand the event loop with more key handlers and views
