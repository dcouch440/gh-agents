# Ticket 6.7: Logs View (/logs)

> Technical log viewer with level filtering.

## Goal

Create the `/logs` view that shows:
- Technical logs from the tracing system
- Different colors for log levels (error, warn, info, debug)

**Checkpoint**: Can switch to `/logs` view and see application logs with color-coded levels.

**Code example**:
```rust
// src/tui/views/logs.rs
use chrono::{DateTime, Local};

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum LogLevel {
    Error,
    Warn,
    Info,
    Debug,
    Trace,
}

impl LogLevel {
    pub fn as_str(&self) -> &'static str {
        match self {
            LogLevel::Error => "ERROR",
            LogLevel::Warn => "WARN",
            LogLevel::Info => "INFO",
            LogLevel::Debug => "DEBUG",
            LogLevel::Trace => "TRACE",
        }
    }
}

#[derive(Debug, Clone)]
pub struct LogEntry {
    pub level: LogLevel,
    pub target: String,      // Module path
    pub message: String,
    pub timestamp: DateTime<Local>,
}

impl LogEntry {
    pub fn new(level: LogLevel, target: &str, message: &str) -> Self {
        Self {
            level,
            target: target.to_string(),
            message: message.to_string(),
            timestamp: Local::now(),
        }
    }
}

pub struct LogsView {
    pub entries: Vec<LogEntry>,
    pub scroll_offset: usize,
    pub min_level: LogLevel,  // Filter: show this level and above
}

impl Default for LogsView {
    fn default() -> Self {
        Self {
            entries: Vec::new(),
            scroll_offset: 0,
            min_level: LogLevel::Info,  // Default to Info and above
        }
    }
}

impl LogsView {
    pub fn push(&mut self, entry: LogEntry) {
        self.entries.push(entry);
    }

    pub fn filtered_entries(&self) -> impl Iterator<Item = &LogEntry> {
        self.entries.iter().filter(|e| e.level <= self.min_level)
    }

    pub fn set_min_level(&mut self, level: LogLevel) {
        self.min_level = level;
    }
}
```

### Slice 6.7.2: Log Entry Rendering

**Do this**:
- Implement `Widget` trait for `LogsView`
- Render each entry with:
  - Timestamp (HH:MM:SS format)
  - Level with color coding (red=error, yellow=warn, green=info, blue=debug)
  - Target module (truncated if too long)
  - Message
- Handle scrolling for large log history

**Create/modify**:
- `src/tui/views/logs.rs` - implement Widget trait

**Code example**:
```rust
// src/tui/views/logs.rs
use ratatui::{
    buffer::Buffer,
    layout::Rect,
    style::{Color, Style},
    widgets::Widget,
};

impl LogLevel {
    pub fn color(&self) -> Color {
        match self {
            LogLevel::Error => Color::Red,
            LogLevel::Warn => Color::Yellow,
            LogLevel::Info => Color::Green,
            LogLevel::Debug => Color::Blue,
            LogLevel::Trace => Color::DarkGray,
        }
    }
}

impl Widget for LogsView {
    fn render(self, area: Rect, buf: &mut Buffer) {
        if self.entries.is_empty() {
            buf.set_string(
                area.x + 1,
                area.y + 1,
                "No logs yet...",
                Style::default().fg(Color::DarkGray),
            );
            return;
        }

        let visible_height = area.height as usize;
        let filtered: Vec<&LogEntry> = self.filtered_entries().collect();

        let display_entries: Vec<&LogEntry> = filtered
            .iter()
            .skip(self.scroll_offset)
            .take(visible_height)
            .copied()
            .collect();

        for (i, entry) in display_entries.iter().enumerate() {
            let y = area.y + i as u16;
            if y >= area.bottom() {
                break;
            }

            let mut x = area.x;

            // Timestamp: HH:MM:SS
            let time = entry.timestamp.format("%H:%M:%S").to_string();
            buf.set_string(x, y, &time, Style::default().fg(Color::DarkGray));
            x += time.len() as u16 + 1;

            // Level
            let level_str = format!("{:5}", entry.level.as_str());
            buf.set_string(x, y, &level_str, Style::default().fg(entry.level.color()));
            x += level_str.len() as u16 + 1;

            // Target (module) - truncate if needed
            let max_target_len = 20;
            let target = if entry.target.len() > max_target_len {
                format!("...{}", &entry.target[entry.target.len() - max_target_len + 3..])
            } else {
                format!("{:width$}", entry.target, width = max_target_len)
            };
            buf.set_string(x, y, &target, Style::default().fg(Color::Cyan));
            x += max_target_len as u16 + 1;

            // Message - fill remaining width
            let remaining = (area.right() - x) as usize;
            let message = if entry.message.len() > remaining {
                format!("{}...", &entry.message[..remaining.saturating_sub(3)])
            } else {
                entry.message.clone()
            };
            buf.set_string(x, y, &message, Style::default());
        }
    }
}
```

// src/tui/log_capture.rs
use tokio::sync::mpsc;
use tracing::{Event, Subscriber};
use tracing_subscriber::layer::Context;
use tracing_subscriber::Layer;
use crate::tui::views::{LogEntry, LogLevel};

pub struct TuiLogLayer {
    tx: mpsc::Sender<LogEntry>,
}

impl TuiLogLayer {
    pub fn new(tx: mpsc::Sender<LogEntry>) -> Self {
        Self { tx }
    }
}

impl<S: Subscriber> Layer<S> for TuiLogLayer {
    fn on_event(&self, event: &Event<'_>, _ctx: Context<'_, S>) {
        let level = match *event.metadata().level() {
            tracing::Level::ERROR => LogLevel::Error,
            tracing::Level::WARN => LogLevel::Warn,
            tracing::Level::INFO => LogLevel::Info,
            tracing::Level::DEBUG => LogLevel::Debug,
            tracing::Level::TRACE => LogLevel::Trace,
        };

        let target = event.metadata().target().to_string();

        // Extract message (simplified - real impl would use a visitor)
        let message = format!("{:?}", event);

        let entry = LogEntry::new(level, &target, &message);
        let _ = self.tx.try_send(entry);
    }
}

## Notes

- **Log retention**: Consider limiting stored logs (e.g., last 10,000 entries) to prevent memory issues
- **Level filtering**: Default to Info. User can change with keyboard shortcuts (defer to polish)
- **Performance**: High log volume could affect TUI. Consider rate limiting or batching.
- **Tracing visitor**: The simplified message extraction could be improved to properly format structured logs
- **File logging**: This doesn't replace file logging from M1.5 - it's an additional capture for TUI display
- **Scroll keys**: Arrow up/down for scrolling. Can implement Page Up/Down for faster scrolling.
- **Filter shortcuts**: Could add `1-5` number keys to set log level filter. Defer to polish.
