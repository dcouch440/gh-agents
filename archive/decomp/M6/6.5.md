# Ticket 6.5: Chat View (/main)

> Orchestrator conversation interface with streaming responses.

## Goal

Create the `/main` chat view where users interact with the orchestrator:
- Display message history (user messages and orchestrator responses)
- Send messages to orchestrator agent
- Display streaming responses as they arrive
- Support message input and submission

**Checkpoint**: Can send a message and see orchestrator response appear (streaming or mock).

---

## Context

The chat view is the primary interaction point. Users communicate with the orchestrator through natural conversation. The orchestrator manages all other agents and reports back.

**Key files**:

- `src/tui/app.rs` - Integrate chat with orchestrator (modify)

**Dependencies**:

```rust
// src/tui/views/chat.rs
use chrono::{DateTime, Utc};

#[derive(Debug, Clone, PartialEq)]
pub enum MessageSender {
    User,
    Orchestrator,
}

#[derive(Debug, Clone)]
pub struct ChatMessage {
    pub sender: MessageSender,
    pub content: String,
    pub timestamp: DateTime<Utc>,
    pub is_streaming: bool,  // True while response is being received
}

impl ChatMessage {
    pub fn user(content: &str) -> Self {
        Self {
            sender: MessageSender::User,
            content: content.to_string(),
            timestamp: Utc::now(),
            is_streaming: false,
        }
    }

    pub fn orchestrator(content: &str) -> Self {
        Self {
            sender: MessageSender::Orchestrator,
            content: content.to_string(),
            timestamp: Utc::now(),
            is_streaming: false,
        }
    }

    pub fn orchestrator_streaming() -> Self {
        Self {
            sender: MessageSender::Orchestrator,
            content: String::new(),
            timestamp: Utc::now(),
            is_streaming: true,
        }
    }
}

pub struct ChatView {
    pub messages: Vec<ChatMessage>,
    pub scroll_offset: usize,
}

impl Default for ChatView {
    fn default() -> Self {
        Self {
            messages: Vec::new(),
            scroll_offset: 0,
        }
    }
}
```

### Slice 6.5.2: Chat Message Rendering

**Do this**:
- Implement `Widget` trait for `ChatView`
- Render messages with different styles:
  - User messages: `You: {content}`
  - Orchestrator messages: `Orchestrator: {content}`
- Handle multi-line messages with proper wrapping
- Show streaming indicator for in-progress responses

**Create/modify**:
- `src/tui/views/chat.rs` - implement Widget trait

**Code example**:
```rust
// src/tui/views/chat.rs
use ratatui::{
    buffer::Buffer,
    layout::Rect,
    style::{Color, Modifier, Style},
    text::{Line, Span, Text},
    widgets::{Paragraph, Widget, Wrap},
};

impl Widget for ChatView {
    fn render(self, area: Rect, buf: &mut Buffer) {
        if self.messages.is_empty() {
            let hint = "Type a message to start chatting with the orchestrator...";
            buf.set_string(area.x + 1, area.y + 1, hint, Style::default().fg(Color::DarkGray));
            return;
        }

        let mut lines: Vec<Line> = Vec::new();

        for msg in &self.messages {
            // Add blank line between messages
            if !lines.is_empty() {
                lines.push(Line::from(""));
            }

            let (prefix, style) = match msg.sender {
                MessageSender::User => (
                    "You: ",
                    Style::default().fg(Color::Green),
                ),
                MessageSender::Orchestrator => (
                    "Orchestrator: ",
                    Style::default().fg(Color::Cyan),
                ),
            };

            // First line with sender prefix
            let content = if msg.is_streaming && msg.content.is_empty() {
                "▋".to_string()  // Blinking cursor for streaming
            } else if msg.is_streaming {
                format!("{}▋", msg.content)
            } else {
                msg.content.clone()
            };

            lines.push(Line::from(vec![
                Span::styled(prefix, style.add_modifier(Modifier::BOLD)),
                Span::raw(&content),
            ]));
        }

        let text = Text::from(lines);
        let paragraph = Paragraph::new(text).wrap(Wrap { trim: false });
        Widget::render(paragraph, area, buf);
    }
}
```

### Slice 6.5.4: Orchestrator Channel Connection

**Do this**:
- Add mpsc channels for orchestrator communication:
  - `chat_tx`: Send user messages TO orchestrator
  - `chat_rx`: Receive responses FROM orchestrator
- Update message submission to send through channel
- Receive and display orchestrator responses
- Handle streaming responses (partial content updates)

**Create/modify**:
- `src/tui/app.rs` - add orchestrator channels

**Code example**:
```rust
// src/tui/app.rs
use tokio::sync::mpsc;

// Message types for orchestrator communication
pub struct UserMessage {
    pub content: String,
}

pub enum OrchestratorResponse {
    Start,                    // Response started
    Chunk(String),           // Partial response content
    Complete(String),        // Final complete response
    Error(String),           // Error occurred
}

pub struct App {
    // ... existing fields ...
    chat_tx: mpsc::Sender<UserMessage>,
    chat_rx: mpsc::Receiver<OrchestratorResponse>,
    pending_response: Option<ChatMessage>,  // Current streaming response
}

impl App {
    fn submit_chat_message(&mut self) {
        let content = self.input_buffer.clone();
        self.input_buffer.clear();

        // Add user message
        self.chat.messages.push(ChatMessage::user(&content));

        // Send to orchestrator
        let _ = self.chat_tx.try_send(UserMessage { content });

        // Start pending response
        self.pending_response = Some(ChatMessage::orchestrator_streaming());
    }

    fn check_orchestrator_responses(&mut self) {
        while let Ok(response) = self.chat_rx.try_recv() {
            match response {
                OrchestratorResponse::Start => {
                    // Response is starting
                }
                OrchestratorResponse::Chunk(text) => {
                    if let Some(ref mut msg) = self.pending_response {
                        msg.content.push_str(&text);
                    }
                }
                OrchestratorResponse::Complete(text) => {
                    if let Some(mut msg) = self.pending_response.take() {
                        msg.content = text;
                        msg.is_streaming = false;
                        self.chat.messages.push(msg);
                    }
                }
                OrchestratorResponse::Error(err) => {
                    self.pending_response = None;
                    self.chat.messages.push(ChatMessage::orchestrator(
                        &format!("Error: {}", err)
                    ));
                }
            }
        }
    }
}
```

```rust
// src/tui/app.rs - in render loop for chat view
CurrentView::Chat => {
    self.check_orchestrator_responses();

    // Build messages list including pending streaming response

    if let Some(ref pending) = self.pending_response {
        messages.push(pending.clone());
```

## Notes

- **Mock responses**: Until M3 (Agent Runtime) is complete, use mock responses for testing
- **Streaming UX**: The cursor indicator (`▋`) shows the user something is happening
- **Message history**: Consider limiting history size for memory efficiency
- **Wrapping**: Long messages should wrap at word boundaries
- **Real orchestrator**: Connection to actual orchestrator agent happens in M3 integration
- **Error handling**: Display errors inline in chat, don't crash the TUI
- **Copy/paste**: Not implemented in initial version. Can add in polish phase.
