# Ticket 15.6: Report Management Backend

> Database schema and API for storing, reviewing, editing, and submitting agent-generated reports.

## Goal

Agent reports are stored in the database with a review lifecycle. Users can view, edit, approve, reject, and submit reports — all via API.

**Checkpoint**: Reports created by agents appear in the API, can be reviewed, edited, and marked as submitted or rejected.

---

## Context

Reports are currently markdown files generated using `templates/report.md`. This ticket gives them a database-backed lifecycle so they can be reviewed in the UI before submission.

**Key files**:
- `src/server/api.rs` — API endpoints
- `src/db/mod.rs` — Database queries
- `migrations/` — New migration
- `templates/report.md` — Existing report template

**Dependencies**:
- Requires M10 (Server Layer) complete

### Slice 15.6.2: Report CRUD API

**Do this**:
- `POST /api/reports` — Create report (typically called by agent runtime)
- `GET /api/reports` — List reports (query: `?status=&repo_id=&task_id=`)
- `GET /api/reports/:id` — Get report with comments
- `PUT /api/reports/:id` — Edit report content
- `DELETE /api/reports/:id` — Delete report (only if draft)

**Create/modify**:
- `src/server/api.rs`

**Verify**:
- [ ] `cargo check` passes

---

### Slice 15.6.3: Review Workflow API

**Do this**:
- `POST /api/reports/:id/review` — Change status (body: `{ action: "approve" | "reject" | "request_changes", comment? }`)
  - `approve` → status = `approved`
  - `reject` → status = `rejected`
  - `request_changes` → status = `pending_review` + adds comment
- `POST /api/reports/:id/submit` — Mark as submitted (only from `approved` status)
  - Sets `submitted_at` timestamp
- Broadcast status changes via WebSocket

**Create/modify**:
- `src/server/api.rs`
- `src/server/ws.rs`

**Verify**:
- [ ] `cargo check` passes
- [ ] Status transitions enforced

## Notes

- Status transitions: `draft → pending_review → approved → submitted` or `→ rejected → pending_review → ...`
- Only `draft` reports can be deleted
- Submitted reports are immutable
