# Ticket 15.8: Pivotal Points Dashboard

> Track key decision points, bookmarks, and milestones across repositories with a timeline view.

## Goal

Users can bookmark important moments — architectural decisions, branch points, key commits, completed milestones — and view them on a searchable timeline across repos.

**Checkpoint**: Can create a pivotal point, link it to a commit/PR/report, view a timeline, and filter by repo or tag.

---

## Context

This feature provides a "project memory" — a way to look back at important decisions and understand why things were done a certain way.

**Key files**:
- `src/server/api.rs` — API endpoints
- `src/db/mod.rs` — Database queries
- `ui/src/pages/` — New PivotsPage
- `migrations/` — New migration

### Slice 15.8.1: Database Schema & API

**Do this**:
- Create migration `010_pivots.sql`:
  - `pivotal_points` table: `id`, `title`, `description` (markdown), `category` (TEXT: decision/milestone/bookmark/branch_point), `repo_id` (FK nullable), `commit_sha` (TEXT nullable), `pr_number` (INT nullable), `report_id` (FK nullable), `tags` (TEXT, comma-separated), `created_at`
- CRUD API:
  - `POST /api/pivots` — Create pivot
  - `GET /api/pivots` — List (query: `?repo_id=&category=&tag=&search=&from=&to=`)
  - `GET /api/pivots/:id` — Get detail
  - `PUT /api/pivots/:id` — Update
  - `DELETE /api/pivots/:id` — Delete
