# Ticket 15.5: Full Code Editor

> Monaco-based code editor with VS Code keybindings, tabs, split panes, file tree, and all the shortcuts a power user expects.

## Goal

A full-screen code editor that feels like VS Code embedded in the browser. Tabs, split panes, command palette, minimap, git gutter, find/replace, and all standard keybindings.

**Checkpoint**: Can open files from tree, edit in tabs, split the editor, use Ctrl+P/Ctrl+Shift+P, save with Ctrl+S, and see git change indicators.

---

## Context

M12.5 plans a basic file browser and editor. This ticket replaces that with a full-featured Monaco integration that fills the entire content area.

**Key files**:
- `ui/src/pages/` — New EditorPage
- `ui/src/components/editor/` — Editor components
- `ui/src/api/client.ts` — File API methods (from M12.5 backend)

**Dependencies**:
- Requires 15.1 (Multi-Repo Backend) for repo-scoped file access
- Requires M12.5 slice 12.5.1 (file API endpoints) or implement here
- npm package: `@monaco-editor/react`
