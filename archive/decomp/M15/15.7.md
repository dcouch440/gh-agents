# Ticket 15.7: Report Viewer & Submission UI

> On-screen report rendering with approve/reject workflow, inline editing, and submission flow.

## Goal

Users can view agent-generated reports as rendered markdown, edit them inline, approve or reject with comments, and submit approved reports — all without leaving the app.

**Checkpoint**: Can see a report list, open a report, edit it, add a review comment, approve it, and submit it.

---

## Context

Backend from ticket 15.6 provides the report lifecycle API.

**Key files**:
- `ui/src/pages/` — New ReportsPage
- `ui/src/components/reports/` — Report components
- `ui/src/api/client.ts` — Add report API methods

**Dependencies**:

- Requires M11.4 (Layout Components) complete
