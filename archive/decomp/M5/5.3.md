# Ticket 5.3: Router (Task → Tier)

> Route tasks to the appropriate agent tier based on task characteristics.

## Goal

Implement a Router that determines which agent tier (Orchestrator, Worker, or Utility) should handle a given task, based on configurable routing rules and task metadata hints.

**Checkpoint**: Call `Router::route(&task)` and receive the correct `AgentTier` based on task type, complexity, and any override hints.

---

## Context

The Router sits between the Planner (which creates tasks with suggested tiers) and the Scheduler (which assigns tasks to agents). It enforces routing rules and handles overrides.

Routing logic:
1. Check for explicit tier override in task metadata
2. Apply type-based rules (formatting → Utility, features → Worker, etc.)
3. Consider complexity hints from Planner
4. Fall back to Worker tier for unknowns

/// A single routing rule that maps task characteristics to a tier
#[derive(Debug, Clone)]
pub struct RoutingRule {
    pub name: String,
    pub matcher: RuleMatcher,
    pub target_tier: AgentTier,
    pub priority: u8,  // Higher priority rules checked first
}

#[derive(Debug, Clone)]
pub enum RuleMatcher {
    /// Match if task title contains any of these keywords
    TitleContains(Vec<String>),

    /// Match if task has specific metadata key
    HasMetadata(String),

    /// Match if task complexity exceeds threshold
    ComplexityAbove(String),  // "low", "medium", "high"

    /// Match if task has explicit tier override
    ExplicitTierOverride,

    /// Always matches (fallback rule)
    Always,
}

#[derive(Debug, Clone)]

impl Router {
    /// Route a task to the appropriate agent tier
    pub fn route(&self, task: &Task) -> AgentTier {
        // Sort rules by priority (highest first)
        let mut rules: Vec<_> = self.config.rules.iter().collect();
        rules.sort_by(|a, b| b.priority.cmp(&a.priority));

        for rule in rules {
            if let Some(tier) = self.evaluate_rule(rule, task) {
                tracing::debug!(
                    task_id = %task.id,
                    rule = %rule.name,
                    tier = ?tier,
                    "Task routed"
                );
                return tier;
            }
        }

        // Should never reach here due to Always matcher, but fallback just in case
        tracing::warn!(
            task_id = %task.id,
            "No routing rule matched, defaulting to Worker"
        );
        AgentTier::Worker
    }

    fn evaluate_rule(&self, rule: &RoutingRule, task: &Task) -> Option<AgentTier> {
        match &rule.matcher {
            RuleMatcher::ExplicitTierOverride => {
                self.get_tier_override(task)
            }

            RuleMatcher::TitleContains(keywords) => {
                let title_lower = task.title.to_lowercase();
                if keywords.iter().any(|k| title_lower.contains(&k.to_lowercase())) {
                    Some(rule.target_tier)
                } else {
                    None
                }
            }

            RuleMatcher::HasMetadata(key) => {
                // Check if task has metadata field (requires Task to have metadata map)
                // For now, skip if no metadata support
                if self.has_metadata(task, key) {
                    Some(rule.target_tier)
                } else {
                    None
                }
            }

            RuleMatcher::ComplexityAbove(threshold) => {
                if self.complexity_exceeds(task, threshold) {
                    Some(rule.target_tier)
                } else {
                    None
                }
            }

            RuleMatcher::Always => {
                Some(rule.target_tier)
            }
        }
    }

    fn get_tier_override(&self, task: &Task) -> Option<AgentTier> {
        // Check task's assigned_tier if it was explicitly set by Planner
        // The Planner sets assigned_tier based on LLM suggestion
        // We treat non-Worker assignments as explicit overrides
        match task.assigned_tier {
            AgentTier::Worker => None, // Not an override, let rules decide
            tier => Some(tier),
        }
    }

    fn has_metadata(&self, _task: &Task, _key: &str) -> bool {
        // TODO: Implement when Task has metadata field
        // For now, return false
        false
    }

    fn complexity_exceeds(&self, task: &Task, threshold: &str) -> bool {
        // Infer complexity from task characteristics
        // - More context files = higher complexity
        // - Longer description = higher complexity
        let file_count = task.context_files.len();
        let desc_len = task.description.len();

        let inferred_complexity = if file_count > 5 || desc_len > 500 {
            "high"
        } else if file_count > 2 || desc_len > 200 {
            "medium"
        } else {
            "low"
        };

        let threshold_value = match threshold.to_lowercase().as_str() {
            "high" => 3,
            "medium" => 2,
            "low" => 1,
            _ => 2,
        };

        let inferred_value = match inferred_complexity {
            "high" => 3,
            "medium" => 2,
            _ => 1,
        };

        inferred_value >= threshold_value
    }
}

impl Router {
    fn has_metadata(&self, task: &Task, key: &str) -> bool {
        task.metadata.as_ref()
            .map(|m| m.contains_key(key))
            .unwrap_or(false)
    }

    fn get_metadata(&self, task: &Task, key: &str) -> Option<&String> {
        task.metadata.as_ref()
            .and_then(|m| m.get(key))
    }

    fn get_tier_override(&self, task: &Task) -> Option<AgentTier> {
        // First check metadata for explicit override
        if let Some(tier_str) = self.get_metadata(task, "tier_override") {
            return match tier_str.to_lowercase().as_str() {
                "orchestrator" => Some(AgentTier::Orchestrator),
                "worker" => Some(AgentTier::Worker),
                "utility" => Some(AgentTier::Utility),
                _ => None,
            };
        }

        // Then check if assigned_tier was explicitly set
        match task.assigned_tier {
            AgentTier::Worker => None,
            tier => Some(tier),
        }
    }

    fn complexity_exceeds(&self, task: &Task, threshold: &str) -> bool {
        // Check metadata for explicit complexity first
        if let Some(complexity) = self.get_metadata(task, "complexity") {
            let threshold_value = Self::complexity_value(threshold);
            let task_value = Self::complexity_value(complexity);
            return task_value >= threshold_value;
        }

        // Fall back to inference
        self.infer_complexity(task, threshold)
    }

    fn complexity_value(level: &str) -> u8 {
        match level.to_lowercase().as_str() {
            "high" => 3,
            "medium" => 2,
            "low" => 1,
            _ => 2,
        }
    }

    fn infer_complexity(&self, task: &Task, threshold: &str) -> bool {
        let file_count = task.context_files.len();
        let desc_len = task.description.len();

        let inferred = if file_count > 5 || desc_len > 500 {
            3 // high
        } else if file_count > 2 || desc_len > 200 {
            2 // medium
        } else {
            1 // low
        };

        inferred >= Self::complexity_value(threshold)
    }
}
