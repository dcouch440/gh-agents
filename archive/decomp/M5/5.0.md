# Ticket 5.0: Planner Bot (Interactive PRD Creation)

> A specialized bot for `/plan` mode that helps users create PRDs through conversation.

## Goal

The Planner Bot is a specialized agent persona activated when users enter `/plan` mode. Unlike the Orchestrator (which manages work), the Planner Bot focuses exclusively on helping users scope projects, create PRDs, and define milestones through interactive conversation.

**Checkpoint**: Enter `/plan` mode, describe a project idea, have a back-and-forth conversation with the Planner Bot, and produce a structured PRD document.

---

## Context

Each TUI mode has a specialized bot with distinct capabilities:

| Mode | Bot | Purpose |
|------|-----|---------|
| `/main` | Orchestrator | Task delegation, work management |
| `/plan` | **Planner** | PRD creation, project scoping |
| `/feed` | (none) | Read-only activity stream |
| `/logs` | (none) | Read-only log viewer |

The Planner Bot is **interactive** - it doesn't auto-generate a PRD from a single prompt. Instead, it:
1. Asks clarifying questions about the project
2. Helps identify scope and scale
3. Suggests technical approaches
4. Collaboratively builds the PRD section by section
5. Outputs a structured document when the user is satisfied

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PRDDocument {
    pub id: Uuid,
    pub title: String,
    pub status: PRDStatus,

    // Core sections
    pub vision: Option<String>,
    pub problem_statement: Option<String>,
    pub target_users: Option<String>,
    pub success_criteria: Vec<String>,

    // Technical planning
    pub technical_decisions: Vec<TechnicalDecision>,
    pub data_models: Vec<DataModelSketch>,
    pub milestones: Vec<MilestoneSpec>,

    // Metadata
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    pub conversation_id: Option<Uuid>,  // Link to planning conversation
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum PRDStatus {
    Draft,      // Being created in /plan
    Review,     // User reviewing before approval
    Approved,   // Ready for execution
    Archived,   // Completed or abandoned
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MilestoneSpec {
    pub number: u32,
    pub title: String,
    pub goal: String,
    pub checkpoint: String,
    pub estimated_tickets: u32,
    pub estimated_effort: Option<String>,  // "1 week", "2-3 days", etc.
    pub dependencies: Vec<u32>,  // Other milestone numbers
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TechnicalDecision {
    pub area: String,           // "Language", "Database", "Architecture", etc.
    pub decision: String,       // "Rust", "SQLite", "Event-driven", etc.
    pub rationale: String,      // Why this choice
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DataModelSketch {
    pub name: String,           // "User", "Task", etc.
    pub fields: Vec<String>,    // ["id: Uuid", "email: String", ...]
    pub notes: Option<String>,
}

impl PRDDocument {
    pub fn new(title: String) -> Self {
        Self {
            id: Uuid::new_v4(),
            title,
            status: PRDStatus::Draft,
            vision: None,
            problem_statement: None,
            target_users: None,
            success_criteria: vec![],
            technical_decisions: vec![],
            data_models: vec![],
            milestones: vec![],
            created_at: Utc::now(),
            updated_at: Utc::now(),
            conversation_id: None,
        }
    }

    pub fn is_complete(&self) -> bool {
        self.vision.is_some()
            && !self.milestones.is_empty()
            && !self.technical_decisions.is_empty()
    }

    pub fn estimated_scale(&self) -> ProjectScale {
        match self.milestones.len() {
            0 => ProjectScale::Unknown,
            1 => ProjectScale::Feature,
            2..=4 => ProjectScale::Project,
            _ => ProjectScale::Epic,
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ProjectScale {
    Unknown,
    Feature,    // 1 milestone
    Project,    // 2-4 milestones
    Epic,       // 5+ milestones
}

/// Tracks the current state of a planning conversation
#[derive(Debug, Clone)]
pub struct PlanningSession {
    pub id: Uuid,
    pub prd: PRDDocument,
    pub current_phase: PlanningPhase,
    pub messages: Vec<PlanningMessage>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PlanningPhase {
    Discovery,      // Understanding the project idea
    Scoping,        // Defining boundaries and scale
    Technical,      // Technical decisions
    Milestones,     // Breaking into milestones
    Review,         // Final review before approval
}

#[derive(Debug, Clone)]
pub struct PlanningMessage {
    pub role: MessageRole,
    pub content: String,
}

#[derive(Debug, Clone, Copy)]
pub enum MessageRole {
    User,
    Planner,
}

pub struct PlannerBot<P: LLMProvider> {
    provider: Arc<P>,
    model_id: String,
}

impl<P: LLMProvider> PlannerBot<P> {
    pub fn new(provider: Arc<P>, model_id: String) -> Self {
        Self { provider, model_id }
    }

    /// Start a new planning session
    pub fn start_session(&self, initial_idea: Option<&str>) -> PlanningSession {
        let mut prd = PRDDocument::new("Untitled Project".to_string());
        prd.conversation_id = Some(Uuid::new_v4());

        let mut session = PlanningSession {
            id: prd.conversation_id.unwrap(),
            prd,
            current_phase: PlanningPhase::Discovery,
            messages: vec![],
        };

        // If user provided an initial idea, record it
        if let Some(idea) = initial_idea {
            session.messages.push(PlanningMessage {
                role: MessageRole::User,
                content: idea.to_string(),
            });
        }

        session
    }

    /// Get the system prompt for the Planner Bot persona
    fn system_prompt(&self, session: &PlanningSession) -> String {
        let phase_guidance = match session.current_phase {
            PlanningPhase::Discovery => {
                "You're in DISCOVERY phase. Ask questions to understand:
                - What problem is the user trying to solve?
                - Who are the target users?
                - What does success look like?
                Don't jump to solutions yet. Understand the problem deeply first."
            }
            PlanningPhase::Scoping => {
                "You're in SCOPING phase. Help define boundaries:
                - What's in scope vs out of scope for v1?
                - What are the must-haves vs nice-to-haves?
                - How big is this project? (Feature/Project/Epic)
                Be realistic about scope. Push back on scope creep."
            }
            PlanningPhase::Technical => {
                "You're in TECHNICAL phase. Discuss:
                - Language and framework choices
                - Database and storage needs
                - Architecture patterns
                - Key technical risks
                Make concrete recommendations with rationale."
            }
            PlanningPhase::Milestones => {
                "You're in MILESTONES phase. Break the project into milestones:
                - Each milestone should deliver user-visible value
                - Order by dependencies (foundation first)
                - Estimate effort for each (days/weeks)
                - Keep it to 3-9 milestones typically"
            }
            PlanningPhase::Review => {
                "You're in REVIEW phase. Summarize the PRD:
                - Recap vision and scope
                - List all milestones
                - Highlight key technical decisions
                - Ask if user wants to approve or revise"
            }
        };

        format!(r#"You are the Planner Bot - a specialized assistant for creating Product Requirements Documents (PRDs).

Your personality:
- Thoughtful and methodical
- Ask clarifying questions rather than assume
- Push back on unrealistic scope
- Focus on MVP/v1 - avoid over-engineering
- Be concrete and specific, not vague

Current PRD Status:
- Title: {}
- Phase: {:?}
- Milestones defined: {}
- Technical decisions: {}

Phase Guidance:
{}

Rules:
- Stay in your current phase until it's complete
- Don't write code - you're a planner, not an implementer
- Keep responses conversational, not formal document-style
- When ready to move phases, explicitly say so
- Use structured output when finalizing sections

You can suggest moving to the next phase when:
- Discovery → Scoping: Problem is well understood
- Scoping → Technical: Scope is clearly defined
- Technical → Milestones: Key technical decisions made
- Milestones → Review: All milestones defined
- Review → Done: User approves the PRD"#,
            session.prd.title,
            session.current_phase,
            session.prd.milestones.len(),
            session.prd.technical_decisions.len(),
            phase_guidance
        )
    }
}

use crate::llm::{LLMRequest, Message};

impl<P: LLMProvider> PlannerBot<P> {
    /// Process a user message and return the Planner's response
    pub async fn chat(
        &self,
        session: &mut PlanningSession,
        user_message: &str,
    ) -> Result<String, PlannerBotError> {
        // Add user message to history
        session.messages.push(PlanningMessage {
            role: MessageRole::User,
            content: user_message.to_string(),
        });

        // Build LLM request with conversation history
        let messages = self.build_messages(session);
        let request = LLMRequest {
            messages,
            model: self.model_id.clone(),
            max_tokens: Some(2000),
            temperature: Some(0.7),
        };

        // Call LLM
        let response = self.provider
            .send_message(&request)
            .await
            .map_err(|e| PlannerBotError::LlmError(e.to_string()))?;

        let assistant_content = response.content.clone();

        // Add assistant response to history
        session.messages.push(PlanningMessage {
            role: MessageRole::Planner,
            content: assistant_content.clone(),
        });

        // Check for phase transitions or structured updates
        self.process_response(session, &assistant_content)?;

        Ok(assistant_content)
    }

    fn build_messages(&self, session: &PlanningSession) -> Vec<Message> {
        let mut messages = vec![
            Message {
                role: "system".to_string(),
                content: self.system_prompt(session),
            }
        ];

        // Add conversation history
        for msg in &session.messages {
            messages.push(Message {
                role: match msg.role {
                    MessageRole::User => "user".to_string(),
                    MessageRole::Planner => "assistant".to_string(),
                },
                content: msg.content.clone(),
            });
        }

        messages
    }

    fn process_response(
        &self,
        session: &mut PlanningSession,
        response: &str,
    ) -> Result<(), PlannerBotError> {
        // Check for phase transition signals
        let response_lower = response.to_lowercase();

        if response_lower.contains("moving to scoping") ||
           response_lower.contains("let's move to scoping") {
            session.current_phase = PlanningPhase::Scoping;
        } else if response_lower.contains("moving to technical") ||
                  response_lower.contains("let's discuss technical") {
            session.current_phase = PlanningPhase::Technical;
        } else if response_lower.contains("moving to milestones") ||
                  response_lower.contains("let's break this into milestones") {
            session.current_phase = PlanningPhase::Milestones;
        } else if response_lower.contains("ready for review") ||
                  response_lower.contains("let's review the prd") {
            session.current_phase = PlanningPhase::Review;
        }

        // Check for structured data in response (JSON blocks)
        if let Some(json_data) = self.extract_json_block(response) {
            self.apply_structured_update(session, &json_data)?;
        }

        Ok(())
    }

    fn extract_json_block(&self, content: &str) -> Option<String> {
        if let Some(start) = content.find("```json") {
            if let Some(end) = content[start + 7..].find("```") {
                return Some(content[start + 7..start + 7 + end].trim().to_string());
            }
        }
        None
    }

    fn apply_structured_update(
        &self,
        session: &mut PlanningSession,
        json_data: &str,
    ) -> Result<(), PlannerBotError> {
        // Try to parse as different update types
        if let Ok(milestone) = serde_json::from_str::<MilestoneSpec>(json_data) {
            session.prd.milestones.push(milestone);
            session.prd.updated_at = Utc::now();
        } else if let Ok(decision) = serde_json::from_str::<TechnicalDecision>(json_data) {
            session.prd.technical_decisions.push(decision);
            session.prd.updated_at = Utc::now();
        }
        // Add more update types as needed

        Ok(())
    }
}

#[derive(Debug, thiserror::Error)]
pub enum PlannerBotError {
    #[error("LLM error: {0}")]
    LlmError(String),

    #[error("Parse error: {0}")]
    ParseError(String),

    #[error("Session error: {0}")]
    SessionError(String),
}
```

impl<P: LLMProvider> PlannerBot<P> {
    /// Finalize and approve the PRD
    pub fn finalize_prd(
        &self,
        session: &mut PlanningSession,
    ) -> Result<PRDDocument, PlannerBotError> {
        // Validate PRD is complete enough
        if !session.prd.is_complete() {
            return Err(PlannerBotError::SessionError(
                "PRD is not complete. Need vision and at least one milestone.".to_string()
            ));
        }

        session.prd.status = PRDStatus::Approved;
        session.prd.updated_at = Utc::now();

        Ok(session.prd.clone())
    }

    /// Export PRD to markdown format
    pub fn export_markdown(&self, prd: &PRDDocument) -> String {
        let mut md = String::new();

        md.push_str(&format!("# {}\n\n", prd.title));
        md.push_str(&format!("**Status**: {:?}\n\n", prd.status));

        if let Some(ref vision) = prd.vision {
            md.push_str("## Vision\n\n");
            md.push_str(vision);
            md.push_str("\n\n");
        }

        if let Some(ref problem) = prd.problem_statement {
            md.push_str("## Problem Statement\n\n");
            md.push_str(problem);
            md.push_str("\n\n");
        }

        if !prd.success_criteria.is_empty() {
            md.push_str("## Success Criteria\n\n");
            for criterion in &prd.success_criteria {
                md.push_str(&format!("- {}\n", criterion));
            }
            md.push_str("\n");
        }

        if !prd.technical_decisions.is_empty() {
            md.push_str("## Technical Decisions\n\n");
            md.push_str("| Area | Decision | Rationale |\n");
            md.push_str("|------|----------|----------|\n");
            for decision in &prd.technical_decisions {
                md.push_str(&format!(
                    "| {} | {} | {} |\n",
                    decision.area, decision.decision, decision.rationale
                ));
            }
            md.push_str("\n");
        }

        if !prd.milestones.is_empty() {
            md.push_str("## Milestones\n\n");
            for milestone in &prd.milestones {
                md.push_str(&format!("### M{}: {}\n\n", milestone.number, milestone.title));
                md.push_str(&format!("**Goal**: {}\n\n", milestone.goal));
                md.push_str(&format!("**Checkpoint**: {}\n\n", milestone.checkpoint));
                if let Some(ref effort) = milestone.estimated_effort {
                    md.push_str(&format!("**Estimated Effort**: {}\n\n", effort));
                }
                if !milestone.dependencies.is_empty() {
                    md.push_str(&format!(
                        "**Dependencies**: M{}\n\n",
                        milestone.dependencies.iter()
                            .map(|d| d.to_string())
                            .collect::<Vec<_>>()
                            .join(", M")
                    ));
                }
            }
        }

        md
    }
}
```

            vision = excluded.vision,

## Integration with Other Modes

Once a PRD is approved in `/plan`:

1. User can switch to `/main`
2. Tell orchestrator: "Execute the billing system PRD" (or select from list)
3. Orchestrator loads the PRD
4. Uses milestones to create tickets
5. Planner (5.1) decomposes tickets into slices
6. Normal work execution begins

The Planner Bot creates the plan; the Orchestrator executes it.
