# Ticket 5.1: Planner (Ticket → Slices)

> Decompose high-level tickets into vertical slices using the orchestrator LLM.

## Goal

The Planner takes a ticket description (from user chat or GitHub issue) and uses the orchestrator-tier LLM to decompose it into actionable vertical slices that can be assigned to worker agents.

**Checkpoint**: Call `Planner::decompose("Add user authentication")` and receive a structured `Vec<VerticalSlice>` with titles, descriptions, tasks, and dependencies.

---

## Context

The Planner is the core intelligence of the orchestration layer. It:
1. Takes raw ticket text as input
2. Builds a prompt using M4's decomposition templates
3. Calls the orchestrator LLM
4. Parses the structured JSON response
5. Handles parse failures with retry/correction
6. Persists slices to the database

use serde::{Deserialize, Serialize};
use uuid::Uuid;

#[derive(Debug, Deserialize)]
struct DecompositionOutput {
    thinking: String,
    slices: Vec<SliceOutput>,
    questions: Vec<String>,
    risks: Vec<String>,
}

#[derive(Debug, Deserialize)]
struct SliceOutput {
    title: String,
    description: String,
    tasks: Vec<TaskOutput>,
    dependencies: Vec<String>,
    acceptance_criteria: Vec<String>,
}

#[derive(Debug, Deserialize)]
struct TaskOutput {
    title: String,
    tier: String,  // "worker" | "utility"
    estimated_complexity: String,
    context_files: Vec<String>,
}

impl<P: LLMProvider> Planner<P> {
    fn parse_decomposition_response(&self, content: &str) -> DecompositionResult {
        // Extract JSON from response (may be wrapped in markdown code block)
        let json_str = Self::extract_json(content)?;

        // Parse JSON
        let output: DecompositionOutput = serde_json::from_str(&json_str)
            .map_err(|e| DecompositionError::ParseError {
                reason: e.to_string(),
                raw_output: content.to_string(),
            })?;

        // Convert to VerticalSlices
        self.convert_to_slices(output)
    }

    fn extract_json(content: &str) -> Result<String, DecompositionError> {
        // Try to find JSON in markdown code blocks first
        if let Some(start) = content.find("```json") {
            if let Some(end) = content[start..].find("```\n") {
                let json_start = start + 7; // len("```json")
                return Ok(content[json_start..start + end].trim().to_string());
            }
        }

        // Try to find raw JSON object
        if let Some(start) = content.find('{') {
            if let Some(end) = content.rfind('}') {
                return Ok(content[start..=end].to_string());
            }
        }

        Err(DecompositionError::ParseError {
            reason: "No JSON found in response".to_string(),
            raw_output: content.to_string(),
        })
    }

    fn convert_to_slices(&self, output: DecompositionOutput) -> DecompositionResult {
        let ticket_id = Uuid::new_v4(); // Would come from actual ticket

        let slices: Vec<VerticalSlice> = output.slices
            .into_iter()
            .enumerate()
            .map(|(i, s)| {
                VerticalSlice {
                    id: Uuid::new_v4(),
                    ticket_id,
                    title: s.title,
                    description: s.description,
                    tasks: s.tasks.into_iter().map(|t| {
                        Task {
                            id: Uuid::new_v4(),
                            slice_id: None, // Set after slice creation
                            title: t.title,
                            description: String::new(),
                            assigned_tier: Self::parse_tier(&t.tier),
                            assigned_agent: None,
                            status: TaskStatus::Pending,
                            priority: Priority::Normal,
                            context_files: t.context_files.into_iter()
                                .map(PathBuf::from)
                                .collect(),
                            created_at: Utc::now(),
                            updated_at: Utc::now(),
                        }
                    }).collect(),
                    status: TaskStatus::Pending,
                    created_at: Utc::now(),
                }
            })
            .collect();

        Ok(slices)
    }

    fn parse_tier(tier_str: &str) -> AgentTier {
        match tier_str.to_lowercase().as_str() {
            "utility" => AgentTier::Utility,
            "orchestrator" => AgentTier::Orchestrator,
            _ => AgentTier::Worker,
        }
    }
}
```

### Slice 5.1.4: Implement Retry with Correction Prompt

**Do this**:
- Wrap decompose logic in retry loop
- On parse failure, send correction prompt with error details
- Use M4's recovery prompt template (ticket 4.9)
- Track attempt count, fail after max retries

**Create/modify**:
- `src/orchestration/planner.rs`

**Code to add**:
```rust
impl<P: LLMProvider> Planner<P> {
    pub async fn decompose(&self, ticket: &Ticket) -> DecompositionResult {
        let mut last_error: Option<DecompositionError> = None;

        for attempt in 1..=self.config.max_retries {
            let prompt = if attempt == 1 {
                // First attempt: standard decomposition prompt
                self.build_decomposition_prompt(ticket)
            } else {
                // Retry: include correction context
                self.build_correction_prompt(ticket, last_error.as_ref().unwrap())
            };

            let response = match self.provider
                .send_message(&prompt, &self.config.model_id)
                .await
            {
                Ok(r) => r,
                Err(e) => {
                    last_error = Some(DecompositionError::LlmError(e.to_string()));
                    continue;
                }
            };

            match self.parse_decomposition_response(&response.content) {
                Ok(slices) => return Ok(slices),
                Err(e) => {
                    tracing::warn!(
                        attempt = attempt,
                        error = %e,
                        "Decomposition parse failed, retrying"
                    );
                    last_error = Some(e);
                }
            }
        }

        Err(DecompositionError::MaxRetriesExceeded {
            attempts: self.config.max_retries,
        })
    }

    fn build_decomposition_prompt(&self, ticket: &Ticket) -> String {
        PromptBuilder::new()
            .role("orchestrator")
            .context_ticket(ticket)
            .task("decompose")
            .output_format("decomposition_json")
            .build()
    }

    fn build_correction_prompt(&self, ticket: &Ticket, error: &DecompositionError) -> String {
        let error_context = match error {
            DecompositionError::ParseError { reason, raw_output } => {
                format!(
                    "Your previous output couldn't be parsed.\n\
                     Error: {}\n\
                     Your output: {}\n\
                     Please regenerate with valid JSON.",
                    reason,
                    &raw_output[..raw_output.len().min(500)]
                )
            }
            _ => format!("Previous attempt failed: {}", error),
        };

        PromptBuilder::new()
            .role("orchestrator")
            .context_ticket(ticket)
            .context_error(&error_context)
            .task("decompose")
            .output_format("decomposition_json")
            .build()
    }
}
```

**Create/modify**:
- `src/orchestration/planner.rs`

**Code to add**:
```rust
use sqlx::SqlitePool;

pub struct Planner<P: LLMProvider> {
    provider: Arc<P>,
    pool: SqlitePool,
    config: PlannerConfig,
}

impl<P: LLMProvider> Planner<P> {
    pub fn new(provider: Arc<P>, pool: SqlitePool, config: PlannerConfig) -> Self {
        Self { provider, pool, config }
    }

    pub async fn decompose_and_save(&self, ticket: &Ticket) -> DecompositionResult {
        let slices = self.decompose(ticket).await?;
        self.save_slices(&slices).await?;
        Ok(slices)
    }

    async fn save_slices(&self, slices: &[VerticalSlice]) -> Result<(), DecompositionError> {
        let mut tx = self.pool.begin().await
            .map_err(|e| DecompositionError::DatabaseError(e.to_string()))?;

        for slice in slices {
            // Insert slice
            sqlx::query!(
                r#"
                INSERT INTO vertical_slices (id, ticket_id, title, description, status, created_at)
                VALUES (?, ?, ?, ?, ?, ?)
                "#,
                slice.id.to_string(),
                slice.ticket_id.to_string(),
                slice.title,
                slice.description,
                "pending",
                slice.created_at.to_rfc3339(),
            )
            .execute(&mut *tx)
            .await
            .map_err(|e| DecompositionError::DatabaseError(e.to_string()))?;

            // Insert tasks for this slice
            for task in &slice.tasks {
                sqlx::query!(
                    r#"
                    INSERT INTO tasks (id, slice_id, title, description, assigned_tier, status, priority, created_at, updated_at)
                    VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                    "#,
                    task.id.to_string(),
                    slice.id.to_string(),
                    task.title,
                    task.description,
                    format!("{:?}", task.assigned_tier),
                    "pending",
                    format!("{:?}", task.priority),
                    task.created_at.to_rfc3339(),
                    task.updated_at.to_rfc3339(),
                )
                .execute(&mut *tx)
                .await
                .map_err(|e| DecompositionError::DatabaseError(e.to_string()))?;
            }
        }

        tx.commit().await
            .map_err(|e| DecompositionError::DatabaseError(e.to_string()))?;

        Ok(())
    }
}
```
