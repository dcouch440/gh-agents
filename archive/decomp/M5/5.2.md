# Ticket 5.2: Task Queue

> Priority-ordered work queue with persistence and requeue support.

## Goal

Implement a priority task queue that orders tasks by priority, persists state to database, and supports requeuing failed tasks. This is the central dispatch mechanism for all agent work.

**Checkpoint**: Enqueue tasks with different priorities, verify dequeue returns highest priority first, restart application and verify queue state survives.

---

## Context

The Task Queue is the heart of the orchestration system. All tasks flow through it:
1. Planner creates tasks → enqueue
2. Scheduler dequeues tasks → assigns to agents
3. Failed tasks → requeue with same or escalated priority

use crate::types::{Task, TaskId, Priority, TaskStatus};
use std::collections::BinaryHeap;
use std::cmp::Ordering;
use thiserror::Error;

#[derive(Error, Debug)]
pub enum QueueError {
    #[error("task not found: {0}")]
    TaskNotFound(TaskId),

    #[error("database error: {0}")]
    DatabaseError(String),

    #[error("queue is empty")]
    Empty,
}

/// Wrapper for priority ordering in BinaryHeap
/// Higher priority = dequeued first (max-heap behavior)
#[derive(Debug, Clone)]
struct PrioritizedTask {
    task: Task,
}

impl PartialEq for PrioritizedTask {
    fn eq(&self, other: &Self) -> bool {
        self.task.id == other.task.id
    }
}

impl Eq for PrioritizedTask {}

impl PartialOrd for PrioritizedTask {
    fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
        Some(self.cmp(other))
    }
}

impl Ord for PrioritizedTask {
    fn cmp(&self, other: &Self) -> Ordering {
        // Higher priority value = higher priority in queue
        // Secondary: older tasks (earlier created_at) have priority
        match self.priority_value().cmp(&other.priority_value()) {
            Ordering::Equal => other.task.created_at.cmp(&self.task.created_at),
            other => other,
        }
    }
}

impl PrioritizedTask {
    fn priority_value(&self) -> u8 {
        match self.task.priority {
            Priority::Urgent => 4,
            Priority::High => 3,
            Priority::Normal => 2,
            Priority::Low => 1,
        }
    }
}

pub struct TaskQueue {
    heap: BinaryHeap<PrioritizedTask>,
}

impl TaskQueue {
    pub fn new() -> Self {
        Self {
            heap: BinaryHeap::new(),
        }
    }

    pub fn len(&self) -> usize {
        self.heap.len()
    }

    pub fn is_empty(&self) -> bool {
        self.heap.is_empty()
    }
}

impl Default for TaskQueue {
    fn default() -> Self {
        Self::new()
    }
}
```

impl TaskQueue {
    /// Add a task to the queue
    pub fn enqueue(&mut self, task: Task) {
        tracing::debug!(
            task_id = %task.id,
            priority = ?task.priority,
            "Enqueueing task"
        );
        self.heap.push(PrioritizedTask { task });
    }

    /// Remove and return the highest priority task
    pub fn dequeue(&mut self) -> Option<Task> {
        self.heap.pop().map(|pt| {
            tracing::debug!(
                task_id = %pt.task.id,
                priority = ?pt.task.priority,
                "Dequeuing task"
            );
            pt.task
        })
    }

    /// Peek at the highest priority task without removing it
    pub fn peek(&self) -> Option<&Task> {
        self.heap.peek().map(|pt| &pt.task)
    }

    /// Check if a task is in the queue
    pub fn contains(&self, id: &TaskId) -> bool {
        self.heap.iter().any(|pt| &pt.task.id == id)
    }

    /// Get all tasks in priority order (for debugging/display)
    pub fn all_tasks(&self) -> Vec<&Task> {
        let mut tasks: Vec<_> = self.heap.iter().map(|pt| &pt.task).collect();
        tasks.sort_by(|a, b| {
            let a_val = match a.priority {
                Priority::Urgent => 4,
                Priority::High => 3,
                Priority::Normal => 2,
                Priority::Low => 1,
            };
            let b_val = match b.priority {
                Priority::Urgent => 4,
                Priority::High => 3,
                Priority::Normal => 2,
                Priority::Low => 1,
            };
            b_val.cmp(&a_val)
        });
        tasks
    }
}

use sqlx::SqlitePool;

pub struct PersistentTaskQueue {
    inner: TaskQueue,
    pool: SqlitePool,
}

impl PersistentTaskQueue {
    pub async fn new(pool: SqlitePool) -> Result<Self, QueueError> {
        let mut queue = Self {
            inner: TaskQueue::new(),
            pool,
        };
        queue.load_from_db().await?;
        Ok(queue)
    }

    /// Load all pending tasks from database into memory queue
    async fn load_from_db(&mut self) -> Result<(), QueueError> {
        let tasks = sqlx::query_as!(
            TaskRow,
            r#"
            SELECT id, slice_id, title, description, assigned_tier, status, priority, created_at, updated_at
            FROM tasks
            WHERE status = 'Pending'
            ORDER BY created_at ASC
            "#
        )
        .fetch_all(&self.pool)
        .await
        .map_err(|e| QueueError::DatabaseError(e.to_string()))?;

        for row in tasks {
            let task = Task::try_from(row)
                .map_err(|e| QueueError::DatabaseError(e.to_string()))?;
            self.inner.enqueue(task);
        }

        tracing::info!(count = self.inner.len(), "Loaded tasks from database");
        Ok(())
    }

    /// Enqueue a task and persist to database
    pub async fn enqueue(&mut self, task: Task) -> Result<(), QueueError> {
        // Update status in database
        sqlx::query!(
            "UPDATE tasks SET status = 'Pending', updated_at = datetime('now') WHERE id = ?",
            task.id.0.to_string()
        )
        .execute(&self.pool)
        .await
        .map_err(|e| QueueError::DatabaseError(e.to_string()))?;

        self.inner.enqueue(task);
        Ok(())
    }

    /// Dequeue highest priority task and update database
    pub async fn dequeue(&mut self) -> Result<Option<Task>, QueueError> {
        match self.inner.dequeue() {
            Some(task) => {
                // Update status to InProgress
                sqlx::query!(
                    "UPDATE tasks SET status = 'InProgress', updated_at = datetime('now') WHERE id = ?",
                    task.id.0.to_string()
                )
                .execute(&self.pool)
                .await
                .map_err(|e| QueueError::DatabaseError(e.to_string()))?;

                Ok(Some(task))
            }
            None => Ok(None),
        }
    }

    pub fn peek(&self) -> Option<&Task> {
        self.inner.peek()
    }

    pub fn len(&self) -> usize {
        self.inner.len()
    }

    pub fn is_empty(&self) -> bool {
        self.inner.is_empty()
    }
}

/// Database row type for task loading
#[derive(Debug)]
struct TaskRow {
    id: String,
    slice_id: Option<String>,
    title: String,
    description: String,
    assigned_tier: String,
    status: String,
    priority: String,
    created_at: String,
    updated_at: String,
}
```

#[derive(Debug, Clone, Copy)]
pub enum RequeuePolicy {
    /// Keep same priority
    SamePriority,
    /// Escalate priority by one level (Low→Normal→High→Urgent)
    EscalatePriority,
    /// Set specific priority
    SetPriority(Priority),
}

impl PersistentTaskQueue {
    /// Requeue a task that failed or needs retry
    pub async fn requeue(
        &mut self,
        mut task: Task,
        policy: RequeuePolicy
    ) -> Result<(), QueueError> {
        // Apply priority policy
        task.priority = match policy {
            RequeuePolicy::SamePriority => task.priority,
            RequeuePolicy::EscalatePriority => Self::escalate_priority(task.priority),
            RequeuePolicy::SetPriority(p) => p,
        };

        // Update task status back to Pending
        task.status = TaskStatus::Pending;
        task.updated_at = Utc::now();

        // Persist changes
        sqlx::query!(
            r#"
            UPDATE tasks
            SET status = 'Pending',
                priority = ?,
                updated_at = datetime('now')
            WHERE id = ?
            "#,
            format!("{:?}", task.priority),
            task.id.0.to_string()
        )
        .execute(&self.pool)
        .await
        .map_err(|e| QueueError::DatabaseError(e.to_string()))?;

        // Log task event for audit trail
        sqlx::query!(
            r#"
            INSERT INTO task_events (id, task_id, event_type, details, timestamp)
            VALUES (?, ?, 'Requeued', ?, datetime('now'))
            "#,
            Uuid::new_v4().to_string(),
            task.id.0.to_string(),
            format!("Requeued with policy {:?}", policy),
        )
        .execute(&self.pool)
        .await
        .map_err(|e| QueueError::DatabaseError(e.to_string()))?;

        tracing::info!(
            task_id = %task.id,
            priority = ?task.priority,
            "Task requeued"
        );

        self.inner.enqueue(task);
        Ok(())
    }

    fn escalate_priority(current: Priority) -> Priority {
        match current {
            Priority::Low => Priority::Normal,
            Priority::Normal => Priority::High,
            Priority::High => Priority::Urgent,
            Priority::Urgent => Priority::Urgent, // Already max
        }
    }

    /// Get count of tasks currently in queue by priority
    pub fn count_by_priority(&self) -> std::collections::HashMap<Priority, usize> {
        let mut counts = std::collections::HashMap::new();
        for task in self.inner.all_tasks() {
            *counts.entry(task.priority).or_insert(0) += 1;
        }
        counts
    }
}

}

## Notes

- The in-memory queue provides fast operations; database is source of truth for recovery
- Priority ties are broken by `created_at` - older tasks go first (FIFO within priority)
- `PersistentTaskQueue` wraps `TaskQueue` to add database operations
- Requeue creates an audit trail via `task_events` table
- Consider adding queue size limits and backpressure handling for production
