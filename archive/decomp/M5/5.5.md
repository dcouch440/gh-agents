# Ticket 5.5: Scheduler

> Coordinate task assignment to agents based on availability and priority.

## Goal

Implement a Scheduler that runs a continuous loop: checking the queue for unblocked tasks, finding available agents in the correct tier, and assigning work. Handle agent unavailability and urgent task preemption.

**Checkpoint**: Start the scheduler, enqueue tasks, observe tasks being assigned to agents, see assignments logged in feed.

---

## Context

The Scheduler is the coordinator that brings together:
- Task Queue (5.2) - provides tasks in priority order
- Router (5.3) - determines which tier handles each task
- Dependency Tracker (5.4) - filters blocked tasks
- Agent Pool (M3) - provides available agents

The scheduler loop:
1. Get next unblocked task from queue
2. Route task to determine target tier
3. Find available agent in that tier
4. Assign task to agent, update status
5. Handle urgent preemption if needed

```rust
use crate::agents::{AgentPool, AgentId, AgentCommand};
use crate::orchestration::{DependencyAwareQueue, Router, QueueError};
use crate::types::{Task, TaskId, TaskStatus, AgentTier};
use std::sync::Arc;
use tokio::sync::{mpsc, RwLock};
use tokio::time::{interval, Duration};
use thiserror::Error;

#[derive(Error, Debug)]
pub enum SchedulerError {
    #[error("queue error: {0}")]
    QueueError(#[from] QueueError),

    #[error("agent pool error: {0}")]
    AgentPoolError(String),

    #[error("scheduler stopped")]
    Stopped,
}

pub struct SchedulerConfig {
    /// How often to check for new tasks (ms)
    pub poll_interval_ms: u64,

    /// Maximum tasks to assign per tick
    pub batch_size: usize,
}

impl Default for SchedulerConfig {
    fn default() -> Self {
        Self {
            poll_interval_ms: 100,
            batch_size: 5,
        }
    }
}

pub struct Scheduler {
    queue: Arc<RwLock<DependencyAwareQueue>>,
    router: Router,
    agent_pool: Arc<RwLock<AgentPool>>,
    config: SchedulerConfig,
    running: Arc<RwLock<bool>>,
}

impl Scheduler {
    pub fn new(
        queue: Arc<RwLock<DependencyAwareQueue>>,
        router: Router,
        agent_pool: Arc<RwLock<AgentPool>>,
        config: SchedulerConfig,
    ) -> Self {
        Self {
            queue,
            router,
            agent_pool,
            config,
            running: Arc::new(RwLock::new(false)),
        }
    }

    /// Start the scheduler loop
    pub async fn run(&self) -> Result<(), SchedulerError> {
        *self.running.write().await = true;

        let mut ticker = interval(Duration::from_millis(self.config.poll_interval_ms));

        tracing::info!("Scheduler started");

        loop {
            ticker.tick().await;

            if !*self.running.read().await {
                tracing::info!("Scheduler stopping");
                break;
            }

            // Try to assign tasks this tick
            match self.tick().await {
                Ok(assigned) => {
                    if assigned > 0 {
                        tracing::debug!(count = assigned, "Assigned tasks this tick");
                    }
                }
                Err(e) => {
                    tracing::error!(error = %e, "Scheduler tick error");
                    // Continue running despite errors
                }
            }
        }

        Ok(())
    }

    /// Stop the scheduler loop
    pub async fn stop(&self) {
        *self.running.write().await = false;
    }

    /// Single tick of the scheduler: try to assign up to batch_size tasks
    async fn tick(&self) -> Result<usize, SchedulerError> {
        let mut assigned = 0;

        for _ in 0..self.config.batch_size {
            match self.try_assign_one().await? {
                true => assigned += 1,
                false => break, // No more tasks or agents available
            }
        }

        Ok(assigned)
    }

    /// Try to assign a single task to an agent
    async fn try_assign_one(&self) -> Result<bool, SchedulerError> {
        // Get next unblocked task
        let task = {
            let mut queue = self.queue.write().await;
            match queue.dequeue_unblocked().await? {
                Some(t) => t,
                None => return Ok(false), // Queue empty or all blocked
            }
        };

        // Route to determine tier
        let tier = self.router.route(&task);

        // Find available agent in that tier
        let agent_id = {
            let pool = self.agent_pool.read().await;
            pool.get_available_agent(tier)
        };

        match agent_id {
            Some(id) => {
                self.assign_task(task, id, tier).await?;
                Ok(true)
            }
            None => {
                // No agent available, put task back
                tracing::debug!(
                    task_id = %task.id,
                    tier = ?tier,
                    "No agent available, requeueing"
                );
                let mut queue = self.queue.write().await;
                queue.requeue(task, RequeuePolicy::SamePriority).await?;
                Ok(false)
            }
        }
    }

    /// Assign a task to an agent
    async fn assign_task(
        &self,
        mut task: Task,
        agent_id: AgentId,
        tier: AgentTier,
    ) -> Result<(), SchedulerError> {
        // Update task status
        task.status = TaskStatus::InProgress;
        task.assigned_agent = Some(agent_id.clone());

        // Mark agent as working
        {
            let mut pool = self.agent_pool.write().await;
            pool.assign_agent(&agent_id, &task.id)
                .map_err(|e| SchedulerError::AgentPoolError(e.to_string()))?;
        }

        // Send task to agent via channel
        {
            let pool = self.agent_pool.read().await;
            pool.send_command(&agent_id, AgentCommand::ExecuteTask(task.clone()))
                .await
                .map_err(|e| SchedulerError::AgentPoolError(e.to_string()))?;
        }

        tracing::info!(
            task_id = %task.id,
            task_title = %task.title,
            agent_id = %agent_id,
            tier = ?tier,
            "Task assigned to agent"
        );

        Ok(())
    }
}
```

```rust
use tokio::sync::Notify;

pub struct Scheduler {
    queue: Arc<RwLock<DependencyAwareQueue>>,
    router: Router,
    agent_pool: Arc<RwLock<AgentPool>>,
    config: SchedulerConfig,
    running: Arc<RwLock<bool>>,

    /// Notified when an agent becomes available
    agent_available: Arc<Notify>,
}

impl Scheduler {
    pub fn new(
        queue: Arc<RwLock<DependencyAwareQueue>>,
        router: Router,
        agent_pool: Arc<RwLock<AgentPool>>,
        config: SchedulerConfig,
    ) -> Self {
        Self {
            queue,
            router,
            agent_pool,
            config,
            running: Arc::new(RwLock::new(false)),
            agent_available: Arc::new(Notify::new()),
        }
    }

    /// Get a handle to notify when agents become available
    pub fn agent_available_notifier(&self) -> Arc<Notify> {
        self.agent_available.clone()
    }

    /// Enhanced tick that waits for agents if needed
    async fn tick(&self) -> Result<usize, SchedulerError> {
        let mut assigned = 0;
        let mut wait_logged = false;

        for _ in 0..self.config.batch_size {
            match self.try_assign_one().await? {
                AssignResult::Assigned => assigned += 1,
                AssignResult::NoTasks => break,
                AssignResult::NoAgents(tier) => {
                    if !wait_logged {
                        tracing::debug!(
                            tier = ?tier,
                            "Waiting for available agent"
                        );
                        wait_logged = true;
                    }

                    // Wait for agent or timeout
                    tokio::select! {
                        _ = self.agent_available.notified() => {
                            tracing::debug!("Agent became available, resuming");
                            // Try again next tick
                        }
                        _ = tokio::time::sleep(Duration::from_millis(500)) => {
                            // Timeout, will retry on next tick
                        }
                    }
                    break;
                }
            }
        }

        Ok(assigned)
    }

    async fn try_assign_one(&self) -> Result<AssignResult, SchedulerError> {
        // Get next unblocked task
        let task = {
            let mut queue = self.queue.write().await;
            match queue.dequeue_unblocked().await? {
                Some(t) => t,
                None => return Ok(AssignResult::NoTasks),
            }
        };

        // Route to determine tier
        let tier = self.router.route(&task);

        // Find available agent
        let agent_id = {
            let pool = self.agent_pool.read().await;
            pool.get_available_agent(tier)
        };

        match agent_id {
            Some(id) => {
                self.assign_task(task, id, tier).await?;
                Ok(AssignResult::Assigned)
            }
            None => {
                // Put task back and report no agents
                let mut queue = self.queue.write().await;
                queue.requeue(task, RequeuePolicy::SamePriority).await?;
                Ok(AssignResult::NoAgents(tier))
            }
        }
    }

    /// Call this when an agent completes work and becomes available
    pub async fn on_agent_available(&self, _agent_id: &AgentId) {
        self.agent_available.notify_waiters();
    }
}

#[derive(Debug)]
enum AssignResult {
    Assigned,
    NoTasks,
    NoAgents(AgentTier),
}

/// Spawn scheduler as background task
impl Scheduler {
    pub fn spawn(self: Arc<Self>) -> tokio::task::JoinHandle<Result<(), SchedulerError>> {
        tokio::spawn(async move {
            self.run().await
        })
    }
}
```

### Slice 5.5.3: Implement Preemption for Urgent Tasks

**Do this**:
- Detect when an urgent task enters the queue
- If urgent and no agents free, preempt lowest priority work
- Implement graceful preemption (agent pauses current task)
- Requeue preempted task with same priority

**Create/modify**:
- `src/orchestration/scheduler.rs`

**Code to add**:
```rust
use crate::types::Priority;

impl Scheduler {
    /// Check if we should preempt running work for an urgent task
    pub async fn check_preemption(&self) -> Result<Option<PreemptionAction>, SchedulerError> {
        // Check if there's an urgent task waiting
        let has_urgent = {
            let queue = self.queue.read().await;
            queue.peek()
                .map(|t| t.priority == Priority::Urgent)
                .unwrap_or(false)
        };

        if !has_urgent {
            return Ok(None);
        }

        // Check if all agents are busy
        let (busy_count, total_count) = {
            let pool = self.agent_pool.read().await;
            (pool.busy_count(), pool.total_count())
        };

        if busy_count < total_count {
            // There's a free agent, no need to preempt
            return Ok(None);
        }

        // Find the lowest priority running task to preempt
        let preempt_target = self.find_preemption_target().await?;

        if let Some((agent_id, task)) = preempt_target {
            tracing::info!(
                preempt_agent = %agent_id,
                preempt_task = %task.id,
                preempt_priority = ?task.priority,
                "Preempting for urgent task"
            );

            return Ok(Some(PreemptionAction {
                agent_id,
                task_to_pause: task,
            }));
        }

        Ok(None)
    }

    /// Find the best candidate for preemption
    async fn find_preemption_target(&self) -> Result<Option<(AgentId, Task)>, SchedulerError> {
        let pool = self.agent_pool.read().await;

        // Get all running tasks with their agents
        let running: Vec<_> = pool.running_tasks().await
            .into_iter()
            .filter(|(_, task)| task.priority != Priority::Urgent) // Don't preempt urgent
            .collect();

        if running.is_empty() {
            return Ok(None);
        }

        // Find lowest priority task
        let lowest = running.into_iter()
            .min_by_key(|(_, task)| {
                match task.priority {
                    Priority::Low => 1,
                    Priority::Normal => 2,
                    Priority::High => 3,
                    Priority::Urgent => 4,
                }
            });

        Ok(lowest)
    }

    /// Execute a preemption
    pub async fn execute_preemption(
        &self,
        action: PreemptionAction
    ) -> Result<(), SchedulerError> {
        // Send pause command to agent
        {
            let pool = self.agent_pool.read().await;
            pool.send_command(&action.agent_id, AgentCommand::Pause)
                .await
                .map_err(|e| SchedulerError::AgentPoolError(e.to_string()))?;
        }

        // Wait for agent to acknowledge pause
        // (The agent will send its current task state back)

        // Requeue the paused task
        {
            let mut queue = self.queue.write().await;
            queue.requeue(action.task_to_pause.clone(), RequeuePolicy::SamePriority).await?;
        }

        // Mark agent as available (it paused its work)
        {
            let mut pool = self.agent_pool.write().await;
            pool.release_agent(&action.agent_id)
                .map_err(|e| SchedulerError::AgentPoolError(e.to_string()))?;
        }

        // Notify that an agent is available
        self.agent_available.notify_waiters();

        tracing::info!(
            agent_id = %action.agent_id,
            task_id = %action.task_to_pause.id,
            "Preemption complete, agent available for urgent work"
        );

        Ok(())
    }

    /// Enhanced run loop with preemption checking
    pub async fn run_with_preemption(&self) -> Result<(), SchedulerError> {
        *self.running.write().await = true;

        let mut ticker = interval(Duration::from_millis(self.config.poll_interval_ms));

        tracing::info!("Scheduler started with preemption support");

        loop {
            ticker.tick().await;

            if !*self.running.read().await {
                break;
            }

            // Check for preemption needs first
            if let Some(action) = self.check_preemption().await? {
                self.execute_preemption(action).await?;
            }

            // Normal scheduling tick
            if let Err(e) = self.tick().await {
                tracing::error!(error = %e, "Scheduler tick error");
            }
        }

        Ok(())
    }
}

#[derive(Debug)]
pub struct PreemptionAction {
    pub agent_id: AgentId,
    pub task_to_pause: Task,
}
```

## Notes

- The scheduler runs as a background task, spawned at application startup
- `Notify` provides efficient wake-up when agents become available
- Preemption should be rare - only for truly urgent tasks
- Consider adding metrics: tasks assigned/second, wait times, preemption count
- The scheduler is the integration point for queue, router, and agent pool
- Graceful shutdown stops the loop cleanly via `running` flag
- Batch processing (batch_size) prevents scheduler from monopolizing the CPU
