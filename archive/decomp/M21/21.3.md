# Ticket 21.3: Branch Transition UX

> Smooth visual transition when switching branches — styled divider, stale item handling, and feed continuity.

## Goal

Branch switches produce a clear visual break in the feed without disrupting the layout. Old content stays visible above the divider. In-progress items above the divider are visually dimmed.

**Checkpoint**: Switching branches shows a yellow divider with branch name. Old items stay, new items appear below.

---

## Context

The divider is a FeedItem with type `branch_switch`. The FeedItemRow renderer (from M20 20.5.2) already handles this type. This ticket refines the transition behavior.

**Key files**:
- `cli/src/components/FeedItemRow.tsx` — Modify: enhance divider rendering
- `cli/src/store/feed.ts` — Modify: add stale marking

**Dependencies**: 21.2

---

## Slices

### Slice 21.3.1: Enhanced Divider Rendering

**Do this**:
- In FeedItemRow, make the `branch_switch` divider full-width:
  - Use `useStdout()` to get terminal width
  - Render: `━━━ Connected to branch: <name> ━━━` padded with `━` to fill width
  - Yellow bold text, centered branch name
  - Add a blank line above the divider for visual breathing room

**Verify**:
- [ ] Test: divider renders with branch name
- [ ] Visual check: divider spans terminal width

---

### Slice 21.3.2: Stale Item Marking

**Do this**:
- Add `stale?: boolean` field to `FeedItem` type
- When `insertDivider` is called in feed store, mark all existing items as `stale: true`
- In FeedItemRow, render stale items with `dimColor` (visually faded)
- Stale items are still visible but clearly distinguished from current branch activity

**Verify**:
- [ ] Unit test: insertDivider marks existing items stale
- [ ] Test: stale items render dimmed

---

### Slice 21.3.3: Transition Smoothness

**Do this**:
- On branch switch, the sequence is:
  1. Mark existing items stale
  2. Insert divider FeedItem
  3. Update `currentBranch` state → StatusBar updates
  4. New feed items appear below divider with normal styling
- No screen clear, no flicker, no layout reflow
- If already on the target branch, show system message: `Already on branch: <name>`

**Verify**:
- [ ] Test: switching to same branch shows "already on" message
- [ ] Test: items below divider are not stale
- [ ] `cd cli && npm test` passes
