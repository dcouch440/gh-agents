# Ticket 21.1: Git HEAD Watcher Hook

> React hook that watches `.git/HEAD` for branch changes and fires a callback when the branch changes.

## Goal

A `useGitBranch` hook that reads the current branch on mount and watches for external changes (e.g., `git checkout` in another terminal).

**Checkpoint**: Hook detects branch name on startup. Running `git checkout` fires the onChange callback.

---

## Context

Git stores the current branch reference in `.git/HEAD` as `ref: refs/heads/<branch>`. When `git checkout` runs, this file is rewritten. `fs.watch()` can detect this.

**Key files**:
- `cli/src/hooks/useGitBranch.ts` — New
- `cli/src/hooks/useGitBranch.test.ts` — New

**Dependencies**: M20 complete

## Slices

### Slice 21.1.1: Read Current Branch

**Do this**:
- Create `cli/src/hooks/useGitBranch.ts`
- Helper function `readBranch(repoRoot: string): string | null`
  - Read `<repoRoot>/.git/HEAD`
  - Parse `ref: refs/heads/<branch>\n` → extract branch name
  - Handle detached HEAD (no `ref:` prefix) → return commit hash (first 8 chars)
  - Return `null` if file doesn't exist or can't be read

**Verify**:
- [ ] Unit test: parses `ref: refs/heads/main\n` → `'main'`
- [ ] Unit test: parses `ref: refs/heads/feature/foo\n` → `'feature/foo'`
- [ ] Unit test: parses `abc123def456\n` (detached) → `'abc123de'`
- [ ] Unit test: returns null on missing file

---

### Slice 21.1.2: Find Repo Root

**Do this**:
- Helper function `findRepoRoot(startDir?: string): string | null`
  - Walk up from `startDir` (default `process.cwd()`) looking for `.git/HEAD`
  - Return the directory containing `.git/`, or `null` if not found
  - Cap at 20 levels to avoid infinite traversal

**Verify**:
- [ ] Unit test: finds repo root from nested directory
- [ ] Unit test: returns null when not in a git repo

---

### Slice 21.1.3: fs.watch Integration

**Do this**:
- `useGitBranch(onChange: (branch: string) => void)` hook
- On mount: find repo root, read initial branch, call `onChange` with it
- Set up `fs.watch()` on `<repoRoot>/.git/HEAD`
- On file change: debounce 100ms, re-read branch, call `onChange` only if changed
- Cleanup: close watcher on unmount
- Handle missing `.git/HEAD` gracefully (no-op)

**Verify**:
- [ ] Unit test with mocked fs.watch: onChange called on file change
- [ ] Unit test: debounce prevents rapid double-fires
- [ ] Unit test: cleanup closes watcher

---

### Slice 21.1.4: Error Resilience

**Do this**:
- If `.git/HEAD` doesn't exist (not a git repo), hook is a no-op — no crash
- If `fs.watch` throws (permissions, OS limits), catch and log warning
- If file becomes unreadable mid-session, don't crash — just stop watching
- Re-establish watcher if `.git/HEAD` reappears (optional, stretch)

**Verify**:
- [ ] Unit test: no crash when .git doesn't exist
