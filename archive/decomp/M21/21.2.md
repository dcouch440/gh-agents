# Ticket 21.2: Branch Selector Component

> An overlay component with filterable branch list, keyboard navigation, and selection — styled like Claude Code's selector.

## Goal

`/branch` opens a bordered overlay listing available branches. User can filter by typing, navigate with arrow keys, select with Enter, cancel with Esc.

**Checkpoint**: Overlay renders branch list, filter narrows results, Enter selects and closes.

---

## Context

The selector needs a branch list. Backend `GET /branches` doesn't exist yet, so use `git branch` locally as a fallback. The component captures keyboard input while open (InputBar is disabled).
