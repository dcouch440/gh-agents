## Execution Records
══════════════════════════════════════════════════════════════

agent_executions (one per agent invocation)
───────────────────────────────────────────────────────────────
│ id                       UUID
│ stage_execution_id       UUID        ← links to pipeline stage run
│ agent_id                 UUID        ← which agent ran
│ workflow_step_id         UUID?       ← which DAG step (if pipeline)
│ is_interactive           BOOL        ← chat vs background
│ parent_agent_execution_id UUID?      ← if spawned by another execution
│ system_prompt_rendered   TEXT        ← exact system prompt used
│ input                    TEXT        ← user message / step input
│ output                   TEXT?       ← final text response
│ structured_output        JSONB?      ← parsed JSON (schemas, routing)
│ status                   TEXT        ← running / completed / failed
│ input_tokens             BIGINT      (to be removed — use token_ledger)
│ output_tokens            BIGINT      (to be removed — use token_ledger)
│ cost_usd                 REAL        (to be removed — use token_ledger)
│ created_at               TIMESTAMPTZ
│ finished_at              TIMESTAMPTZ?
│
│  Future additions:
│  + agent_version          INT
│  + selected_mode_id       UUID?
│  + selected_mode_version  INT?
└──────────────────────────────────────────────────────────────
        │
        │ one-to-many
        │
        ▼
execution_messages (one per LLM round-trip within an execution)
───────────────────────────────────────────────────────────────
│ id                       UUID
│ agent_execution_id       UUID        ← parent execution
│ role                     TEXT        ← user / assistant / tool
│ content                  TEXT        ← message body
│ tool_call_id             TEXT?       ← links tool result to call
│ input_tokens             BIGINT      ← tokens for THIS round
│ output_tokens            BIGINT      ← tokens for THIS round
│ created_at               TIMESTAMPTZ
└──────────────────────────────────────────────────────────────


        Example: a chat turn with 2 tool calls

        agent_execution (id: exec-001, agent_id: abc-123)
            │
            ├── execution_message #1
            │     role: "assistant"
            │     content: "Let me search for that..."
            │     input_tokens: 1200, output_tokens: 50
            │
            ├── execution_message #2
            │     role: "tool"
            │     tool_call_id: "call_abc"
            │     content: '{"results": [...]}'
            │
            ├── execution_message #3
            │     role: "assistant"
            │     content: "I also need to check..."
            │     input_tokens: 1400, output_tokens: 80
            │
            ├── execution_message #4
            │     role: "tool"
            │     tool_call_id: "call_def"
            │     content: '{"file": "..."}'
            │
            └── execution_message #5
                  role: "assistant"
                  content: "Here's what I found..."
                  input_tokens: 1800, output_tokens: 400


        Example: mode classification (single round, no tools)

        agent_execution (id: exec-000, agent_id: def-456)
            │              selected_mode_id: mode-xyz
            │              input: "chat history + hints"
            │              output: "technical"
            │
            └── execution_message #1
                  role: "assistant"
                  content: "technical"
                  input_tokens: 200, output_tokens: 5


## Token Ledger (single source of truth for cost)
══════════════════════════════════════════════════════════════

token_ledger
───────────────────────────────────────────────────────────────
│ id                       UUID
│ user_id                  UUID        ← who pays
│ agent_execution_id       UUID        ← which execution
│ model_id                 TEXT        ← which model
│ input_tokens             BIGINT
│ output_tokens            BIGINT
│ cost_usd                 REAL
│ created_at               TIMESTAMPTZ
└──────────────────────────────────────────────────────────────

    Every strategy writes here. All cost queries hit here.
    agent_executions token/cost columns are deprecated.
