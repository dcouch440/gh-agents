# Ticket 8.3: PR Creation

> Create pull requests from completed work with proper linking.

## Goal

Implement PR creation that:
- Creates PRs on GitHub from local branches
- Generates descriptive PR body from slice information
- Links PRs to original issues (auto-close support)
- Handles branch and base specification

**Checkpoint**: After agents complete a slice, can create a PR that links back to the original issue.

---

## Context

When agents complete work on a slice, the changes need to be submitted as a pull request. This ticket handles the GitHub side of PR creation.

**Key files**:
- `src/github/pr.rs` - PR creation logic (create)
- `src/github/mod.rs` - Export PR functions (modify)

**Dependencies**:
- Requires 8.1 (GitHub API Client) complete
- Requires M7 (Execution Layer) for git operations (branch creation, commits)
- Uses `VerticalSlice` type from M1

**References**:
- GitHub PR API: https://docs.github.com/en/rest/pulls/pulls#create-a-pull-request
- See `ROADMAP.md` Ticket 8.3 for spec

```rust
// src/github/pr.rs
use crate::github::{GitHubClient, GitHubError};
use serde::{Deserialize, Serialize};
use anyhow::Result;

#[derive(Debug, Clone, Serialize)]
pub struct CreatePrRequest {
    pub title: String,
    pub body: String,
    pub head: String,      // Branch with changes
    pub base: String,      // Branch to merge into (e.g., "main")
    #[serde(skip_serializing_if = "Option::is_none")]
    pub draft: Option<bool>,
}

impl CreatePrRequest {
    pub fn new(title: &str, body: &str, head: &str, base: &str) -> Self {
        Self {
            title: title.to_string(),
            body: body.to_string(),
            head: head.to_string(),
            base: base.to_string(),
            draft: None,
        }
    }

    pub fn draft(mut self) -> Self {
        self.draft = Some(true);
        self
    }
}

#[derive(Debug, Clone, Deserialize)]
pub struct GitHubPullRequest {
    pub number: u32,
    pub html_url: String,
    pub state: String,
    pub title: String,
    pub body: Option<String>,
    pub head: PrBranch,
    pub base: PrBranch,
    pub draft: bool,
    pub mergeable: Option<bool>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct PrBranch {
    #[serde(rename = "ref")]
    pub branch_ref: String,
    pub sha: String,
}

impl GitHubClient {
    pub async fn create_pr(
        &self,
        owner: &str,
        repo: &str,
        request: CreatePrRequest,
    ) -> Result<GitHubPullRequest, GitHubError> {
        let url = format!("{}/repos/{}/{}/pulls", self.base_url, owner, repo);

        let response = self.client
            .post(&url)
            .json(&request)
            .send()
            .await
            .map_err(|e| GitHubError::Other(e.into()))?;

        self.handle_response(response).await
    }
}
```

### Slice 8.3.2: Generate PR Description

**Do this**:
- Create `PrBodyGenerator` that builds PR description from slice info
- Include:
  - Summary of what was done
  - List of files modified (if available)
  - Link to original issue (Fixes #123 format)
  - Attribution note
- Format using markdown
- Handle missing optional information gracefully

**Create/modify**:
- `src/github/pr.rs` - add `PrBodyGenerator`

**Code example**:
```rust
// src/github/pr.rs
use crate::types::{VerticalSlice, TicketSource};

pub struct PrBodyGenerator {
    slice: VerticalSlice,
    files_modified: Vec<String>,
    issue_ref: Option<(String, String, u32)>,  // (owner, repo, number)
}

impl PrBodyGenerator {
    pub fn new(slice: VerticalSlice) -> Self {
        Self {
            slice,
            files_modified: Vec::new(),
            issue_ref: None,
        }
    }

    pub fn with_files(mut self, files: Vec<String>) -> Self {
        self.files_modified = files;
        self
    }

    pub fn with_issue(mut self, owner: &str, repo: &str, number: u32) -> Self {
        self.issue_ref = Some((owner.to_string(), repo.to_string(), number));
        self
    }

    pub fn generate(&self) -> String {
        let mut body = String::new();

        // Summary section
        body.push_str("## Summary\n\n");
        body.push_str(&self.slice.description);
        body.push_str("\n\n");

        // Tasks completed (if slice has tasks)
        if !self.slice.tasks.is_empty() {
            body.push_str("## Changes\n\n");
            for task in &self.slice.tasks {
                body.push_str(&format!("- {}\n", task.title));
            }
            body.push('\n');
        }

        // Files modified
        if !self.files_modified.is_empty() {
            body.push_str("## Files Modified\n\n");
            for file in &self.files_modified {
                body.push_str(&format!("- `{}`\n", file));
            }
            body.push('\n');
        }

        // Issue linking
        if let Some((owner, repo, number)) = &self.issue_ref {
            body.push_str(&format!("Fixes {}/{}#{}\n\n", owner, repo, number));
        }

        // Attribution
        body.push_str("---\n\n");
        body.push_str("*Created by [nexor](https://github.com/nexor) AI agents*\n");

        body
    }
}

impl PrBodyGenerator {
    /// Create from a ticket with GitHub source
    pub fn from_ticket_source(slice: VerticalSlice, source: &TicketSource) -> Self {
        let mut gen = Self::new(slice);

        if let TicketSource::GitHub { owner, repo, issue_number } = source {
            gen = gen.with_issue(owner, repo, *issue_number);
        }

        gen
    }
}
```

### Slice 8.3.3: PR Service Integration

**Do this**:
- Create `PrService` that combines client, body generation, and workflow
- Implement `create_pr_for_slice(slice, ticket, branch)` high-level method
- Determine base branch from config or repo default
- Return PR URL for user feedback
- Handle common errors with helpful messages

**Create/modify**:
- `src/github/pr.rs` - add `PrService`

**Code example**:
```rust
// src/github/pr.rs
use crate::github::GitHubClient;
use crate::types::{Ticket, VerticalSlice, TicketSource};
use anyhow::{Context, Result, bail};
use tracing::info;

pub struct PrService {
    client: GitHubClient,
    default_base: String,
}

impl PrService {
    pub fn new(client: GitHubClient) -> Self {
        Self {
            client,
            default_base: "main".to_string(),
        }
    }

    pub fn with_default_base(mut self, base: &str) -> Self {
        self.default_base = base.to_string();
        self
    }

    /// Create a PR for a completed slice
    pub async fn create_pr_for_slice(
        &self,
        slice: &VerticalSlice,
        ticket: &Ticket,
        branch: &str,
        files_modified: Vec<String>,
    ) -> Result<PrResult> {
        // Extract repo info from ticket source
        let (owner, repo, issue_number) = match &ticket.source {
            TicketSource::GitHub { owner, repo, issue_number } => {
                (owner.clone(), repo.clone(), Some(*issue_number))
            }
            TicketSource::Manual => {
                bail!("cannot create PR for manually created ticket - no GitHub repository associated");
            }
        };

        // Generate PR title
        let title = format!("{}: {}", slice.title, ticket.title);

        // Generate PR body
        let mut body_gen = PrBodyGenerator::new(slice.clone())
            .with_files(files_modified);

        if let Some(num) = issue_number {
            body_gen = body_gen.with_issue(&owner, &repo, num);
        }

        let body = body_gen.generate();

        // Create the PR
        let request = CreatePrRequest::new(&title, &body, branch, &self.default_base);

        info!(
            owner = %owner,
            repo = %repo,
            branch = %branch,
            base = %self.default_base,
            "creating pull request"
        );

        let pr = self.client
            .create_pr(&owner, &repo, request)
            .await
            .context("failed to create pull request")?;

        info!(pr_number = pr.number, url = %pr.html_url, "pull request created");

        Ok(PrResult {
            number: pr.number,
            url: pr.html_url,
            title: pr.title,
        })
    }
}

#[derive(Debug, Clone)]
pub struct PrResult {
    pub number: u32,
    pub url: String,
    pub title: String,
}

impl std::fmt::Display for PrResult {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "PR #{}: {} ({})", self.number, self.title, self.url)
    }
}
```
