# Ticket 8.4: Progress Updates

> Post progress updates to GitHub issues as comments.

## Goal

Implement issue commenting that:
- Posts comments to GitHub issues
- Generates progress summaries from task states
- Auto-comments when milestones are reached
- Provides visibility into agent work on the issue

**Checkpoint**: After agents complete a slice, a comment is posted to the original issue showing progress.

---

## Context

Users who filed GitHub issues want to see progress without checking the nexor TUI. By posting comments back to the issue, we keep stakeholders informed and create an audit trail.

**Key files**:
- `src/github/comments.rs` - Comment posting logic (create)
- `src/github/mod.rs` - Export comment functions (modify)

**Dependencies**:
- Requires 8.1 (GitHub API Client) complete
- Uses task/slice status from internal state

**References**:
- GitHub Comments API: https://docs.github.com/en/rest/issues/comments
- See `ROADMAP.md` Ticket 8.4 for spec

```rust
// src/github/comments.rs
use crate::github::{GitHubClient, GitHubError, GitHubUser};
use serde::{Deserialize, Serialize};
use chrono::{DateTime, Utc};
use anyhow::Result;

#[derive(Debug, Clone, Serialize)]
pub struct CreateCommentRequest {
    pub body: String,
}

impl CreateCommentRequest {
    pub fn new(body: &str) -> Self {
        Self {
            body: body.to_string(),
        }
    }
}

#[derive(Debug, Clone, Deserialize)]
pub struct GitHubComment {
    pub id: u64,
    pub body: String,
    pub user: GitHubUser,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    pub html_url: String,
}

impl GitHubClient {
    /// Add a comment to an issue
    pub async fn add_comment(
        &self,
        owner: &str,
        repo: &str,
        issue_number: u32,
        body: &str,
    ) -> Result<GitHubComment, GitHubError> {
        let url = format!(
            "{}/repos/{}/{}/issues/{}/comments",
            self.base_url, owner, repo, issue_number
        );

        let request = CreateCommentRequest::new(body);

        let response = self.client
            .post(&url)
            .json(&request)
            .send()
            .await
            .map_err(|e| GitHubError::Other(e.into()))?;

        self.handle_response(response).await
    }

    /// Update an existing comment
    pub async fn update_comment(
        &self,
        owner: &str,
        repo: &str,
        comment_id: u64,
        body: &str,
    ) -> Result<GitHubComment, GitHubError> {
        let url = format!(
            "{}/repos/{}/{}/issues/comments/{}",
            self.base_url, owner, repo, comment_id
        );

        let request = CreateCommentRequest::new(body);

        let response = self.client
            .patch(&url)
            .json(&request)
            .send()
            .await
            .map_err(|e| GitHubError::Other(e.into()))?;

        self.handle_response(response).await
    }
}
```

### Slice 8.4.2: Progress Summary Generator

**Do this**:
- Create `ProgressSummary` struct that aggregates task/slice status
- Generate markdown-formatted progress report
- Include:
  - Overall progress (X of Y slices complete)
  - Status of each slice (emoji indicators)
  - Current activity (if any agent is working)
  - Errors/blockers (if any)
- Make output concise but informative

**Create/modify**:
- `src/github/comments.rs` - add `ProgressSummary`

**Code example**:
```rust
// src/github/comments.rs
use crate::types::{Ticket, VerticalSlice, TaskStatus};

pub struct ProgressSummary {
    pub ticket_title: String,
    pub slices: Vec<SliceProgress>,
    pub current_activity: Option<String>,
    pub errors: Vec<String>,
}

pub struct SliceProgress {
    pub title: String,
    pub status: TaskStatus,
    pub task_count: usize,
    pub tasks_completed: usize,
}

impl ProgressSummary {
    pub fn from_ticket(ticket: &Ticket) -> Self {
        let slices = ticket.slices.iter().map(|s| {
            let tasks_completed = s.tasks.iter()
                .filter(|t| t.status == TaskStatus::Completed)
                .count();

            SliceProgress {
                title: s.title.clone(),
                status: s.status.clone(),
                task_count: s.tasks.len(),
                tasks_completed,
            }
        }).collect();

        Self {
            ticket_title: ticket.title.clone(),
            slices,
            current_activity: None,
            errors: Vec::new(),
        }
    }

    pub fn with_activity(mut self, activity: &str) -> Self {
        self.current_activity = Some(activity.to_string());
        self
    }

    pub fn with_error(mut self, error: &str) -> Self {
        self.errors.push(error.to_string());
        self
    }

    pub fn generate_markdown(&self) -> String {
        let mut md = String::new();

        // Header
        md.push_str("## nexor Progress Update\n\n");

        // Overall progress
        let completed = self.slices.iter()
            .filter(|s| s.status == TaskStatus::Completed)
            .count();
        let total = self.slices.len();

        md.push_str(&format!(
            "**Progress:** {} of {} slices complete\n\n",
            completed, total
        ));

        // Progress bar
        let filled = if total > 0 { (completed * 10) / total } else { 0 };
        let bar: String = (0..10)
            .map(|i| if i < filled { '█' } else { '░' })
            .collect();
        md.push_str(&format!("`[{}]` {}%\n\n", bar, (completed * 100) / total.max(1)));

        // Slice status
        md.push_str("### Slices\n\n");
        for slice in &self.slices {
            let emoji = match slice.status {
                TaskStatus::Completed => "✅",
                TaskStatus::InProgress => "🔄",
                TaskStatus::Review => "👀",
                TaskStatus::Failed => "❌",
                TaskStatus::Pending => "⏳",
            };

            md.push_str(&format!(
                "{} **{}** ({}/{})\n",
                emoji, slice.title, slice.tasks_completed, slice.task_count
            ));
        }
        md.push('\n');

        // Current activity
        if let Some(ref activity) = self.current_activity {
            md.push_str(&format!("**Currently:** {}\n\n", activity));
        }

        // Errors
        if !self.errors.is_empty() {
            md.push_str("### Issues\n\n");
            for error in &self.errors {
                md.push_str(&format!("- ⚠️ {}\n", error));
            }
            md.push('\n');
        }

        // Footer
        md.push_str("---\n");
        md.push_str("*Updated by [nexor](https://github.com/nexor)*\n");

        md
    }
}
```

### Slice 8.4.3: Auto-Comment on Milestones

**Do this**:
- Create `CommentService` that wraps client and progress generation
- Implement hooks for key events:
  - `on_work_started(ticket)` - Initial "work has begun" comment
  - `on_slice_completed(ticket, slice)` - Progress update
  - `on_ticket_completed(ticket, pr_url)` - Final "done" comment with PR link
- Store comment ID to update existing comment vs. posting new ones
- Configure comment frequency (avoid spam)

**Create/modify**:
- `src/github/comments.rs` - add `CommentService`

**Code example**:
```rust
// src/github/comments.rs
use crate::github::GitHubClient;
use crate::types::{Ticket, VerticalSlice, TicketSource};
use anyhow::{Context, Result, bail};
use tracing::info;
use std::collections::HashMap;

pub struct CommentService {
    client: GitHubClient,
    // Track comment IDs for updating instead of creating new
    progress_comments: HashMap<uuid::Uuid, u64>,  // ticket_id -> comment_id
}

impl CommentService {
    pub fn new(client: GitHubClient) -> Self {
        Self {
            client,
            progress_comments: HashMap::new(),
        }
    }

    fn get_issue_ref(&self, ticket: &Ticket) -> Result<(String, String, u32)> {
        match &ticket.source {
            TicketSource::GitHub { owner, repo, issue_number } => {
                Ok((owner.clone(), repo.clone(), *issue_number))
            }
            TicketSource::Manual => {
                bail!("cannot comment on manually created ticket - no GitHub issue associated")
            }
        }
    }

    /// Post initial comment when work begins
    pub async fn on_work_started(&mut self, ticket: &Ticket) -> Result<()> {
        let (owner, repo, number) = self.get_issue_ref(ticket)?;

        let body = format!(
            "## 🤖 nexor is working on this\n\n\
            I've started working on this issue. I'll post updates as slices are completed.\n\n\
            **Planned slices:** {}\n\n\
            ---\n*Automated by [nexor](https://github.com/nexor)*",
            ticket.slices.len()
        );

        let comment = self.client
            .add_comment(&owner, &repo, number, &body)
            .await
            .context("failed to post start comment")?;

        // Store comment ID for future updates
        self.progress_comments.insert(ticket.id, comment.id);

        info!(ticket_id = %ticket.id, comment_id = comment.id, "posted work started comment");

        Ok(())
    }

    /// Update progress when a slice is completed
    pub async fn on_slice_completed(&mut self, ticket: &Ticket, _slice: &VerticalSlice) -> Result<()> {
        let (owner, repo, number) = self.get_issue_ref(ticket)?;

        let summary = ProgressSummary::from_ticket(ticket);
        let body = summary.generate_markdown();

        // Check if we have an existing comment to update
        if let Some(&comment_id) = self.progress_comments.get(&ticket.id) {
            self.client
                .update_comment(&owner, &repo, comment_id, &body)
                .await
                .context("failed to update progress comment")?;

            info!(ticket_id = %ticket.id, comment_id, "updated progress comment");
        } else {
            // Create new comment
            let comment = self.client
                .add_comment(&owner, &repo, number, &body)
                .await
                .context("failed to post progress comment")?;

            self.progress_comments.insert(ticket.id, comment.id);

            info!(ticket_id = %ticket.id, comment_id = comment.id, "posted new progress comment");
        }

        Ok(())
    }

    /// Post final comment when ticket is complete
    pub async fn on_ticket_completed(&mut self, ticket: &Ticket, pr_url: Option<&str>) -> Result<()> {
        let (owner, repo, number) = self.get_issue_ref(ticket)?;

        let pr_section = if let Some(url) = pr_url {
            format!("\n\n**Pull Request:** {}", url)
        } else {
            String::new()
        };

        let body = format!(
            "## ✅ Work Complete\n\n\
            All slices have been completed for this issue.{}\n\n\
            ---\n*Automated by [nexor](https://github.com/nexor)*",
            pr_section
        );

        self.client
            .add_comment(&owner, &repo, number, &body)
            .await
            .context("failed to post completion comment")?;

        // Remove from tracking
        self.progress_comments.remove(&ticket.id);

        info!(ticket_id = %ticket.id, "posted completion comment");

        Ok(())
    }
}
```

## Notes

- **Comment frequency**: We update a single progress comment rather than posting many. This avoids spamming the issue.
- **Persistence**: `progress_comments` map is in-memory. For persistence across restarts, would need to store in database or search for existing nexor comments.
- **Rate limiting**: Comment updates share the same API rate limit. Should be fine for normal usage.
- **Formatting**: Markdown rendering depends on GitHub. Test that emojis and progress bar display correctly.
- **Opt-out**: Could add config option to disable auto-commenting. Deferred.
- **Mentions**: Could @mention issue author on completion. Deferred.
