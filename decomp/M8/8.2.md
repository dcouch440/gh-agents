# Ticket 8.2: Issue Sync

> Pull GitHub issues and convert them to internal Ticket format.

## Goal

Implement issue synchronization that:
- Converts GitHub issues to internal `Ticket` type
- Provides a `/sync` command to pull issues by URL
- Detects and handles already-synced issues
- Stores synced tickets in the database

**Checkpoint**: Can run `/sync https://github.com/owner/repo/issues/123` and see the issue appear as a ticket.

---

## Context

This connects GitHub issues to the nexor workflow. Once synced, an issue becomes a Ticket that the orchestrator can decompose into slices for agents to work on.

**Key files**:
- `src/github/issue_sync.rs` - Sync logic (create)
- `src/github/mod.rs` - Export sync functions (modify)
- `src/types/ticket.rs` - Ticket type (from M1, reference)

**Dependencies**:

- Uses database from M1.4

```rust
// src/github/issue_sync.rs
use crate::github::types::GitHubIssue;
use crate::types::{Ticket, TicketSource, TicketStatus};
use uuid::Uuid;

pub fn convert_issue_to_ticket(
    issue: GitHubIssue,
    owner: &str,
    repo: &str,
) -> Ticket {
    Ticket {
        id: Uuid::new_v4(),
        source: TicketSource::GitHub {
            owner: owner.to_string(),
            repo: repo.to_string(),
            issue_number: issue.number,
        },
        title: issue.title,
        description: issue.body.unwrap_or_default(),
        labels: issue.labels.into_iter().map(|l| l.name).collect(),
        slices: Vec::new(),  // Will be populated by orchestrator
        status: TicketStatus::New,
        created_at: issue.created_at,
    }
}
```

### Slice 8.2.2: Sync Issue Command

**Do this**:
- Create `IssueSync` service struct that wraps `GitHubClient` and database
- Implement `sync_issue_by_url(url: &str) -> Result<Ticket>`
- Parse GitHub URL to extract owner, repo, issue number
- Fetch issue from API
- Convert to Ticket
- Save to database
- Support URLs in formats:
  - `https://github.com/owner/repo/issues/123`
  - `github.com/owner/repo/issues/123`
  - `owner/repo#123`

**Create/modify**:
- `src/github/issue_sync.rs` - add `IssueSync` and URL parsing

**Code example**:
```rust
// src/github/issue_sync.rs
use crate::github::GitHubClient;
use crate::db::Database;
use anyhow::{Context, Result, bail};
use regex::Regex;

pub struct IssueSync {
    client: GitHubClient,
    db: Database,
}

#[derive(Debug, Clone)]
pub struct IssueRef {
    pub owner: String,
    pub repo: String,
    pub number: u32,
}

impl IssueSync {
    pub fn new(client: GitHubClient, db: Database) -> Self {
        Self { client, db }
    }

    /// Parse various GitHub issue URL formats
    pub fn parse_issue_url(url: &str) -> Result<IssueRef> {
        // Format: https://github.com/owner/repo/issues/123
        let full_url_re = Regex::new(
            r"(?:https?://)?github\.com/([^/]+)/([^/]+)/issues/(\d+)"
        ).unwrap();

        if let Some(caps) = full_url_re.captures(url) {
            return Ok(IssueRef {
                owner: caps[1].to_string(),
                repo: caps[2].to_string(),
                number: caps[3].parse().context("invalid issue number")?,
            });
        }

        // Format: owner/repo#123
        let short_re = Regex::new(r"^([^/]+)/([^#]+)#(\d+)$").unwrap();

        if let Some(caps) = short_re.captures(url) {
            return Ok(IssueRef {
                owner: caps[1].to_string(),
                repo: caps[2].to_string(),
                number: caps[3].parse().context("invalid issue number")?,
            });
        }

        bail!("invalid issue URL format: {}", url);
    }

    pub async fn sync_issue_by_url(&self, url: &str) -> Result<Ticket> {
        let issue_ref = Self::parse_issue_url(url)?;

        // Fetch from GitHub
        let github_issue = self.client
            .get_issue(&issue_ref.owner, &issue_ref.repo, issue_ref.number)
            .await
            .context("failed to fetch issue from GitHub")?;

        // Convert to internal Ticket
        let ticket = convert_issue_to_ticket(
            github_issue,
            &issue_ref.owner,
            &issue_ref.repo,
        );

        // Save to database
        self.db.insert_ticket(&ticket).await
            .context("failed to save ticket to database")?;

        Ok(ticket)
    }
}
```

### Slice 8.2.3: Duplicate Detection

**Do this**:
- Before inserting, check if ticket with same GitHub source already exists
- Implement `find_ticket_by_github_source(owner, repo, number)` database query
- If exists, update instead of insert (or return existing with warning)
- Add `updated_at` tracking for synced tickets

**Create/modify**:
- `src/github/issue_sync.rs` - add duplicate checking
- `src/db/queries.rs` - add query for finding by source (or inline in issue_sync)

**Code example**:
```rust
// src/github/issue_sync.rs - update sync_issue_by_url
impl IssueSync {
    pub async fn sync_issue_by_url(&self, url: &str) -> Result<SyncResult> {
        let issue_ref = Self::parse_issue_url(url)?;

        // Check for existing ticket
        let existing = self.db
            .find_ticket_by_github_source(
                &issue_ref.owner,
                &issue_ref.repo,
                issue_ref.number,
            )
            .await?;

        // Fetch fresh data from GitHub
        let github_issue = self.client
            .get_issue(&issue_ref.owner, &issue_ref.repo, issue_ref.number)
            .await
            .context("failed to fetch issue from GitHub")?;

        if let Some(mut existing_ticket) = existing {
            // Update existing ticket
            existing_ticket.title = github_issue.title.clone();
            existing_ticket.description = github_issue.body.clone().unwrap_or_default();
            existing_ticket.labels = github_issue.labels.iter().map(|l| l.name.clone()).collect();

            self.db.update_ticket(&existing_ticket).await?;

            return Ok(SyncResult::Updated(existing_ticket));
        }

        // Create new ticket
        let ticket = convert_issue_to_ticket(
            github_issue,
            &issue_ref.owner,
            &issue_ref.repo,
        );

        self.db.insert_ticket(&ticket).await?;

        Ok(SyncResult::Created(ticket))
    }
}

#[derive(Debug)]
pub enum SyncResult {
    Created(Ticket),
    Updated(Ticket),
}

impl SyncResult {
    pub fn ticket(&self) -> &Ticket {
        match self {
            SyncResult::Created(t) => t,
            SyncResult::Updated(t) => t,
        }
    }

    pub fn is_new(&self) -> bool {
        matches!(self, SyncResult::Created(_))
    }
}

// Database query (in src/db/queries.rs or inline)
impl Database {
    pub async fn find_ticket_by_github_source(
        &self,
        owner: &str,
        repo: &str,
        issue_number: u32,
    ) -> Result<Option<Ticket>> {
        // Query tickets table where source matches
        // source is stored as JSON or separate columns
        sqlx::query_as!(
            TicketRow,
            r#"
            SELECT * FROM tickets
            WHERE source_type = 'github'
              AND source_owner = ?
              AND source_repo = ?
              AND source_issue_number = ?
            "#,
            owner,
            repo,
            issue_number
        )
        .fetch_optional(&self.pool)
        .await
        .context("failed to query for existing ticket")
        .map(|opt| opt.map(|row| row.into()))
    }
}
```
