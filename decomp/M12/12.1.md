# Ticket 12.1: CLI Scaffolding

> Set up the TypeScript + Ink project structure for the terminal CLI.

## Goal

A working Ink app that renders "hello world" in the terminal with proper TypeScript compilation.

**Checkpoint**: `cd cli && npm run dev` renders an Ink component in the terminal.

---

## Context

Ink is React for CLIs — same component model, hooks, JSX, but renders to the terminal instead of a browser. We use it because it's the same approach Claude Code takes.

**Key files**:
- `cli/package.json` - Package config
- `cli/tsconfig.json` - TypeScript config
- `cli/src/index.tsx` - Entry point
- `cli/src/App.tsx` - Root component

**Dependencies**:
- M10 (server must be running for later tickets)

**References**:
- Ink docs: https://github.com/vadimdemedes/ink
- Claude Code uses a similar terminal rendering approach

---

- Create `cli/` directory at repo root
- Create `package.json` with dependencies
- Create `.gitignore` for `node_modules/` and `dist/`

### Slice 12.1.2: TypeScript Configuration

**Do this**:
- Create `tsconfig.json` configured for Ink (JSX, ESM, React)

**Create `cli/tsconfig.json`**:
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "jsx": "react-jsx",
    "outDir": "dist",
    "rootDir": "src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "declaration": true,
    "declarationMap": true,
    "sourceMap": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

**Verify**:
- [ ] `cd cli && npx tsc --noEmit` passes (after source files exist)

### Slice 12.1.3: Entry Point and Root Component

**Do this**:
- Create the entry point that renders the Ink app
- Create a minimal App component that shows a welcome message
- Create the CLI bin script

**Create `cli/src/index.tsx`**:
```tsx
import { render } from 'ink';
import { App } from './App.js';

render(<App />);
```

**Create `cli/src/App.tsx`**:
```tsx
import { Box, Text } from 'ink';

export function App() {
  return (
    <Box flexDirection="column" padding={1}>
      <Text bold color="cyan">nexor</Text>
      <Text dimColor>AI agent orchestration for GitHub workflows</Text>
    </Box>
  );
}
```

**Create `cli/bin/nexor.js`**:
```js
#!/usr/bin/env node
import '../dist/index.js';
```

**Verify**:
- [ ] `cd cli && npm run dev` shows "nexor" heading in terminal
- [ ] Process exits cleanly with Ctrl+C
