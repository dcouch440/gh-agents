# Ticket 12.5: Streaming & SSE

> Stream assistant responses token-by-token in the terminal.

## Goal

When the user sends a message, the assistant's response streams in real-time — tokens appear one by one, like Claude Code's typing effect.

**Checkpoint**: Send a message → see response appear token-by-token → final message saved to history.

---

## Context

The backend uses Server-Sent Events (SSE) for streaming chat responses. After `POST /api/chat` returns a `message_id`, the CLI connects to `GET /api/chat/{message_id}/stream` and receives `token` events with text chunks, then a `done` event.

**Key files**:
- `cli/src/hooks/useChat.ts` - Chat hook (from 12.4)
- `cli/src/api/client.ts` - API client (from 12.2)
- `src/server/api.rs` - SSE endpoint (lines 350-433)

**Dependencies**:
- 12.4 (chat UI components)

---

## Slices

### Slice 12.5.1: SSE Client

**Do this**:
- Create an SSE client function that connects to the stream endpoint
- Parse `token`, `done`, and `error` events
- Call provided callbacks for each event type
- Handle connection errors and cleanup

**Create `cli/src/api/stream.ts`**:
```typescript
interface StreamCallbacks {
  onToken: (text: string) => void;
  onDone: () => void;
  onError: (error: string) => void;
}

export function streamResponse(
  baseUrl: string,
  messageId: string,
  token: string,
  callbacks: StreamCallbacks
): () => void  // returns cleanup function
```

Use the `eventsource` package for SSE in Node.js. Set the `Authorization` header for auth.
