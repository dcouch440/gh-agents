# Ticket 15.4: Prompt Library Frontend

> React UI for browsing, creating, editing, tagging, and launching saved prompts.

## Goal

Users can manage a library of reusable prompts with search, tags, categories, version history, and one-click launch to agent chat.

**Checkpoint**: Can create a prompt, tag it, find it via search, view its history, and launch it to start a chat session.

---

## Context

Backend endpoints from ticket 15.2 provide the data.

**Key files**:
- `ui/src/pages/` — New PromptsPage

- `ui/src/api/client.ts` — Add prompt API methods
