# Ticket 15.4: Prompt Library Frontend

> React UI for browsing, creating, editing, tagging, and launching saved prompts.

## Goal

Users can manage a library of reusable prompts with search, tags, categories, version history, and one-click launch to agent chat.

**Checkpoint**: Can create a prompt, tag it, find it via search, view its history, and launch it to start a chat session.

---

### Slice 15.4.5: Quick Launch with Auto-Fill Variables

**Do this**:
- "Launch" button on prompt card and detail view
- On launch, call `GET /api/prompts/variables` to get current system state
- Show a launch dialog with the prompt's `{{variables}}` listed:
  - **Auto-filled variables** shown as pre-populated read-only fields with a green check and source label (e.g., "from active repo", "from current task")
  - **Overridable** — user can click an auto-filled field to unlock and change it
  - **Unresolved variables** shown as empty text inputs the user must fill in (e.g., task vars when not launched from a task context)
  - **No variables** — skip the dialog entirely, launch immediately
- Live preview panel below the form showing the fully resolved prompt text, updating as the user edits overrides
- Keyboard shortcut: `Ctrl+Enter` to launch from editor or dialog
- Launch navigates to chat view with the resolved prompt already sent
- Context passthrough: if launched from a task detail page, auto-pass `task_id` so task variables resolve; same for agent context

**Create/modify**:
- `ui/src/components/PromptLauncher.tsx`
- `ui/src/hooks/usePromptVariables.ts` — fetches available variables, merges with prompt template
- Update routing to support navigation with prompt payload and launch context

**Verify**:
- [ ] Auto-filled variables show with current values
- [ ] User can override auto-filled values
- [ ] Unresolved variables require manual input
- [ ] Live preview updates in real-time
- [ ] Launch sends resolved prompt to chat
