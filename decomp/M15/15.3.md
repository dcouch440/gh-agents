# Ticket 15.3: Multi-Repo Frontend

> React UI for adding, switching, and monitoring multiple repositories.

## Goal

Users can manage repos from the UI — add local paths or clone remotes, switch active repo from the header, and see per-repo status at a glance.

**Checkpoint**: Can add a repo, see it in the list, switch to it, and see the file tree update.

---

## Context

Backend endpoints from ticket 15.1 provide the data. This ticket builds the UI.

**Key files**:
- `ui/src/pages/` — New ReposPage
- `ui/src/components/` — RepoSwitcher, RepoCard
- `ui/src/api/client.ts` — Add repo API methods
- `ui/src/store/` — Add repo store

**Dependencies**:
- Requires 15.1 (Multi-Repo Backend) complete
- Requires M11.4 (Layout Components) complete
