# Ticket 6.4: Feed View (/feed)

> Real-time agent activity feed with natural language updates.

## Goal

Create the `/feed` view that shows:
- Scrollable list of agent activity
- Different styling for different item types (report, milestone, error)
- Auto-scroll to bottom when new items arrive
- Read-only (no sending messages, just viewing)

**Checkpoint**: Can switch to `/feed` view and see agent activity items with different styles.

---

## Context

The feed is where users observe agent work in progress. Items appear in real-time as agents report their activity. The feed is read-only - users don't interact with it directly.

### Slice 6.4.2: Feed Item Rendering

**Do this**:
- Implement `Widget` trait for `FeedView`
- Render each item with:
  - Type indicator: `●` for reports, `★` for milestones, `✗` for errors
  - Agent name prefix (e.g., "Worker 1:")
  - Content text
- Apply different colors based on `FeedItemType`
- Handle empty state (show "No activity yet")

**Create/modify**:
- `src/tui/views/feed.rs` - implement Widget trait

**Code example**:
```rust
// src/tui/views/feed.rs - add Widget implementation
impl Widget for FeedView {
    fn render(self, area: Rect, buf: &mut Buffer) {
        if self.items.is_empty() {
            let empty_msg = "No agent activity yet. Start a task to see updates here.";
            let x = area.x + 2;
            let y = area.y + area.height / 2;
            buf.set_string(x, y, empty_msg, Style::default().fg(Color::DarkGray));
            return;
        }

        let items: Vec<ListItem> = self
            .items
            .iter()
            .map(|item| {
                let (icon, style) = match item.item_type {
                    FeedItemType::AgentReport => ("●", Style::default().fg(Color::White)),
                    FeedItemType::TaskStarted => ("▶", Style::default().fg(Color::Blue)),
                    FeedItemType::TaskCompleted => ("✓", Style::default().fg(Color::Green)),
                    FeedItemType::Milestone => ("★", Style::default().fg(Color::Yellow).add_modifier(Modifier::BOLD)),
                    FeedItemType::Error => ("✗", Style::default().fg(Color::Red)),
                    FeedItemType::SystemNotice => ("ℹ", Style::default().fg(Color::Cyan)),
                };

                let line = Line::from(vec![
                    Span::styled(format!("{} ", icon), style),
                    Span::styled(format!("{}: ", item.agent_name), Style::default().fg(Color::Cyan)),
                    Span::raw(&item.content),
                ]);

                ListItem::new(line)
            })
            .collect();

        let list = List::new(items);
        Widget::render(list, area, buf);
    }
}
```

// src/tui/views/feed.rs - update FeedView
impl FeedView {
    pub fn scroll_to_bottom(&mut self, visible_height: usize) {
        if self.items.len() > visible_height {
            self.scroll_offset = self.items.len() - visible_height;
        } else {
            self.scroll_offset = 0;
        }
    }

    pub fn scroll_up(&mut self, amount: usize) {
        self.scroll_offset = self.scroll_offset.saturating_sub(amount);
    }

    pub fn scroll_down(&mut self, amount: usize, max: usize) {
        self.scroll_offset = (self.scroll_offset + amount).min(max);
    }
}

## Notes

- **Read-only view**: Users don't type in feed view. Input bar is inactive or hidden.
- **Performance**: For large feeds, consider limiting stored items (e.g., last 1000).
- **Timestamp display**: Not shown in initial version. Can add later as "2m ago" style.
- **Channel buffer size**: 100 is reasonable. Items won't be lost if briefly not rendered.
- **Mock data**: Remove or reduce mock items before production.
- **Unicode icons**: `●★✗✓▶ℹ` - ensure terminal supports these. Fallback to ASCII if needed.
