# Ticket 6.6: Slash Command Router

> Parse and route slash commands to appropriate handlers.

## Goal

Implement command parsing for slash commands:
- Detect `/` prefix in input
- Parse command name and arguments
- Route to appropriate view or action
- Show error for unknown commands

**Checkpoint**: Can type `/feed`, `/main`, `/home`, `/logs` to switch views. Unknown commands show error.

---

Slash commands provide quick navigation and actions. They're the primary way users switch between views and trigger actions.

### Slice 6.6.1: Command Parser

**Do this**:
- Create `src/tui/commands.rs`
- Define `Command` enum with all supported commands
- Implement `parse(input: &str) -> Result<Command, CommandError>`
- Handle command arguments where needed
- Export from `src/tui/mod.rs`

**Create/modify**:
- `src/tui/commands.rs`
- `src/tui/mod.rs`

**Code example**:
```rust
// src/tui/commands.rs
use thiserror::Error;

#[derive(Debug, Clone, PartialEq)]
pub enum Command {
    // Navigation
    Home,
    Main,
    Feed,
    Logs,
    Tasks,
    Agents,
    Costs,

    // Actions
    Help,
    Quit,
}

#[derive(Error, Debug)]
pub enum CommandError {
    #[error("unknown command: {0}")]
    Unknown(String),

    #[error("invalid arguments for {command}: {message}")]
    InvalidArgs { command: String, message: String },
}

pub fn parse(input: &str) -> Result<Command, CommandError> {
    let input = input.trim();

    // Must start with /
    if !input.starts_with('/') {
        return Err(CommandError::Unknown(input.to_string()));
    }

    // Split into command and args
    let parts: Vec<&str> = input[1..].splitn(2, ' ').collect();
    let cmd = parts[0].to_lowercase();
    let _args = parts.get(1).map(|s| s.trim()).unwrap_or("");

    match cmd.as_str() {
        "home" => Ok(Command::Home),
        "main" => Ok(Command::Main),
        "feed" => Ok(Command::Feed),
        "logs" => Ok(Command::Logs),
        "tasks" => Ok(Command::Tasks),
        "agents" => Ok(Command::Agents),
        "costs" => Ok(Command::Costs),
        "help" | "?" => Ok(Command::Help),
        "quit" | "q" | "exit" => Ok(Command::Quit),
        _ => Err(CommandError::Unknown(cmd)),
    }
}

impl Command {
    pub fn description(&self) -> &'static str {
        match self {
            Command::Home => "Return to home screen",
            Command::Main => "Chat with orchestrator",
            Command::Feed => "View agent activity feed",
            Command::Logs => "View technical logs",
            Command::Tasks => "View task queue",
            Command::Agents => "View agent status",
            Command::Costs => "View cost breakdown",
            Command::Help => "Show available commands",
            Command::Quit => "Exit nexor",
        }
    }
}
```

- [ ] `/home` parses to `Command::Home`
- [ ] `/FEED` (uppercase) parses to `Command::Feed`
- [ ] `/unknown` returns `CommandError::Unknown`

### Slice 6.6.2: Detect Command Input

**Do this**:
- Check if input buffer starts with `/` before submission
- If it's a command, parse and route instead of sending to chat
- If not a command, proceed with normal handling

**Create/modify**:
- `src/tui/app.rs` - add command detection in Enter handler

**Code example**:
```rust
// src/tui/app.rs
use crate::tui::commands::{self, Command, CommandError};

impl App {
    fn handle_input_submit(&mut self) {
        let input = self.input_buffer.trim().to_string();
        if input.is_empty() {
            return;
        }

        if input.starts_with('/') {
            self.handle_command(&input);
        } else {
            self.handle_chat_input();
        }

        self.input_buffer.clear();
    }

    fn handle_command(&mut self, input: &str) {
        match commands::parse(input) {
            Ok(cmd) => self.execute_command(cmd),
            Err(e) => self.show_error(&e.to_string()),
        }
    }

    fn handle_chat_input(&mut self) {
        // Existing chat submission logic
        if self.current_view == CurrentView::Home {
            self.current_view = CurrentView::Chat;
        }
        self.submit_chat_message();
    }
}
```

```rust
// src/tui/app.rs
impl App {
    fn execute_command(&mut self, cmd: Command) {
        match cmd {
            Command::Home => {
                self.current_view = CurrentView::Home;
            }
            Command::Main => {
                self.current_view = CurrentView::Chat;
            }
            Command::Feed => {
                self.current_view = CurrentView::Feed;
            }
            Command::Logs => {
                self.current_view = CurrentView::Logs;
            }
            Command::Tasks | Command::Agents | Command::Costs => {
                self.show_error("This view is not yet implemented");
            }
            Command::Help => {
                self.show_help();
            }
            Command::Quit => {
                self.should_quit = true;
            }
        }
    }

    fn show_help(&mut self) {
        // Could show in a modal or switch to a help view
        // For now, add help text to chat or feed
        let help_text = [
            "Available commands:",
            "  /home   - Return to home screen",
            "  /main   - Chat with orchestrator",
            "  /feed   - View agent activity",
            "  /logs   - View technical logs",
            "  /help   - Show this help",
            "  /quit   - Exit nexor",
        ].join("\n");

        // Add as system message to feed
        self.feed.push(FeedItem::new(
            "System",
            &help_text,
            FeedItemType::SystemNotice
        ));

        // Switch to feed to show help
        self.current_view = CurrentView::Feed;
    }

    fn show_error(&mut self, message: &str) {
        self.feed.push(FeedItem::new(
            "System",
            message,
            FeedItemType::Error
        ));
        // Optionally flash the input bar or show inline
    }
}
```

```rust
// src/tui/input.rs - update InputBar
pub struct InputBar {
    pub input: String,
    pub cursor_position: usize,
    pub error_message: Option<String>,
}

impl Widget for InputBar {
    fn render(self, area: Rect, buf: &mut Buffer) {
        // First line: prompt and input (existing)
        let prompt = "> ";
        buf.set_string(area.x, area.y, prompt, Style::default());
        buf.set_string(
            area.x + prompt.len() as u16,
            area.y,
            &self.input,
            Style::default(),
        );

        // Cursor
        let cursor_x = area.x + prompt.len() as u16 + self.cursor_position as u16;
        if cursor_x < area.right() && self.input.len() == self.cursor_position {
            buf.set_string(cursor_x, area.y, "_", Style::default().fg(Color::Gray));
        }

        // Second line: error or hints
        if let Some(ref error) = self.error_message {
            buf.set_string(
                area.x,
                area.y + 1,
                error,
                Style::default().fg(Color::Red),
            );
        }
    }
}
```
