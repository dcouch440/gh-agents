# Ticket 13.2: Agent Types & State

> TypeScript types for agents/tasks/pools, plus a `useAgents` hook managing state from WebSocket and REST.

## Goal

A `useAgents` hook that provides the complete agent grid state: agents with status, tasks with progress, and pool statistics. Combines initial REST fetch with real-time WebSocket deltas.

**Checkpoint**: `useAgents()` returns typed agent data that updates in real time when agent status changes.

---

## Context

Two data sources:
1. `GET /api/agents` — Initial snapshot with agents list and pool stats
2. WebSocket `agent_update` / `task_update` — Real-time deltas

The hook loads initial state via REST, then applies WebSocket deltas to keep state current.

**Key files**:
- `cli/src/api/ws-client.ts` - WebSocket client (from 13.1)
- `cli/src/api/ws-types.ts` - WebSocket message types (from 13.1)
- `cli/src/api/client.ts` - REST API client (from M12)
- `cli/src/api/types.ts` - Existing types (from M12)

**Dependencies**:
- 13.1 (WebSocket client)

### Slice 13.2.1: Agent & Pool Types

**Do this**:
- Define TypeScript types for the agent grid state

**Create `cli/src/types/agents.ts`**:
```typescript
import type { AgentStatus, TaskStatus } from '../api/ws-types.js';

export type AgentTier = 'orchestrator' | 'worker' | 'utility';

export interface Agent {
  id: string;
  name: string;
  status: AgentStatus;
  tier: AgentTier;
  currentTask: AgentTask | null;
}

export interface AgentTask {
  id: string;
  title: string;
  status: TaskStatus;
  progress: number;
}

export interface PoolStats {
  total: number;
  available: number;
  max: number;
}

export interface AgentPoolSummary {
  orchestrators: PoolStats;
  workers: PoolStats;
  utilities: PoolStats;
}

export interface AgentGridState {
  agents: Agent[];
  stats: AgentPoolSummary;
  connected: boolean;
  loading: boolean;
}
```
