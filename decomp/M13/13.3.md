# Ticket 13.3: Agent Station Widget

> Single agent rendered as a Unicode "station" box with name, status icon, task label, progress bar, and status coloring.

## Goal

An `AgentStation` Ink component that renders one agent as a bordered Unicode box with live status. This is the atomic building block of the grid.

**Checkpoint**: `<AgentStation agent={...} />` renders a 32-char-wide box with name, status icon, task, and progress bar.

---

## Context

Each agent is a fixed "station" — a Unicode box-drawing bordered box. The Factorio inspiration means static positions, not moving elements. Claude Code aesthetic: monochrome, dim for inactive, minimal.

**Key files**:
- `cli/src/types/agents.ts` - Agent types (from 13.2)
- `cli/src/components/` - Existing components directory

**Dependencies**:
- 13.2 (types and state)

**Design**:
