# Ticket 13.5: Screen Navigation

> Tab/keybind system to switch between Chat view and Agent view, with a status bar.

## Goal

Users can press Tab to toggle between Chat and Agent View screens. A status bar at the bottom shows the current screen and available keybinds.

**Checkpoint**: Press Tab → switch from Chat to Agent grid and back. Status bar updates to reflect current view.

---

## Context

M12 built Chat as the only screen. We now need a screen router in `App.tsx` that conditionally renders Chat or Agent Grid, toggled by Tab. Both views stay mounted (hidden via `display: none`) to preserve state when switching.

**Key files**:
- `cli/src/App.tsx` - Root component, currently renders ChatView
- `cli/src/components/ChatView.tsx` - Chat view (from M12)
- `cli/src/components/agent/AgentGrid.tsx` - Agent grid (from 13.4)
- `cli/src/hooks/useAgents.ts` - Agent state (from 13.2)

**Dependencies**:
- 13.4 (agent grid layout)

---
