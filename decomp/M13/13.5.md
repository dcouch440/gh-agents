# nexor

AI Agent Orchestration for GitHub Workflows

## Overview

nexor orchestrates multiple AI agents to handle software engineering tasks.
Built with a Rust backend (Axum) and React frontend.

## Features

- **Chat Interface** - Natural language interaction with AI agents
- **Real-time Feed** - Watch agents work in real-time
- **Task Management** - Create, track, and manage tasks
- **Agent Pool** - Monitor agent status and utilization
- **File Browser** - Browse and edit project files
- **Diff Viewer** - Review changes made by agents
- **Analytics** - Track performance and costs

## Quick Start

### Prerequisites

- Rust 1.75+
- Node.js 20+
- Anthropic API key

### Installation

```bash
# Clone the repository
git clone https://github.com/your-org/nexor.git
cd nexor

# Build UI
cd ui && npm install && npm run build && cd ..

# Build and run
cargo run --release
```

### Configuration

Create `.nexor/config.toml`:

```toml
[server]
host = "127.0.0.1"
port = 8080

[auth]
# Set via environment: NEXOR_AUTH_PASSWORD
session_timeout_hours = 24

[llm]
default_provider = "anthropic"
# Set via environment: ANTHROPIC_API_KEY
```

### Docker

```bash
docker build -t nexor .
docker run -p 8080:8080 \
  -e ANTHROPIC_API_KEY=your-key \
  -e NEXOR_AUTH_PASSWORD=your-password \
  nexor
```

# nexor API Reference

Base URL: `http://localhost:8080`

## Authentication

All API endpoints (except `/api/auth/login`) require authentication.

Include the JWT token in requests:
```
Authorization: Bearer <token>
```

### POST /api/auth/login

Authenticate and receive a JWT token.

**Request:**
```json
{
  "password": "your-password"
}
```

**Response:**
```json
{
  "token": "eyJ...",
  "expires_at": "2024-01-28T12:00:00Z"
}
```

---

## Chat

### POST /api/chat

Send a message and receive AI response.

**Request:**
```json
{
  "message": "Help me fix the bug in auth.rs",
  "context": {
    "files": ["src/auth.rs"]
  }
}
```

**Response (streaming):**
```
data: {"type":"start","id":"msg_123"}
data: {"type":"content","text":"Looking at "}
data: {"type":"content","text":"auth.rs..."}
data: {"type":"done","id":"msg_123"}
```

## Tasks

### GET /api/tasks

List all tasks.

**Query Parameters:**
- `status` - Filter by status (pending, in_progress, completed, failed)
- `limit` - Max results (default: 50)
- `offset` - Pagination offset

**Response:**
```json
{
  "tasks": [
    {
      "id": "task_123",
      "title": "Fix authentication bug",
      "description": "...",
      "status": "in_progress",
      "priority": "high",
      "assigned_agent": "worker-1",
      "created_at": "2024-01-27T10:00:00Z"
    }
  ],
  "total": 42
}
```

### POST /api/tasks

Create a new task.

**Request:**
```json
{
  "title": "Implement feature X",
  "description": "...",
  "priority": "medium"
}
```

### GET /api/tasks/:id

Get task details.

### PUT /api/tasks/:id

Update task.

### DELETE /api/tasks/:id

Delete task.

## WebSocket

Connect to `/ws` for real-time updates.

### Subscribe to Channels

```json
{"type":"subscribe","channels":["feed","tasks","agents"]}
```

### Message Types

**Feed Event:**
```json
{
  "type": "feed",
  "data": {
    "id": "evt_123",
    "agent": "worker-1",
    "content": "Reading file src/main.rs",
    "type": "report",
    "timestamp": "2024-01-27T10:00:00Z"
  }
}
```

**Task Update:**
```json
{
  "type": "task_update",
  "data": {
    "id": "task_123",
    "status": "completed"
  }
}
```

**Agent Update:**
```json
{
  "type": "agent_update",
  "data": {
    "id": "worker-1",
    "status": "idle",
    "current_task": null
  }
}
```

## Error Responses

All errors follow this format:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or expired token"
  }
}
```

Common error codes:
- `UNAUTHORIZED` - Authentication required or failed
- `NOT_FOUND` - Resource not found
- `VALIDATION_ERROR` - Invalid request data
- `INTERNAL_ERROR` - Server error
```
