# Ticket 22.5: Worker Client Protocol

> Host-side client that the orchestrator uses to communicate with containerized agent workers.

## Goal

`WorkerClient` connects to a running agent container's worker process and provides an async API for assigning tasks, streaming progress, and collecting results. This is the orchestrator's view of a containerized agent.

### 22.5.1: WorkerClient struct and connection

```rust
pub struct WorkerClient {
    agent_id: String,
    container_name: String,
    ws_url: String,
    status: WorkerConnectionStatus,
}

impl WorkerClient {
    pub async fn connect(agent_id: &str, ws_url: &str) -> Result<Self, WorkerClientError>;
    pub async fn disconnect(&self) -> Result<(), WorkerClientError>;
    pub fn is_connected(&self) -> bool;
}
```

### 22.5.4: Result collection

```rust
pub async fn await_result(
    &self,
    timeout: Duration,

    pub task_id: Uuid,
    pub success: bool,
    pub output: String,
    pub files_changed: Vec<String>,

```
