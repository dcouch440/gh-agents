# Ticket 22.1: Git Worktree Manager

> CRUD operations for git worktrees that give each agent an isolated branch checkout.

## Goal

`WorktreeManager` can create, list, and remove git worktrees under `.nexor/worktrees/`. Each worktree is a lightweight checkout on a specific branch, sharing the main repo's `.git` object store.

## Slices

### 22.1.1: WorktreeInfo and WorktreeError types

Define the data types.

```rust
pub struct WorktreeInfo {
    pub path: PathBuf,
    pub branch: String,
    pub agent_id: Option<String>,  // Tag for tracking ownership
    pub created_at: chrono::DateTime<chrono::Utc>,
}

pub enum WorktreeError {
    GitError(String),
    WorktreeExists { branch: String },
    WorktreeNotFound { path: PathBuf },
    InvalidBranch(String),
    CleanupFailed { path: PathBuf, reason: String },
    IoError(std::io::Error),
}
```

**Test**: Error display messages contain expected content. `WorktreeInfo` fields are accessible.

### 22.1.2: WorktreeManager::create

Create a worktree for a given branch.

```rust
impl WorktreeManager {
    pub fn new(project_root: PathBuf) -> Self;

    /// Creates .nexor/worktrees/<agent_id>/ on the given branch
    pub async fn create(
        &self,
        agent_id: &str,
        branch: &str,
    ) -> Result<WorktreeInfo, WorktreeError>;
}
```

Internally runs: `git worktree add .nexor/worktrees/<agent_id> -b <branch>` (or without `-b` if branch exists).

**Test**: Create worktree in temp repo, verify directory exists, verify branch is checked out (`git -C <worktree> branch --show-current`).

### 22.1.3: WorktreeManager::list

List all managed worktrees.

```rust
pub async fn list(&self) -> Result<Vec<WorktreeInfo>, WorktreeError>;
```

Parses output of `git worktree list --porcelain`.

**Test**: Create 2 worktrees, list returns both with correct branches.

### 22.1.4: WorktreeManager::remove

Remove a worktree and clean up.

```rust
pub async fn remove(&self, agent_id: &str) -> Result<(), WorktreeError>;
```

Runs `git worktree remove .nexor/worktrees/<agent_id> --force`, then `git worktree prune`.

**Test**: Create then remove, verify directory gone and `git worktree list` no longer includes it.

### 22.1.5: WorktreeManager::cleanup_all

Remove all nexor-managed worktrees. Used on startup or shutdown.

```rust
pub async fn cleanup_all(&self) -> Result<usize, WorktreeError>;
```

**Test**: Create 3 worktrees, cleanup_all removes all, returns count 3.
