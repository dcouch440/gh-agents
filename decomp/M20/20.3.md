# Ticket 20.3: Feed Store

> Create a reactive feed state store using the useSyncExternalStore pattern for Ink/React consumption.

## Goal

A module-level store that holds feed items, task state, and agent state. React components subscribe via a `useFeed()` hook.

**Checkpoint**: Feed items can be pushed, tasks/agents updated, and React components re-render on changes.

---

## Context

Ink uses React 18. `useSyncExternalStore` is the idiomatic way to subscribe to external state without Zustand or Redux.

**Key files**:
- `cli/src/store/feed.ts` — New file
- `cli/src/store/feed.test.ts` — New file

**Dependencies**: 20.1 (FeedItem, TaskUpdate, AgentUpdate types)

---

## Slices

### Slice 20.3.1: Core Store

**Do this**:
- Create `cli/src/store/feed.ts`
- Module-level state: `{ items: FeedItem[], tasks: Map<string, TaskUpdate>, agents: Map<string, AgentUpdate> }`
- `subscribe(callback)` → returns unsubscribe function
- `getSnapshot()` → returns current state (same reference if unchanged)
- Notify all listeners on any mutation

**Verify**:
- [ ] Unit test: subscribe receives notifications on mutations

---

### Slice 20.3.2: Mutation Functions

**Do this**:
- `pushFeedItem(update: FeedUpdate, branch?: string)` — converts FeedUpdate to FeedItem, appends
- `pushSystemMessage(content: string)` — adds a system-type FeedItem
- `insertDivider(branch: string)` — adds a branch_switch-type FeedItem
- `updateTask(update: TaskUpdate)` — upserts in tasks map
- `updateAgent(update: AgentUpdate)` — upserts in agents map
- `clearFeed()` — resets items array (keeps tasks/agents)
- Cap items array at 500 entries (drop oldest)

**Verify**:
- [ ] Unit test: each mutation function works correctly
- [ ] Unit test: items capped at 500

---

### Slice 20.3.3: React Hook

**Do this**:
- `useFeed()` hook wrapping `useSyncExternalStore(subscribe, getSnapshot)`
- Returns `{ items, tasks, agents }`
- Memoize return value to prevent unnecessary re-renders

**Verify**:
- [ ] Hook compiles
- [ ] `cd cli && npm test` passes
