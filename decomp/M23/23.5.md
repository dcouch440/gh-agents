# Ticket 23.5: REST API Endpoints

> HTTP endpoints for gate CRUD, conversation, and project tree.

## Goal

Expose gate operations and the project tree via REST API so the CLI can interact with the gate system.

**Checkpoint**: CLI can list gates, open a gate conversation, send messages, resolve/skip, and fetch the project tree — all via HTTP.

---

## Context

The Axum server already has auth-protected routes. Gate endpoints follow the same pattern: extract `AppState`, call service methods, return JSON.

**Key files**:
- `src/server/api.rs` — Add gate route handlers
- `src/server/state.rs` — Add `GateService` to `AppState`
- `src/server/mod.rs` — Register routes

**Dependencies**:
- 23.3 (gate service)
