# Ticket 23.6: Config Loading

> Parse gate toggle fields from project config TOML.

## Goal

The gate toggle fields (`milestone_gates`, `slice_gates`, `task_gates`) are read from `.nexor/config.toml` and validated.

**Checkpoint**: Config file with `milestone_gates = true` is loaded correctly, validation catches invalid combinations.

---

## Context

Project config is loaded in `src/config/project.rs` from `.nexor/config.toml`. The `[approval_gates]` section already exists with `before_commit`, `before_pr`, `before_merge` fields.

**Key files**:
- `src/config/project.rs` — Parse new fields
- `src/config/validation.rs` — Validate gate config

**Dependencies**:
- 23.1 (config type updates)

---

## Slices

### Slice 23.6.1: Project Config Parsing

**Do this**:
- Update the TOML deserialization in `src/config/project.rs` to include the new gate fields
- Fields should be optional with defaults (milestone_gates=true, slice_gates=false, task_gates=false)
- Missing fields fall back to defaults

**Modify `src/config/project.rs`**:
```toml
# Example .nexor/config.toml with gates
[approval_gates]
before_commit = false
before_pr = true
before_merge = true
milestone_gates = true
slice_gates = false
task_gates = false
```

**Verify**:
- [ ] Config with gate fields parses correctly
- [ ] Config without gate fields uses defaults
- [ ] `cargo test` config tests pass

---

### Slice 23.6.2: Validation Rules

**Do this**:
- In `src/config/validation.rs`, add validation: if `autonomy = "full_auto"`, gate toggles should all be false (warn or error)
- Gates only make sense when `autonomy = "approval_gates"` or `"supervised"`

**Modify `src/config/validation.rs`**:
```rust
// Add validation rule:
if config.autonomy == AutonomyLevel::FullAuto {
    let gates = &config.approval_gates;
    if gates.milestone_gates || gates.slice_gates || gates.task_gates {
        warnings.push("Gate toggles have no effect in full_auto autonomy mode".to_string());
    }
}
```

**Verify**:
- [ ] `full_auto` + gates enabled produces warning
- [ ] `approval_gates` + gates enabled validates cleanly
- [ ] Validation tests pass
