# Ticket 23.11: CLI Spec Detail View

> Browse the full ticket spec (goal, slices, descriptions) inline in the tree, like expanding files in a file explorer.

## Goal

When navigating the project tree, the user can expand any milestone, slice, or task to reveal its full specification content — goal, description, slices, acceptance criteria. This turns the tree into a browsable spec viewer where you can drill into any level of detail before deciding to open a gate.

**Checkpoint**: Open tree → expand a milestone → see its goal and slice list → expand a slice → see its description and task list → press `g` to open the gate from any level.

---

## Context

The tree overlay (23.8) currently shows titles and gate statuses. This ticket adds a deeper layer: each node can be expanded to show its spec content as readable, formatted text nested inside the tree. Think of it like expanding a folder in a file tree to see the files inside — except the "files" are sections of the ticket spec.

The backend needs a new endpoint (or extend the existing `/tree` endpoint) to serve spec content per node. The CLI tree component needs a "detail expansion" mode that renders markdown-formatted spec content inline.

**Key files**:
- `cli/src/components/TreeOverlay.tsx` — Add detail expansion
- `cli/src/hooks/useTree.ts` — Add spec content fetching
- `src/server/api.rs` — Add spec content endpoint

**Dependencies**:
- 23.8 (tree overlay)

### Slice 23.11.3: Tree Detail Expansion

**Do this**:
- Add a "detail expanded" state to tree items (separate from child expansion)
- When a node is "detail expanded", render its spec content as indented text blocks below the node in the tree
- Use a different key for detail expansion vs child expansion:
  - `→` (right arrow) or `Enter`: expand/collapse children (existing behavior)
  - `d` or `Space`: toggle detail view for the selected node
- Spec content is fetched lazily on first detail expansion and cached

**Modify `cli/src/hooks/useTree.ts`**:
```typescript
// Add to useTree hook:
const [detailExpanded, setDetailExpanded] = useState<Set<string>>(new Set());
const [specCache, setSpecCache] = useState<Map<string, SpecContent>>(new Map());

const toggleDetail = useCallback(async (id: string, level: string) => {
  const next = new Set(detailExpanded);
  if (next.has(id)) {
    next.delete(id);
  } else {
    next.add(id);
    // Fetch spec if not cached
    if (!specCache.has(id)) {
      const spec = await getSpecContent(id, level);
      setSpecCache(prev => new Map(prev).set(id, spec));
    }
  }
  setDetailExpanded(next);
}, [detailExpanded, specCache]);
```

**Modify `cli/src/components/TreeOverlay.tsx`**:
