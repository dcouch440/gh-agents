# Ticket 5.0: Plan Mode (Request → Strategy)

> Classify incoming requests by scale and route to appropriate decomposition strategy.

## Goal

Plan Mode sits upstream of the Planner. It classifies user requests by complexity (Quick, Task, Feature, Project, Epic) and routes them to the appropriate decomposition depth. Small requests skip decomposition entirely; large requests generate PRDs and milestone breakdowns before reaching the Planner.

**Checkpoint**: Call `PlanMode::process("Build a billing system")` and receive either:
- A direct task assignment (Quick)
- A ticket ready for Planner (Task/Feature)
- A generated PRD with milestones (Project/Epic)

---

## Context

Currently, all requests flow directly to the Planner (5.1), which assumes ticket-level input. This fails for:
- **Too small**: "Fix typo" doesn't need decomposition
- **Too large**: "Build entire auth system" overwhelms a single Planner call

Plan Mode adds intelligent routing:

```
Request
   ↓
[5.0 Plan Mode]
   ├─ Quick → Direct route to agent (skip Planner)
   ├─ Task → Light context → Planner
   ├─ Feature → Standard → Planner (current behavior)
   ├─ Project → Mini-PRD → Planner with context
   └─ Epic → Full PRD → Milestones → Planner (per milestone)
```

use crate::llm::LLMProvider;
use crate::types::{Ticket, Task, AgentTier};
use thiserror::Error;
use std::sync::Arc;
use serde::{Deserialize, Serialize};

/// Scale of incoming request - determines decomposition depth
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum RequestScale {
    /// Trivial task, no decomposition needed (e.g., "fix typo")
    Quick,
    /// Single task, light decomposition (e.g., "add input validation")
    Task,
    /// Standard feature, normal Planner flow (e.g., "add dark mode")
    Feature,
    /// Multi-feature project, needs mini-PRD (e.g., "build auth system")
    Project,
    /// Large initiative, full PRD + milestones (e.g., "build entire platform")
    Epic,
}

impl RequestScale {
    /// Whether this scale requires PRD generation
    pub fn needs_prd(&self) -> bool {
        matches!(self, Self::Project | Self::Epic)
    }

    /// Whether this scale requires milestone decomposition
    pub fn needs_milestones(&self) -> bool {
        matches!(self, Self::Epic)
    }

    /// Whether this scale can skip the Planner entirely
    pub fn skip_planner(&self) -> bool {
        matches!(self, Self::Quick)
    }
}

#[derive(Debug, Clone)]
pub struct ClassificationResult {
    pub scale: RequestScale,
    pub confidence: f32,
    pub reasoning: String,
    pub suggested_title: String,
}

#[derive(Debug, Clone)]
pub struct GeneratedPRD {
    pub title: String,
    pub vision: String,
    pub milestones: Vec<MilestoneSpec>,
    pub technical_decisions: Vec<String>,
    pub data_models: Vec<String>,
}

#[derive(Debug, Clone)]
pub struct MilestoneSpec {
    pub number: u32,
    pub title: String,
    pub goal: String,
    pub checkpoint: String,
    pub estimated_tickets: u32,
    pub dependencies: Vec<u32>,
}

/// Output from Plan Mode - tells downstream what to do
#[derive(Debug)]
pub enum PlanModeOutput {
    /// Skip decomposition, route directly to agent
    DirectRoute {
        task: Task,
        tier: AgentTier,
    },
    /// Standard path - send to Planner as ticket
    PlannerRoute {
        ticket: Ticket,
        context: Option<String>,
    },
    /// Project-level - includes mini-PRD for context
    ProjectRoute {
        ticket: Ticket,
        prd: GeneratedPRD,
    },
    /// Epic-level - multiple milestones, each becomes a ticket
    EpicRoute {
        prd: GeneratedPRD,
        milestone_tickets: Vec<Ticket>,
    },
}

#[derive(Error, Debug)]
pub enum PlanModeError {
    #[error("classification failed: {0}")]
    ClassificationError(String),

    #[error("PRD generation failed: {0}")]
    PrdGenerationError(String),

    #[error("LLM call failed: {0}")]
    LlmError(String),

    #[error("failed to parse response: {reason}")]
    ParseError { reason: String, raw_output: String },
}

#[derive(Debug, Clone)]
pub struct PlanModeConfig {
    /// Model for classification (can be cheaper)
    pub classifier_model: String,
    /// Model for PRD generation (needs to be smart)
    pub prd_model: String,
    /// Confidence threshold - below this, fall back to safer scale
    pub confidence_threshold: f32,
    /// Maximum milestones for epic decomposition
    pub max_milestones: u32,
}

impl Default for PlanModeConfig {
    fn default() -> Self {
        Self {
            classifier_model: "claude-haiku-3-5-latest".to_string(),
            prd_model: "claude-sonnet-4-20250514".to_string(),
            confidence_threshold: 0.7,
            max_milestones: 12,
        }
    }
}

pub struct PlanMode<P: LLMProvider> {
    provider: Arc<P>,
    config: PlanModeConfig,
}

impl<P: LLMProvider> PlanMode<P> {
    pub fn new(provider: Arc<P>, config: PlanModeConfig) -> Self {
        Self { provider, config }
    }
}

use crate::llm::LLMProvider;
use crate::prompts::PromptBuilder;
use super::{RequestScale, ClassificationResult, PlanModeError, PlanModeConfig};
use std::sync::Arc;
use serde::Deserialize;

#[derive(Debug, Deserialize)]
struct ClassificationOutput {
    scale: String,
    confidence: f32,
    reasoning: String,
    suggested_title: String,
    indicators: Vec<String>,
}

pub struct Classifier<P: LLMProvider> {
    provider: Arc<P>,
    config: PlanModeConfig,
}

impl<P: LLMProvider> Classifier<P> {
    pub fn new(provider: Arc<P>, config: PlanModeConfig) -> Self {
        Self { provider, config }
    }

    pub async fn classify(&self, request: &str) -> Result<ClassificationResult, PlanModeError> {
        let prompt = self.build_classification_prompt(request);

        let response = self.provider
            .send_message(&prompt, &self.config.classifier_model)
            .await
            .map_err(|e| PlanModeError::LlmError(e.to_string()))?;

        let output = self.parse_classification(&response.content)?;
        let mut result = self.convert_to_result(output);

        // Apply confidence threshold - if uncertain, fall back to safer (smaller) scale
        if result.confidence < self.config.confidence_threshold {
            result.scale = self.fallback_scale(result.scale);
            tracing::info!(
                original_scale = ?result.scale,
                confidence = result.confidence,
                "Low confidence classification, falling back to safer scale"
            );
        }

        Ok(result)
    }

    fn build_classification_prompt(&self, request: &str) -> String {
        PromptBuilder::new()
            .role("classifier")
            .system(r#"
You classify software development requests by scale. Analyze the request and determine:

SCALES:
- Quick: Trivial, single-file changes. Examples: "fix typo", "update version number", "add comment"
- Task: Small, focused work. Examples: "add input validation", "fix login bug", "update error message"
- Feature: Standard feature work. Examples: "add dark mode", "implement search", "add export to CSV"
- Project: Multi-feature system. Examples: "build auth system", "add payment processing", "create admin dashboard"
- Epic: Large initiative spanning weeks/months. Examples: "build entire platform", "rewrite backend in Rust", "create AI agent system"

INDICATORS:
- Quick: Single file, <10 lines changed, no new dependencies
- Task: 1-3 files, clear scope, hours of work
- Feature: Multiple files, new functionality, days of work
- Project: Multiple features, new subsystems, week+ of work
- Epic: Multiple milestones, architectural decisions, month+ of work

Output JSON:
{
    "scale": "quick|task|feature|project|epic",
    "confidence": 0.0-1.0,
    "reasoning": "why this scale",
    "suggested_title": "concise title for this work",
    "indicators": ["indicator1", "indicator2"]
}
"#)
            .user(request)
            .output_format("classification_json")
            .build()
    }

    fn parse_classification(&self, content: &str) -> Result<ClassificationOutput, PlanModeError> {
        // Extract JSON from response
        let json_str = Self::extract_json(content)?;

        serde_json::from_str(&json_str).map_err(|e| PlanModeError::ParseError {
            reason: e.to_string(),
            raw_output: content.to_string(),
        })
    }

    fn extract_json(content: &str) -> Result<String, PlanModeError> {
        // Try markdown code block first
        if let Some(start) = content.find("```json") {
            if let Some(end) = content[start + 7..].find("```") {
                return Ok(content[start + 7..start + 7 + end].trim().to_string());
            }
        }

        // Try raw JSON
        if let Some(start) = content.find('{') {
            if let Some(end) = content.rfind('}') {
                return Ok(content[start..=end].to_string());
            }
        }

        Err(PlanModeError::ParseError {
            reason: "No JSON found".to_string(),
            raw_output: content.to_string(),
        })
    }

    fn convert_to_result(&self, output: ClassificationOutput) -> ClassificationResult {
        let scale = match output.scale.to_lowercase().as_str() {
            "quick" => RequestScale::Quick,
            "task" => RequestScale::Task,
            "feature" => RequestScale::Feature,
            "project" => RequestScale::Project,
            "epic" => RequestScale::Epic,
            _ => RequestScale::Feature, // Safe default
        };

        ClassificationResult {
            scale,
            confidence: output.confidence,
            reasoning: output.reasoning,
            suggested_title: output.suggested_title,
        }
    }

    /// Fall back to a safer (smaller) scale when confidence is low
    fn fallback_scale(&self, scale: RequestScale) -> RequestScale {
        match scale {
            RequestScale::Epic => RequestScale::Project,
            RequestScale::Project => RequestScale::Feature,
            RequestScale::Feature => RequestScale::Task,
            RequestScale::Task => RequestScale::Task, // Don't fall to Quick
            RequestScale::Quick => RequestScale::Quick,
        }
    }
}

use super::classifier::Classifier;
use super::prd_generator::PrdGenerator;
use uuid::Uuid;
use chrono::Utc;

impl<P: LLMProvider> PlanMode<P> {
    /// Process a raw request through Plan Mode
    pub async fn process(&self, request: &str) -> Result<PlanModeOutput, PlanModeError> {
        // Step 1: Classify the request
        let classifier = Classifier::new(Arc::clone(&self.provider), self.config.clone());
        let classification = classifier.classify(request).await?;

        tracing::info!(
            scale = ?classification.scale,
            confidence = classification.confidence,
            title = %classification.suggested_title,
            "Request classified"
        );

        // Step 2: Route based on scale
        match classification.scale {
            RequestScale::Quick => {
                self.handle_quick(request, &classification).await
            }
            RequestScale::Task | RequestScale::Feature => {
                self.handle_standard(request, &classification).await
            }
            RequestScale::Project => {
                self.handle_project(request, &classification).await
            }
            RequestScale::Epic => {
                self.handle_epic(request, &classification).await
            }
        }
    }

    async fn handle_quick(
        &self,
        request: &str,
        classification: &ClassificationResult,
    ) -> Result<PlanModeOutput, PlanModeError> {
        // Quick requests skip decomposition entirely
        let task = Task {
            id: TaskId(Uuid::new_v4()),
            slice_id: None,
            title: classification.suggested_title.clone(),
            description: request.to_string(),
            assigned_tier: AgentTier::Utility, // Quick tasks go to utility
            assigned_agent: None,
            status: TaskStatus::Pending,
            priority: Priority::Normal,
            context_files: vec![],
            metadata: None,
            created_at: Utc::now(),
            updated_at: Utc::now(),
        };

        Ok(PlanModeOutput::DirectRoute {
            task,
            tier: AgentTier::Utility,
        })
    }

    async fn handle_standard(
        &self,
        request: &str,
        classification: &ClassificationResult,
    ) -> Result<PlanModeOutput, PlanModeError> {
        // Standard path - create ticket for Planner
        let ticket = Ticket {
            id: TicketId(Uuid::new_v4()),
            title: classification.suggested_title.clone(),
            description: request.to_string(),
            source: TicketSource::Manual,
            status: TicketStatus::Open,
            created_at: Utc::now(),
            updated_at: Utc::now(),
        };

        Ok(PlanModeOutput::PlannerRoute {
            ticket,
            context: Some(classification.reasoning.clone()),
        })
    }

    async fn handle_project(
        &self,
        request: &str,
        classification: &ClassificationResult,
    ) -> Result<PlanModeOutput, PlanModeError> {
        // Generate mini-PRD for context
        let generator = PrdGenerator::new(Arc::clone(&self.provider), self.config.clone());
        let prd = generator.generate(request, RequestScale::Project).await?;

        let ticket = Ticket {
            id: TicketId(Uuid::new_v4()),
            title: prd.title.clone(),
            description: format!("{}\n\nVision: {}", request, prd.vision),
            source: TicketSource::Manual,
            status: TicketStatus::Open,
            created_at: Utc::now(),
            updated_at: Utc::now(),
        };

        Ok(PlanModeOutput::ProjectRoute { ticket, prd })
    }

    async fn handle_epic(
        &self,
        request: &str,
        classification: &ClassificationResult,
    ) -> Result<PlanModeOutput, PlanModeError> {
        // Generate full PRD with milestones
        let generator = PrdGenerator::new(Arc::clone(&self.provider), self.config.clone());
        let prd = generator.generate(request, RequestScale::Epic).await?;

        // Convert each milestone to a ticket
        let milestone_tickets: Vec<Ticket> = prd.milestones.iter().map(|m| {
            Ticket {
                id: TicketId(Uuid::new_v4()),
                title: format!("M{}: {}", m.number, m.title),
                description: format!(
                    "Goal: {}\n\nCheckpoint: {}\n\nEstimated tickets: {}",
                    m.goal, m.checkpoint, m.estimated_tickets
                ),
                source: TicketSource::Generated,
                status: TicketStatus::Open,
                created_at: Utc::now(),
                updated_at: Utc::now(),
            }
        }).collect();

        tracing::info!(
            epic_title = %prd.title,
            milestone_count = milestone_tickets.len(),
            "Epic decomposed into milestones"
        );

        Ok(PlanModeOutput::EpicRoute {
            prd,
            milestone_tickets,
        })
    }
}

use sqlx::SqlitePool;

pub struct PlanMode<P: LLMProvider> {
    provider: Arc<P>,
    pool: SqlitePool,
    config: PlanModeConfig,
}

impl<P: LLMProvider> PlanMode<P> {
    pub fn new(provider: Arc<P>, pool: SqlitePool, config: PlanModeConfig) -> Self {
        Self { provider, pool, config }
    }

    /// Process and persist results
    pub async fn process_and_save(&self, request: &str) -> Result<PlanModeOutput, PlanModeError> {
        let output = self.process(request).await?;

        // Persist PRD if generated
        match &output {
            PlanModeOutput::ProjectRoute { prd, .. } |
            PlanModeOutput::EpicRoute { prd, .. } => {
                self.save_prd(prd, request).await?;
            }
            _ => {}
        }

        Ok(output)
    }

    async fn save_prd(&self, prd: &GeneratedPRD, source_request: &str) -> Result<(), PlanModeError> {
        let prd_id = Uuid::new_v4().to_string();
        let scale = if prd.milestones.len() > 5 { "epic" } else { "project" };

        sqlx::query!(
            r#"
            INSERT INTO generated_prds (id, title, vision, technical_decisions, data_models, scale, source_request, created_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            "#,
            prd_id,
            prd.title,
            prd.vision,
            serde_json::to_string(&prd.technical_decisions).unwrap(),
            serde_json::to_string(&prd.data_models).unwrap(),
            scale,
            source_request,
            Utc::now().to_rfc3339(),
        )
        .execute(&self.pool)
        .await
        .map_err(|e| PlanModeError::PrdGenerationError(e.to_string()))?;

        // Save milestones
        for milestone in &prd.milestones {
            let milestone_id = Uuid::new_v4().to_string();
            sqlx::query!(
                r#"
                INSERT INTO milestone_specs (id, prd_id, number, title, goal, checkpoint, estimated_tickets, dependencies, created_at)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                "#,
                milestone_id,
                prd_id,
                milestone.number,
                milestone.title,
                milestone.goal,
                milestone.checkpoint,
                milestone.estimated_tickets,
                serde_json::to_string(&milestone.dependencies).unwrap(),
                Utc::now().to_rfc3339(),
            )
            .execute(&self.pool)
            .await
            .map_err(|e| PlanModeError::PrdGenerationError(e.to_string()))?;
        }

        tracing::info!(prd_id = %prd_id, title = %prd.title, "PRD saved to database");
        Ok(())
    }
}
