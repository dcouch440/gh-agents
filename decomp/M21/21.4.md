# Ticket 21.4: MainView Integration

> Wire the git watcher, branch selector, and transition logic into MainView.

## Goal

MainView supports both explicit `/branch` switching and auto-detection of `git checkout`. Both paths use the same transition UX.

**Checkpoint**: `/branch` opens selector → select branch → divider shown. `git checkout` in another terminal → divider shown automatically.

---

## Context

MainView already has `currentBranch` state and `showBranchSelector` from M20. This ticket connects the remaining pieces.

**Key files**:
- `cli/src/components/MainView.tsx` — Modify
- `cli/src/components/MainView.test.tsx` — Extend

**Dependencies**: 21.3

---

## Slices

### Slice 21.4.1: Wire useGitBranch Hook

**Do this**:
- Call `useGitBranch(onChange)` in MainView
- `onChange` callback: if branch differs from `currentBranch`, call `handleBranchSwitch(newBranch)`
- Set initial branch from hook's first callback (instead of hardcoded `'main'`)

**Verify**:
- [ ] Test: MainView initializes with detected branch
- [ ] Test: external branch change triggers transition

---

### Slice 21.4.2: Wire BranchSelector

**Do this**:
- When `showBranchSelector` is true, render `<BranchSelector>` between FeedArea and InputBar
- Pass `currentBranch`, `onSelect: handleBranchSwitch`, `onCancel: () => setShowBranchSelector(false)`
- When selector is open, set `disabled={true}` on InputBar

**Verify**:
- [ ] Test: /branch opens selector
- [ ] Test: selecting branch closes selector + shows divider
- [ ] Test: Esc closes selector without switching

---

### Slice 21.4.3: Unified handleBranchSwitch

**Do this**:
- Single `handleBranchSwitch(name: string)` function used by both paths:
  1. If `name === currentBranch`, push system message "Already on branch: <name>", return
  2. Call `insertDivider(name)` (marks old items stale + inserts divider)
  3. Set `currentBranch` to `name`
  4. Set `showBranchSelector` to false
  5. Push system message: `Switched to branch: <name>`

**Verify**:
- [ ] Test: same-branch switch shows "already on" message
- [ ] Test: different-branch switch shows divider + system message

---

### Slice 21.4.4: Direct /branch <name> Switch

**Do this**:
- `/branch main` (with args) calls `handleBranchSwitch('main')` directly without opening selector
- `/branch` (no args) opens selector
- Already wired in M20 command deps, verify it works end-to-end

**Verify**:
- [ ] Test: `/branch main` switches directly
- [ ] Test: `/branch` opens selector
- [ ] `cd cli && npm test` passes
