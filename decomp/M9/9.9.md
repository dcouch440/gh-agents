# Ticket 9.9: TUI Integration

> Integrate refactor mode into the terminal user interface.

## Overview

Add refactor mode support to the TUI:
- `/refactor` command to enter mode
- Mode indicator in status bar
- `/exit` and conversation-based mode exit

## Slices

### Slice 9.9.1: Mode System

**Goal**: Add application mode tracking

**Files**:
- `src/tui/mode.rs` - New file
- `src/tui/mod.rs` - Export mode module

**Types**:
- `AppMode` - Normal, Refactor(RefactorModeState)
- `RefactorModeState` - Session, halted flag, change counts

**Methods**:
- `is_normal()`, `is_refactor()` - Mode checks
- `name()`, `status_indicator()` - Display helpers
- `summary()` - State summary string

**Verify**: Unit tests pass

### Slice 9.9.2: Command System

**Goal**: Add slash command parsing and routing

**Files**:
- `src/tui/commands.rs` - New file
- `src/tui/mod.rs` - Export commands module

**Types**:
- `Command` - Refactor, Exit, Help, Quit, Feed, Main, Logs, Tasks, Agents, Costs, Unknown
- `CommandResult` - Success, Error, ModeChanged, ViewChanged, Quit, Help

**Functions**:
- `Command::parse()` - Parse input to command
- `generate_help_text()` - Generate help message

**Verify**: Unit tests pass

### Slice 9.9.3: App Integration

**Goal**: Main app with mode switching and input handling

**Files**:
- `src/tui/app.rs` - New file
- `src/tui/mod.rs` - Export app module

**Types**:
- `View` - Home, Feed, Main, Logs, Tasks, Agents, Costs
- `App` - Main application state

**Methods**:
- `handle_input()` - Process user input
- `enter_refactor_mode()`, `exit_refactor_mode()` - Mode transitions
- `handle_refactor_input()` - Process input in refactor mode
- `status_bar_text()` - Generate status bar
- `apply_refactor_changes()` - Apply approved changes

**Features**:
- `/refactor` enters refactor mode
- `/exit` exits current mode (or quits in normal mode)
- Saying "done" or "exit" in refactor mode exits
- Saying "STOP" in refactor mode halts production
- Status bar shows mode indicator
- View switching with slash commands

**Verify**: Integration tests pass
