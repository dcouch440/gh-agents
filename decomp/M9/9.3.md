# Ticket 9.3: Error Handling Polish

> Graceful failures and recovery throughout the application.

## Goal

- Errors don't crash the application
- Users see clear, actionable error messages
- Recovery suggestions are provided for common errors
- Errors are properly logged for debugging

### Slice 9.3.1: Error Boundaries for Async Tasks

**Do this**:
- Wrap all spawned async tasks with error boundaries
- Catch panics and convert to errors
- Log errors with context (task ID, agent ID, etc.)
- Prevent one task failure from crashing the app
- Report failures through feed/notification channel

**Create/modify**:
- `src/error.rs` - create centralized error module
- `src/agents/runtime.rs` - wrap agent tasks
- `src/orchestration/scheduler.rs` - wrap scheduler tasks

**Code example**:
```rust
// src/error.rs
use thiserror::Error;
use std::panic;
use tokio::task::JoinHandle;
use tracing::{error, warn};
use tokio::sync::mpsc;

#[derive(Error, Debug)]
pub enum NexorError {
    #[error("configuration error: {message}")]
    Config { message: String, suggestion: Option<String> },

    #[error("database error: {message}")]
    Database { message: String, suggestion: Option<String> },

    #[error("LLM API error: {message}")]
    LlmApi { message: String, suggestion: Option<String> },

    #[error("GitHub API error: {message}")]
    GitHubApi { message: String, suggestion: Option<String> },

    #[error("agent error: {agent_id} - {message}")]
    Agent { agent_id: String, message: String, suggestion: Option<String> },

    #[error("task failed: {task_id} - {message}")]
    TaskFailed { task_id: String, message: String, recoverable: bool },

    #[error("internal error: {message}")]
    Internal { message: String },
}

impl NexorError {
    pub fn suggestion(&self) -> Option<&str> {
        match self {
            NexorError::Config { suggestion, .. } => suggestion.as_deref(),
            NexorError::Database { suggestion, .. } => suggestion.as_deref(),
            NexorError::LlmApi { suggestion, .. } => suggestion.as_deref(),
            NexorError::GitHubApi { suggestion, .. } => suggestion.as_deref(),
            NexorError::Agent { suggestion, .. } => suggestion.as_deref(),
            _ => None,
        }
    }

    pub fn is_recoverable(&self) -> bool {
        match self {
            NexorError::TaskFailed { recoverable, .. } => *recoverable,
            NexorError::LlmApi { .. } => true,  // Usually transient
            NexorError::GitHubApi { .. } => true,
            _ => false,
        }
    }
}

/// Spawn a task with error boundary
pub fn spawn_with_boundary<F, T>(
    name: &str,
    error_tx: mpsc::Sender<NexorError>,
    future: F,
) -> JoinHandle<()>
where
    F: std::future::Future<Output = Result<T, anyhow::Error>> + Send + 'static,
    T: Send + 'static,
{
    let name = name.to_string();
    tokio::spawn(async move {
        match future.await {
            Ok(_) => {}
            Err(e) => {
                error!(task = %name, error = %e, "task failed");
                let nexor_error = NexorError::Internal {
                    message: format!("{}: {}", name, e),
                };
                let _ = error_tx.send(nexor_error).await;
            }
        }
    })
}

/// Catch panic in a future
pub async fn catch_panic<F, T>(future: F) -> Result<T, NexorError>
where
    F: std::future::Future<Output = T>,
{
    match panic::catch_unwind(panic::AssertUnwindSafe(|| {
        futures::executor::block_on(future)
    })) {
        Ok(result) => Ok(result),
        Err(e) => {
            let msg = if let Some(s) = e.downcast_ref::<&str>() {
                s.to_string()
            } else if let Some(s) = e.downcast_ref::<String>() {
                s.clone()
            } else {
                "unknown panic".to_string()
            };
            Err(NexorError::Internal { message: format!("panic: {}", msg) })
        }
    }
}
```

### Slice 9.3.2: Error Display in TUI

**Do this**:
- Add error display area in TUI (collapsible section)
- Show recent errors with timestamp
- Color code by severity (red=fatal, yellow=warning)
- Allow dismissing errors
- Show error count in header when minimized

**Create/modify**:
- `src/tui/layout.rs` - add error display area
- `src/tui/app.rs` - manage error state and display

**Code example**:
```rust
// src/tui/errors.rs
use crate::error::NexorError;
use ratatui::{
    buffer::Buffer,
    layout::Rect,
    style::{Color, Modifier, Style},
    text::{Line, Span},
    widgets::{Block, Borders, List, ListItem, Widget},
};
use chrono::{DateTime, Local};

#[derive(Debug, Clone)]
pub struct DisplayError {
    pub error: NexorError,
    pub timestamp: DateTime<Local>,
    pub dismissed: bool,
}

impl DisplayError {
    pub fn new(error: NexorError) -> Self {
        Self {
            error,
            timestamp: Local::now(),
            dismissed: false,
        }
    }
}

pub struct ErrorDisplay {
    pub errors: Vec<DisplayError>,
    pub expanded: bool,
    pub max_visible: usize,
}

impl Default for ErrorDisplay {
    fn default() -> Self {
        Self {
            errors: Vec::new(),
            expanded: false,
            max_visible: 5,
        }
    }
}

impl ErrorDisplay {
    pub fn push(&mut self, error: NexorError) {
        self.errors.push(DisplayError::new(error));
        // Auto-expand on new error
        self.expanded = true;
    }

    pub fn dismiss_all(&mut self) {
        for e in &mut self.errors {
            e.dismissed = true;
        }
        self.expanded = false;
    }

    pub fn active_count(&self) -> usize {
        self.errors.iter().filter(|e| !e.dismissed).count()
    }

    pub fn recent_errors(&self) -> Vec<&DisplayError> {
        self.errors
            .iter()
            .filter(|e| !e.dismissed)
            .rev()
            .take(self.max_visible)
            .collect()
    }
}

impl Widget for ErrorDisplay {
    fn render(self, area: Rect, buf: &mut Buffer) {
        let active = self.active_count();

        if !self.expanded {
            // Collapsed: just show count if any
            if active > 0 {
                let text = format!("⚠ {} error(s) - press 'e' to expand", active);
                buf.set_string(area.x, area.y, &text, Style::default().fg(Color::Yellow));
            }
            return;
        }

        // Expanded: show error list
        let items: Vec<ListItem> = self.recent_errors()
            .iter()
            .map(|de| {
                let time = de.timestamp.format("%H:%M:%S").to_string();
                let color = if de.error.is_recoverable() {
                    Color::Yellow
                } else {
                    Color::Red
                };

                let mut spans = vec![
                    Span::styled(format!("[{}] ", time), Style::default().fg(Color::DarkGray)),
                    Span::styled(format!("{}", de.error), Style::default().fg(color)),
                ];

                if let Some(suggestion) = de.error.suggestion() {
                    spans.push(Span::raw("\n"));
                    spans.push(Span::styled(
                        format!("  → {}", suggestion),
                        Style::default().fg(Color::Cyan),
                    ));
                }

                ListItem::new(Line::from(spans))
            })
            .collect();

        let title = format!(" Errors ({}) - press 'd' to dismiss ", active);
        let list = List::new(items)
            .block(Block::default()
                .borders(Borders::ALL)
                .border_style(Style::default().fg(Color::Red))
                .title(title));

        Widget::render(list, area, buf);
    }
}
```

### Slice 9.3.3: Recovery Suggestions

**Do this**:
- Add helpful suggestions for common errors:
  - API key missing/invalid → "Set ANTHROPIC_API_KEY environment variable"
  - Rate limited → "Wait until {reset_time} or reduce concurrency"
  - Network error → "Check your internet connection"
  - Config parse error → "Check syntax in {file} near line {line}"
  - Database locked → "Another nexor instance may be running"
- Make suggestions actionable and specific

**Create/modify**:
- `src/error.rs` - add suggestion mappings

**Code example**:
```rust
// src/error.rs - add suggestion helper
impl NexorError {
    /// Create error with appropriate suggestion
    pub fn config_missing_key(key: &str) -> Self {
        NexorError::Config {
            message: format!("missing required key: {}", key),
            suggestion: Some(format!("Add '{}' to your config file", key)),
        }
    }

    pub fn config_invalid_value(key: &str, value: &str, expected: &str) -> Self {
        NexorError::Config {
            message: format!("invalid value for '{}': {}", key, value),
            suggestion: Some(format!("Expected: {}", expected)),
        }
    }

    pub fn api_key_missing(provider: &str) -> Self {
        let env_var = match provider {
            "anthropic" => "ANTHROPIC_API_KEY",
            "github" => "GITHUB_TOKEN",
            _ => "API_KEY",
        };
        NexorError::Config {
            message: format!("{} API key not found", provider),
            suggestion: Some(format!(
                "Set the {} environment variable: export {}=\"your-key\"",
                env_var, env_var
            )),
        }
    }

    pub fn rate_limited(reset_time: chrono::DateTime<chrono::Utc>) -> Self {
        NexorError::LlmApi {
            message: "rate limit exceeded".to_string(),
            suggestion: Some(format!(
                "Wait until {} or reduce agent concurrency in config",
                reset_time.format("%H:%M:%S UTC")
            )),
        }
    }

    pub fn network_error(details: &str) -> Self {
        NexorError::LlmApi {
            message: format!("network error: {}", details),
            suggestion: Some("Check your internet connection and try again".to_string()),
        }
    }

    pub fn database_locked() -> Self {
        NexorError::Database {
            message: "database is locked".to_string(),
            suggestion: Some(
                "Another nexor instance may be running. Close it or delete .nexor/state.db-lock"
                    .to_string()
            ),
        }
    }

    pub fn github_not_found(resource: &str) -> Self {
        NexorError::GitHubApi {
            message: format!("{} not found", resource),
            suggestion: Some(
                "Check the URL and ensure you have access to this repository".to_string()
            ),
        }
    }

    pub fn github_unauthorized() -> Self {
        NexorError::GitHubApi {
            message: "authentication failed".to_string(),
            suggestion: Some(
                "Check your GITHUB_TOKEN has the required permissions (repo scope)".to_string()
            ),
        }
    }

    pub fn agent_timeout(agent_id: &str) -> Self {
        NexorError::Agent {
            agent_id: agent_id.to_string(),
            message: "agent timed out".to_string(),
            suggestion: Some(
                "The task may be too complex. Try breaking it into smaller pieces.".to_string()
            ),
        }
    }
}

/// Convert common anyhow errors to NexorError with suggestions
pub fn enrich_error(error: anyhow::Error) -> NexorError {
    let msg = error.to_string().to_lowercase();

    if msg.contains("api key") || msg.contains("unauthorized") || msg.contains("401") {
        return NexorError::api_key_missing("unknown");
    }

    if msg.contains("rate limit") || msg.contains("429") {
        return NexorError::LlmApi {
            message: error.to_string(),
            suggestion: Some("Rate limited. Wait a moment and try again.".to_string()),
        };
    }

    if msg.contains("network") || msg.contains("connection") || msg.contains("timeout") {
        return NexorError::network_error(&error.to_string());
    }

    if msg.contains("database") || msg.contains("sqlite") {
        if msg.contains("locked") {
            return NexorError::database_locked();
        }
        return NexorError::Database {
            message: error.to_string(),
            suggestion: None,
        };
    }

    // Default: internal error
    NexorError::Internal {
        message: error.to_string(),
    }
}
```

## Notes

- **Don't hide errors**: Users should see what went wrong, but not be overwhelmed
- **Log everything**: Even if we show a friendly message, log the full error for debugging
- **Recoverable vs fatal**: Recoverable errors (network, rate limit) can be retried; fatal errors need user action
- **Error deduplication**: Consider deduping repeated errors (e.g., same error every second)
- **Error history**: Keep last N errors for debugging, but don't let it grow unbounded
- **Keyboard shortcuts**: 'e' to expand, 'd' to dismiss feels intuitive
