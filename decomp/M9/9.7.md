# Ticket 9.7: Refactor Mode Foundation

> Foundation types, database schema, and scheduler integration for /refactor mode.

## Overview

Create the core infrastructure needed for refactor mode:
- Types for tracking production mode, sessions, and changes
- Database tables for persistence
- Scheduler integration for pause/resume

## Slices

### Slice 9.7.1: Refactor Types

**Goal**: Define core types for refactor mode

**Files**:
- `src/types/refactor.rs` - New file
- `src/types/mod.rs` - Export refactor module

**Types**:
- `RefactorId` - Unique identifier for sessions
- `ProductionMode` - Running, RefactorMode, Paused, Resuming
- `RefactorIntent` - HaltNow, RefactorNeeded, Clarifying, JustChatting, ExitRefactor
- `ChangeType` - Create, Modify, Delete, Rename
- `ChangeStatus` - Proposed, Approved, Rejected, Applied
- `RefactorChange` - A proposed change to a planning file
- `RefactorSession` - Session tracking with changes
- `RefactorContext` - Context provided to the agent

**Verify**: `cargo check`

### Slice 9.7.2: Database Migration

**Goal**: Add database tables for refactor persistence

**Files**:
- `migrations/007_create_refactors.sql` - New migration

**Tables**:
- `system_state` - Key-value for production mode
- `refactor_sessions` - Session tracking
- `refactor_changes` - Proposed changes within sessions

**Verify**: Migration runs without errors

### Slice 9.7.4: Scheduler Integration
