# Ticket 9.4: Docker Packaging

> Containerized deployment for easy installation and isolation.

## Goal

Create Docker packaging that:
- Builds nexor in a multi-stage Dockerfile
- Provides docker-compose for easy deployment
- Documents Docker usage
- Enables running without Rust toolchain

**Checkpoint**: Can run `docker-compose up` and interact with nexor.

## Slices

### Slice 9.4.1: Production Dockerfile

**Do this**:
- Create `docker/Dockerfile` with multi-stage build:
  - Builder stage: Rust toolchain, build release binary
  - Runtime stage: Minimal base image, just the binary
- Use Alpine or Debian slim for small image size
- Set up non-root user for security
- Configure proper entrypoint

**Create/modify**:
- `docker/Dockerfile`
- `docker/.dockerignore`

**Code example**:
```dockerfile
# docker/Dockerfile

# =============================================================================
# Stage 1: Builder
# =============================================================================
FROM rust:1.75-slim-bookworm AS builder

# Install build dependencies
RUN apt-get update && apt-get install -y \
    pkg-config \
    libssl-dev \
    && rm -rf /var/lib/apt/lists/*

# Create app directory
WORKDIR /app

# Copy manifests first for layer caching
COPY Cargo.toml Cargo.lock ./

# Create dummy src to cache dependencies
RUN mkdir src && \
    echo "fn main() {}" > src/main.rs && \
    cargo build --release && \
    rm -rf src

# Copy actual source
COPY src ./src
COPY migrations ./migrations

# Build release binary
RUN touch src/main.rs && cargo build --release

# =============================================================================
# Stage 2: Runtime
# =============================================================================
FROM debian:bookworm-slim AS runtime

# Install runtime dependencies
RUN apt-get update && apt-get install -y \
    ca-certificates \
    libssl3 \
    && rm -rf /var/lib/apt/lists/*

# Create non-root user
RUN useradd -m -u 1000 nexor

# Create data directory
RUN mkdir -p /data/.nexor && chown -R nexor:nexor /data

# Copy binary from builder
COPY --from=builder /app/target/release/nexor /usr/local/bin/nexor

# Set ownership
RUN chown nexor:nexor /usr/local/bin/nexor

# Switch to non-root user
USER nexor

# Set working directory
WORKDIR /data

# Environment variables
ENV RUST_LOG=info
ENV NEXOR_DATA_DIR=/data/.nexor

# Expose no ports (TUI app, not a server)

# Default command
ENTRYPOINT ["nexor"]

# Default to headless mode in container
CMD ["--help"]
```

```dockerfile
# docker/.dockerignore
target/
.git/
.github/
*.md
!README.md
.nexor/
*.log
.env
.env.*
docker/
!docker/Dockerfile
docs/
tests/
```

### Slice 9.4.2: Docker Compose Setup

**Do this**:
- Create `docker/docker-compose.yml`
- Configure volume mounts:
  - Project directory (for code access)
  - Data directory (for persistence)
- Pass through environment variables for API keys
- Support both TUI and headless modes
- Add optional services (could add monitoring later)

**Create/modify**:
- `docker/docker-compose.yml`

**Code example**:
```yaml
# docker/docker-compose.yml
version: "3.8"

services:
  nexor:
    build:
      context: ..
      dockerfile: docker/Dockerfile
    image: nexor:latest
    container_name: nexor

    # For TUI mode, need TTY
    stdin_open: true
    tty: true

    # Environment variables (API keys)
    environment:
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - GITHUB_TOKEN=${GITHUB_TOKEN}
      - RUST_LOG=${RUST_LOG:-info}

    # Mount project directory for code access
    volumes:
      - ${PROJECT_DIR:-.}:/project:rw
      - nexor-data:/data/.nexor

    # Working directory
    working_dir: /project

    # Override default command for interactive mode
    # For headless: docker-compose run nexor --headless --task "..."
    command: []

  # Optional: headless worker for batch jobs
  nexor-headless:
    build:
      context: ..
      dockerfile: docker/Dockerfile
    image: nexor:latest
    container_name: nexor-headless
    profiles:
      - headless  # Only start with --profile headless

    environment:
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - GITHUB_TOKEN=${GITHUB_TOKEN}
      - RUST_LOG=${RUST_LOG:-info}

    volumes:
      - ${PROJECT_DIR:-.}:/project:rw
      - nexor-data:/data/.nexor
      - ${INPUT_FILE:-/dev/null}:/input:ro
      - ${OUTPUT_DIR:-./output}:/output:rw

    working_dir: /project

    command: ["--headless", "--input", "/input", "--output", "/output/result.txt"]

volumes:
  nexor-data:
    name: nexor-data
```

**Example `.env` file**:
```bash
# .env (in project root)
ANTHROPIC_API_KEY=sk-ant-...
GITHUB_TOKEN=ghp_...
PROJECT_DIR=/path/to/your/project
RUST_LOG=info
```

# docs/docker.md

# Docker Deployment

Run nexor in a Docker container without installing Rust.

## Prerequisites

- Docker 20.10+
- Docker Compose 2.0+ (optional, for easier management)

## Quick Start

### Using Docker directly

```bash
# Build the image
docker build -t nexor -f docker/Dockerfile .

# Run with TUI (interactive)
docker run -it \
  -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY \
  -v $(pwd):/project \
  nexor

# Run headless
docker run \
  -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY \
  -v $(pwd):/project \
  nexor --headless --task "implement feature X"
```

### Using Docker Compose

```bash
# Copy example env file and add your keys
cp .env.example .env
# Edit .env with your API keys

# Build and run
docker-compose run nexor

# Run headless batch job
docker-compose run nexor --headless --task "your task"
```

## Configuration

### Environment Variables

| Variable | Description | Required |
|----------|-------------|----------|
| `ANTHROPIC_API_KEY` | Anthropic API key | Yes |
| `GITHUB_TOKEN` | GitHub personal access token | For GitHub features |
| `RUST_LOG` | Log level (info, debug, trace) | No (default: info) |
| `PROJECT_DIR` | Project directory to mount | No (default: current dir) |

### Volume Mounts

| Mount | Purpose |
|-------|---------|
| `/project` | Your project directory (code access) |
| `/data/.nexor` | Persistent nexor data (database, logs) |

## Use Cases

### Interactive TUI

```bash
docker-compose run nexor
```

Requires TTY. Works in terminal, not in CI.

### Headless for CI/CD

```bash
docker run \
  -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY \
  -v $(pwd):/project \
  nexor --headless --task "run tests and fix failures"
```

### Batch Processing

```bash
# Create tasks file
echo "Add unit tests" > tasks.txt
echo "Update documentation" >> tasks.txt

# Run batch
docker run \
  -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY \
  -v $(pwd):/project \
  -v $(pwd)/tasks.txt:/input.txt:ro \
  nexor --headless --input /input.txt
```

## Troubleshooting

### "API key not found"

Ensure environment variables are passed to container:
```bash
docker run -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY ...
```

### "Permission denied" on mounted volumes

The container runs as UID 1000. Ensure your files are accessible:
```bash
chmod -R a+rw /path/to/project
```

### "Database locked"

Only one nexor instance can access the database. Stop other containers:
```bash
docker-compose down
```

### Can't see TUI output

TUI requires interactive terminal. Use `-it` flags:
```bash
docker run -it ...  # Note: -it not just -i
```

## Notes

- **Image size**: Multi-stage build keeps image small (~50-100MB)
- **Security**: Running as non-root is important for production
- **Persistence**: Data volume preserves database across container restarts
- **TUI in Docker**: Requires `-it` flags for interactive terminal
- **CI/CD**: Headless mode works without TTY for automation
- **Layer caching**: Cargo.toml copied first to cache dependencies
